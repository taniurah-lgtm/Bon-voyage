# Instagramカード用の写真

`scripts/social/render-ig-card.mjs` が、その日の内容に合わせてここから写真を1枚選び、
フィード画像(1080×1350)の上半分に使う。

## ⚠ 置いてよい写真
- **自分たちで撮った写真**（いちばん良い。地元感が出て信頼される）
- 商用利用OKのライセンス素材（Unsplash / Pexels / 写真AC など、規約を確認のうえ）

**公式サイトやSNSから拾った他人の写真は不可**（著作権侵害）。どうしても使いたい場合は主催者に許可を取り、
クレジットを明記すること。

## 置き方
内容に合うカテゴリのフォルダに入れるだけ（ファイル名は自由）。

| フォルダ | 使われる内容の例 |
|---|---|
| `park/` | 公園・広場・原っぱ・遊具・散歩 |
| `water/` | じゃぶじゃぶ池・プール・水あそび・川 |
| `fireworks/` | 花火・大火祭り |
| `festival/` | 夏祭り・盆踊り・縁日・阿波おどり・マルシェ |
| `indoor/` | 室内あそび場・雨の日・図書館・児童館 |
| `museum/` | 科学館・博物館・プラネタリウム・たてもの園 |
| `train/` | 電車・鉄道・駅 |
| `animal/` | 動物園・牧場・水族館・ふれあい |
| `camp/` | キャンプ・BBQ・アウトドア |
| `_default/` | 上に該当が無いとき／カテゴリのフォルダが空のときに使う予備 |

- 推奨サイズ: 横1600px以上・横長（上半分にトリミングされる）。容量は1枚1MB程度まで。
- **子どもの顔が特定できる写真は避ける**（風景・後ろ姿・手元などが安心）。
- 同じ日は同じ写真、日が変わると順番に巡って使われる（同カテゴリに複数入れておくと絵面が変わる）。

## 写真がないとき
そのカテゴリも `_default/` も空なら、写真なし（ブランド色のグラデーション）で生成される。
まずは撮り溜めた写真を少しずつ足していけばOK。
