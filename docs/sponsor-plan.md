# 協賛（BtoB）の売り方 — 2026-09-05 決定

収益の本線は**読者への課金ではなく、地元事業者からの協賛**。
読者側の課金は「年1回の応援」に格下げする（`docs/strategy-2026-09.md`）。

---

## 1. 協賛は2種類。混ぜない

### A. 紹介型（本文に載る）＝ **お金を払っているおでかけ先だけ**

| | |
|---|---|
| 載せ方 | **ほかのイベントと完全に同じ書式**。年齢3区分・天気の目安・締切 |
| 違うところ | 末尾に **「協賛」と明記する**（下記・法律の話） |
| 料金 | **1回 3,000円の単発**。月額にしない |
| 枠 | **1号1件まで。**冒頭に置かない。バナーを貼らない |
| 対象 | 習い事の体験会（スイミング・体操・英語・リトミック・ピアノ）／摘み取り農園（ブルーベリー・芋掘り）／室内遊び場／陶芸・パン作りの体験／写真館の七五三／商店会のまつり |

単発にする理由: 体験会は開催日が決まっていて、月額を売る理由がない。
初回のハードルが低く、良ければまた買う。

### B. 応援型（名前だけ載る）＝ **お祭りの提灯**

| | |
|---|---|
| 載せ方 | 本文のいちばん下に「この通信は以下の協賛で届いています」＋**屋号のみ1行** |
| 枠 | **5枠まで。増やさない** |
| 料金 | **年 一口 10,000円・前払い** |
| 対象 | 小児科・歯科・不動産・保険・整体。**紙面と無関係でよい**（むしろ無関係な方が自然） |
| おまけ | **チラシ下部にも同じ協賛欄**。市の窓口経由で20館に並ぶ紙に名前が載る |

5枠埋まれば**年50,000円**＝LINEの費用（月5,000円）のほぼ全額。

年額にする理由: 月額だと「毎月、何のために払うのか」を説明し続けることになる。

### やらないこと

- クリニックを**紹介文**で載せる（応援型の名前だけにする）
- 紹介型を月額にする
- 応援型を5枠より増やす

## 2. 🔴 法律の話 — 「協賛」の明記は必須

**お金をもらった掲載を、広告と分からない形で出すと景品表示法のステマ規制に当たる**
（2023年10月施行）。方針の問題ではなく、守らないと違法。

- 紹介型には**必ず「協賛」と書く**。号のなか・ホームページ・過去号のすべてで
- 応援型も「協賛」の見出しの下に置く
- **「協賛」の一文が、規制対応・トーン・お店の好感を同時に満たす。**削る理由がない

---

## 3. 原稿は、こちらが書く

お店に原稿を書かせると宣伝文になる。**こちらが確認して、ほかのイベントと同じ書式で書く。**

必ず入れる: ベビーカー可否／おむつ替え／予約の要否／何歳から／料金／締切

こうすると協賛枠が**「有料なのに、いちばん役に立つ行」**になる。対価をもらう理由がここに立つ。

---

## 4. 断る基準（先に決めておく）

- 子連れに向かない先
- 読者に合わない業種
- **金額が良くても載せない**

市の窓口と多摩六都科学館に置いてもらえている信用は、**1回の掲載で失える。**
断る基準があること自体が、載せた側の格を上げる。

**同業種は同じ月に2件入れない。**「この月はうちだけ」が売り物になる。

## 5. 売り込み方

**相手は、店に決定者がいる個人事業者だけ。** チェーンや本部決裁は追えない（稼働が足りない）。

### 対面5分。資料はスマホの画面だけ

> 花小金井周辺の子育て家庭59世帯に、毎週水曜の朝に届いています。
> 読んでいるのは9割が母親で、8割が都内在住。2か月でブロックは2人。
> この通信に、体験会をほかのイベントと同じ書式で載せる枠を作りました。
> 1回3,000円です。私が書きます。

**使ってはいけない言葉: 「広告」「宣伝」「今だけ」**

### 「59人しかいない」と言われたら

> チラシ500枚を配って何人来ますか。
> 59人は全員が近所の子育て世帯で、毎週読んでいます。

効果を疑われたら、計測の仕組み（配布先別QR・パス別集計）を出す。

### 初月無料は最初の2件まで

実績と「載った側の声」をもらう対価。**3件目からは無料なし。**

### 順番

1. 台帳から紹介型の第1号（→ ⚠️ **いまの台帳には居ない。下記「6.」**）
2. **せいぶ通り商店会**に、今回のお礼と次回協賛の話（2026-09 に無料で裏取りまでして載せた）
3. **不動産2社**に、配布依頼ではなく**応援型（年一口10,000円）**として連絡し直す
4. 応援型の残り枠を、読者がよく行く場所の隣の小児科・歯科へ

## 6. ⚠️ 紹介型の第1号は、いまの台帳からは出てこない

2026-09-05 に台帳（62件）とマップ（46件）を全部あたった結果:

| 見つかった有料のもの | 判定 |
|---|---|
| 多摩六都科学館（KAPLA大会） | 公的施設。**売る相手ではなく提携先** |
| 田無アスタ（アスター海賊団・スライム） | 商業施設。**本部決裁**で、個人事業者ではない |
| 子育て支援講座（カラフル弁当） | **市の講座** |
| キッズランドUS / ちきゅうのにわ | どちらも**チェーン** |

**民間の・個人事業者の・有料のおでかけ先は、1件も載せたことがない。**

理由ははっきりしていて、**巡回先が公共のソースだけで組まれているから**
（`docs/sources.md` のコア巡回セット）。市・公民館・児童館・図書館・観光協会。
そこに習い事も農園も体験教室も出てこない。

### だから、先にやることは「営業」ではなく「巡回先を増やす」

`docs/sources.md` に **「民間の有料おでかけ先」の巡回セット**を足した。
ここが埋まらないと、紹介型は売る商品そのものが無い。

**当面の進め方**: 次に載せる予定の民間の先に、**載せる前に**聞く。

> 来週ご紹介したいのですが、協賛枠として3,000円でどうですか。

断られても、載せるつもりだったなら**無料で載せてよい**。
ただし**「今回は無料、次回から協賛枠」と口に出しておく。**

## 7. お金の受け取り方

### 🔵 事業主体は「ニコマル」（2026-09-06 決定）

ぼんぼやーじゅ通信は、**妻の個人事業「ニコマル」の事業のひとつ**として扱う。
費用も収入も、ぜんぶニコマルの帳簿1本に乗せる。

| | 置き場所 |
|---|---|
| LINE公式アカウント代（ライト 5,000円/月＝年6万円） | ニコマルのカード（国分寺DIY工房で使っているもの） |
| 印刷代・交通費 | 同上 |
| 協賛金の入金先 | ニコマルの屋号付き口座 |
| 請求書・領収書の発行名義 | **ニコマル** |
| チラシ・サイトの「発行：ぼんぼやーじゅ通信の会」 | そのまま。通称としての併記 |

**なぜ寄せるか**：費用が妻の事業、収入が別、という形にすると、
他人の事業の費用が妻の経費に混ざる（税務上も否認されうる）うえ、
**通信が黒字か赤字か誰にも読めなくなる**。年6万円の費用と協賛収入が
同じ帳簿に乗って初めて、下の「判定の線」がそのまま読める。

- あすぴあ登録の「ぼんぼやーじゅ通信の会」とは矛盾しない。
  **市民活動団体としての登録と、事業主体は別に置ける**
- 協賛の請求書・領収書は**ニコマル名義**で出す。相手に渡す紙の発行者名が
  チラシと違うことになるので、初回の説明で一言添える
  （「発行はぼんぼやーじゅ通信の会、経理はニコマルで見ています」）
- LINE Business ID の**請求先情報もニコマルに合わせる**（適格請求書が出るため）

### 集金の実務

**銀行振込・前払い・請求書は無料ツール。**

- 個人事業者は振込請求に慣れている。**カード決済リンクの方が敬遠される**
- 紹介型は**掲載前に振込**、応援型は**年一口前払い**。集金の手間と未払いの心配が消える
- 口座は**ニコマルの屋号付き口座**。個人名だけより相手が安心する
- 請求書は Misoca や freee の無料枠。差出人は**屋号（ニコマル）＋メール＋電話**で足り、**自宅住所は不要**
- **インボイスは登録しない。**聞かれたら「未登録です」と先に言う
- **PayPay等の個人間送金は使わない**（商用利用の規約問題。信用を損なう）
- 書面は**「掲載申込書」1枚**。内容・期間・金額・**「子連れに向かないと判断した場合は掲載をお断りできる」**の一文。契約書は要らない

> ⚠️ **確定申告の線は「収入20万円」ではなく「所得20万円」。**
> 給与所得者の副業は、**所得（収入−経費）が年20万円を超えると所得税の確定申告が必要**。
> ただし今回は**ニコマル（妻の個人事業）の売上・経費として申告**するので、
> 判断するのは妻の事業所得のほう。この20万円の線は谷裏さん個人には当たらない。
> さらに、**20万円以下でも住民税の申告は必要**（所得税の申告不要ラインとは別）。
> 印刷代・交通費・LINEの月額は経費に落ちるので、記録を残しておくこと。

## 10. 小平商工会に電話する（042-344-2311）

### かける前に決めておくこと

**今日のゴールは1つだけ。「担当の方の名前」と「次にすること」を聞く。**
売り込まない。初回で協賛の話を出すと、次が無くなる。

- **かける時間**: 平日 14:00〜16:00。**月曜の午前・金曜の夕方・12〜13時は避ける**
- **名乗り**: 団体名 →「あすぴあ登録団体」→ 用件。個人事業の話は出さない
  （市民活動団体としてのほうが、商工会は話を聞きやすい）
- **手元に置く**: チラシ1枚、スマホでホームページ、メモ用紙

### 🔴 言ってはいけないこと

- **「広告」「宣伝」「協賛をお願いしたい」** — 初回では出さない。売り込みの電話として処理される
- **「10月から商品券が始まると聞いて」** — **この情報は裏取りできていない。**
  違っていたら初回で信用を落とす。**白紙で「今年度の実施予定はありますか」と聞く**
- **作り方の話**（巡回・自動・使っている道具）— `CLAUDE.md`「公開物に書かないこと」と同じ

### 最初の30秒（そのまま読んでよい）

> お世話になります。小平市で、子育て世帯向けのおでかけ情報を**無料でお配りしている**
> 「ぼんぼやーじゅ通信の会」の谷裏と申します。
> 小平市民活動支援センターあすぴあの登録団体で、活動しております。
> 本日は**ご相談**でお電話しました。ご担当の方、少しだけお時間よろしいでしょうか。

（つないでもらえたら）

> 未就学児から小学生のいるご家庭に向けて、市内のイベントやおでかけ先を
> 毎週おとどけしています。10月下旬に、市の課を通じて**市内20館の地域センターと
> 児童館**にチラシを置いていただく予定です。
> それで、**商工会さんの会員のお店の情報も、子育て世帯にお伝えできないか**と思いまして。

### 聞くこと（この順番。4つまで）

1. **会報・広報誌はありますか。** 市民活動団体からのお知らせを載せていただくことはできますか
   → 載る条件／原稿の締切／発行の頻度／部数／どこへ配られるか
2. **会員のお店に、子育て世帯向けの情報を届けたい**と思っています。
   会員のみなさまにご案内する方法はありますか（回覧・メール・部会など）
3. **商品券の事業について。** 今年度の実施予定はありますか。
   あれば**加盟店の一覧はどこで見られますか**。通信でご紹介したいと思っています
4. （最後に軽く）**入会について**も教えてください。対象・会費・受けられること

### なぜこの4つを、この順番で聞くか

順番は「**相手の手間が小さい順** × **こちらが与える話が先**」。
4つに絞るのは、**電話が3分だから**。5つ以上聞くと「面倒な人」と判断され、次が無くなる。
**今日の勝ち筋は「全部聞く」ことではなく、「2回目の電話ができる状態を作る」こと。**

| # | 表向きの用件 | 本当に取りに行っているもの | 順番の理由 |
|---|---|---|---|
| 1 | 会報に載せてほしい | **配布網**＋「会報に載った媒体」という**信用** | 特別な決裁が要らない日常業務なので**断られにくい**。ここでYesが1つ出ると、以降が「協力する側」の会話になる |
| 2 | 会員の店に情報を届けたい | **協賛の買い手への接触経路**（回覧・部会・メール網） | `6.` のとおり紹介型の第1号は台帳から出ない。買い手のいる場所へ行く必要がある。**「広告」と言わずに経路だけ聞ける言い方**にしてある |
| 3 | 商品券のこと | **加盟店一覧＝地元の店の名簿**／関係を温める／未検証情報の裏取り | 商工会の看板事業で、たいてい**周知に困っている**。「紹介したい」は貢献の申し出になる。ただし**いきなり聞くと「取材か」と身構えられる**ので、自己紹介のあと |
| 4 | 入会について | 判断材料だけ。今日決めない | **最初に聞くと「会員でないと」という門前払いの理由を相手に差し出すことになる。**最後なら1〜3の答えはもう手元にある。「軽く」なのは、これが主目的だと思われると1〜3の答えが営業トークに変わるから |

### 相手が言いそうなこと → 返し

| 言われること | 返し |
|---|---|
| 「会員の方ですか？」 | 「まだ入っておりません。まずはご相談をと思いまして。入会についても後ほど教えてください」 |
| 「どういう団体ですか？」 | 「あすぴあの登録団体で、第254号です。無料の通信で、いまお読みの方が60名ほど。10月下旬から市内20館に置いていただきます」 |
| 「有料の広告掲載でしたら…」 | 「今日はそのお話ではなくて。**まず会員のお店のことを子育て世帯に知ってもらいたい**、というご相談です」 |
| 「担当が不在です」 | **お名前と、戻られる時間を聞く。「こちらからかけ直します」**（先方にかけさせない） |
| 「資料を送ってください」 | **その場で宛先を聞く。**メールか郵送か、宛名は誰宛か。**当日中に送る** |

### 通話のあとに残すこと（`docs/apo-list.md` へ）

- 日時／出た方のお名前・部署／次にすること・期限
- 会報：あるか／締切／発行日／部数／配布先
- 商品券：実施の有無／期間／加盟店一覧の入手先
- 入会：対象／会費／得られること
- **次に電話する日**（宙に浮かせない）

## 11. 🔴 小平商工会は打ち止め（2026-09-07 電話ずみ）

**042-344-2311 に架電。結果は4つとも空振り。入会は見送る。**

| 聞いたこと | 答え |
|---|---|
| 会報・広報誌に載せてもらえるか | **無い** |
| 会員のお店へ案内してもらえるか | **できない** |
| 商品券の加盟店一覧 | **会員・非会員が混在**（＝商工会の会員名簿ではない） |
| 入会 | できるが、**入っても会員への案内はできない** |

部会にも子育て向けの紹介先は無い。活動内容そのものは理解してもらえた。

### 何を間違えていたか

この章にはもともと「**加盟店＝協賛の買い手がまとまっている唯一の場所**」と書いていた。
**これが誤り。**小平商工会は**支援機関**（経営相談・補助金・共済）であって、**媒体を持っていない**。
「商工会には会報がある」と暗黙に決めつけていた。会報が無い時点で配布網ではない。

**→ 入会しても得るものが無い。会費を払わない。** この判断を覆すのは、
先方から「こういう枠ができた」と連絡が来たときだけ。**こちらから再訪しない。**

### 商品券は、期待していたものではなかった

一般の商品券事業ではなく、**夏のレシートキャンペーン（3,000円で応募・8月末〆）の派生**。
当選者が **10/30までに使い切る**段階で、周知にも困っていない。

**→ 営業・協賛の材料としては終わり。商工会に戻る理由は完全に消えた。**

加盟店一覧に「会員も非会員もいる」のは事実だが、**キャンペーン限りの名簿**なので、
「地元の店の名簿」としての価値も限定的。取りに行く優先度は低い。

🔴 別のAIが出した「10/1〜11/30」は**誤り**だった。裏取りできていない数字を
電話で口にしなかったのが効いた（`10.`「言ってはいけないこと」の実例）。

### 買い手にたどり着く道は、こう置き換わった

| もとの想定 | 実際 |
|---|---|
| 商工会の会報に載る → 会員店に届く | **無い。**配布網は**市の2課（20館＋児童館3館）**と**商店会**だけ |
| 商工会経由で会員店に案内 | **できない。**1軒ずつか、**保護者つながり**で入る |
| 会員名簿＝買い手リスト | **商品券の加盟店一覧**を自分で取る |

**次にあたるのは せいぶ通り商店会**（`docs/distribution.md`「せいぶ通り商店会への打診」）。
商店会は**小売の集まり**で、商工会とは目的が違う。連絡先が個人商店なので**決裁が要らない**のも大きい。
