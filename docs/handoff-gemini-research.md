### 日付に曜日が書いてあったら、合っているか見てほしい

**去年のチラシが、今年のものとしてSNSに流れてきます。**実際に2回踏みかけました。

- 「9月18日（金）」とあったら、**その年の9/18が本当に金曜か**
- 「第52回」とあったら、**去年が第51回で辻褄が合うか**

**ずれていたら「去年のものかもしれません」と添える。**
🔴 **それでも落とさないでください。**判断は Claude 側でします。

### 情報が食い違ったら、そのまま渡してください

例: チラシは「主催 みんデパ事務局」、協会サイトは「小平市ハンドメイド協会」。

## 6. やってはいけないこと

| | なぜ |
|---|---|
| **見ていないことを書く** | 🔴 **これだけが本当の禁止事項。**「たぶん無料」「例年どおりなら10月」は書かない。**「分からない」と書く** |
| まとめサイトを**出典として書く** | `iko-yo`・まいぷれ・号外NET 等は**見つける入口としては大いに使ってよい**。ただし出典欄には「まとめサイトで見かけた」と正直に書く（Claude が一次に置き換えます） |
| **個人の連絡先を書く** | 主催者個人の携帯（080/090）やフリーメールは出さない。**公式の代表番号だけ** |
| **受診者数・来場者数などの数字を推測で出す** | 裏の取れた数字だけ |
| **この通信の作り方を外に書く** | 巡回の仕組み・頻度・自動化の有無・道具の名前・巡回先の一覧 |
| **SNSの投稿文をそのままコピーする** | 要約して、出典は公式に置く |
