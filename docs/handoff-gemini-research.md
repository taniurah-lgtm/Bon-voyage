## 4. 🔴 裏取りのルール（この仕事の本体）

**見つけたら、必ず主催者・施設・自治体の公式ページを開く。**そこで次を確認する。

| 項目 | 注意 |
|---|---|
| 名称 | 正式名称で |
| **日付** | **★下の「曜日と回次」を必ずやる** |
| 時間 | 開始・終了 |
| 場所 | 施設名＋住所 |
| 費用 | **「無料」は公式に書いてあるときだけ。**書いていなければ「記載なし」 |
| 対象 | 年齢・学年・市内在住限定かどうか |
| 申込 | 不要 / 要（**締切・開始日・定員**） |
| 雨天時 | **書いていなければ「記載なし」。推測しない** |
| 出典URL | **必ず。これが無いものは報告しない** |

### 🔴 曜日と回次を必ず検証する（2回、事故りかけている）

**去年のチラシが今年のものとしてSNSに流れてくる。**実際に2回踏みかけた。

1. **曜日を計算する。**「9月18日（金）」と書いてあるなら、その年の9/18が本当に金曜か
2. **回次を数える。**「第52回」なら、去年が第51回で辻褄が合うか
3. **合わなければ、それは去年のもの。**報告しない（または「去年のものかもしれない」と明記）

### 情報が食い違ったら、そのまま報告する

例: チラシは「主催 みんデパ事務局」、協会サイトは「小平市ハンドメイド協会」。
**どちらかに決めない。「2つのソースで食い違っている」と書く。**

```
- 見かけた場所: Instagram @xxxxx の 9/14 の投稿 / X の検索結果 など

```

## 6. やってはいけないこと

| | なぜ |
|---|---|
| **まとめサイト・キュレーションサイトを出典にする** | 読者への約束と正面から矛盾する。`iko-yo` 等は**見つける入口**としては使ってよいが、**出典は必ず一次に置き換える** |
| **公式に無いことを補う** | 「たぶん無料」「例年どおりなら」は書かない。**「記載なし」と書く** |
| **個人の連絡先を書く** | 主催者個人の携帯（080/090）やフリーメールは出さない。**公式の代表番号だけ** |
| **受診者数・来場者数などの数字を推測で出す** | 裏の取れた数字だけ |
| **この通信の作り方を外に書く** | 巡回の仕組み・頻度・自動化の有無・道具の名前・巡回先の一覧 |
| **SNSの投稿文をそのままコピーする** | 要約して、出典は公式に置く |

**毎週たくさん出すことではなく、次の2つが増えることが成果。**

- **A（裏が取れたもの）のうち、Claude が台帳に無かったもの**
