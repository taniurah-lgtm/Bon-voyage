# 協賛の買い手リスト（内部用・非公開）

**駅の広告は「協賛の買い手」の答え合わせになる。**
`docs/sponsor-plan.md` に「営業10件やって0なら、この街に買い手はいない」という判断基準があるが、
**駅ホームに広告を出している事業者は、すでに広告費を払っている＝買い手が実在する証拠**である。

- 記録開始: **2026-09-10**（小平駅ホームで3件）
- ここに載せるのは**看板・掲示に出ている公式の代表番号と住所だけ**。
  個人の携帯・フリーメールは載せない（`CLAUDE.md`「個人の連絡先を機械可読で撒かない」）
- **このファイルは公開しない。**チラシ・ホームページ・通信に転記しない

## 1. なぜ駅広告が効くのか

`docs/sponsor-plan.md` 6章に、こう書いてある。

> **民間の・個人事業者の・有料のおでかけ先は、1件も載せたことがない。**
> 理由ははっきりしていて、**巡回先が公共のソースだけで組まれているから**。
> 市・公民館・児童館・図書館・観光協会。そこに習い事も農園も体験教室も出てこない。

**駅ホームの広告は、その穴をそのまま埋める一次情報源。**しかも——

| 普通の巡回で分かること | 駅広告で追加で分かること |
|---|---|
| その事業者が存在する | **広告にお金を払う習慣がある** |
| 何をやっているか | **子育て世帯を客だと思っている**（広告の絵柄と文言で分かる） |
| 場所 | **どの駅の利用者を狙っているか**＝商圏の自己申告 |

Threadsを1件ずつ見るより、**駅のホームを一周撮ってくるほうが、単位時間あたりの収穫が大きい。**

### 撮ってくる駅（優先順）

1. **花小金井**（南口・北口・ホーム）— 宛先の中心
2. **小平**（ゾーンB。2026-09-10 実施済み）
3. 久米川・小川・一橋学園・鷹の台 — 小平市内の残り
4. 田無・東久留米 — 読者が行く先

## 3. 🔴 正直に見ておくべき弱点

**「駅に出しているから紙にも出す」とは限らない。**
むしろ「**もう駅に出しているので足りている**」と言われる可能性がある。これは想定しておく。

そのときに効く言い方は、値段ではなくて**媒体の性質の違い**:

> 駅の広告は、通る人の目に一瞬入ります。
> こちらは**持ち帰られて、家で読まれる紙**です。市の20館と児童館3館に置かれます。

⭕️ これは事実で、しかも検証できる。
❌ 「駅より効きます」は言わない（**効果の約束は §7 で禁止**）
