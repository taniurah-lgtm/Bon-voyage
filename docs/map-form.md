# みんなのおでかけマップ — 投稿フォームと承認フロー

`docs/homepage/map.html` に載せる「みんなの声」を集める仕組み。
**Googleフォーム → スプレッドシート → 承認 → 毎日の取り込みでマップに反映**、という流れ。

## 全体の流れ

```
投稿者 → Googleフォーム → スプレッドシート（オーナーだけが見られる）
                                  ↓ ①毎日、Claudeが新着を読んで所見をつける
                            オーナーに通知（push/メール）
                                  ↓ ②オーナーが「承認」列に ✓（3日以内めやす）
                            ③翌日の取り込みで data/map-posts.json に反映
                                  ↓
                            マップ再生成 → 公開
```

- **承認されるまで、投稿は絶対に公開されない。** 子どもの居場所の話なので、人の目を必ず通す。
- Claudeは「これは載せて大丈夫そう / ここが気になる」という**所見を出すだけ**で、公開の判断はオーナーがする。

## 1. Googleフォームの設問

タイトル: **みんなのおでかけマップに書き込む**

説明文:
> 花小金井まわりで「行ってよかった」場所を教えてください。ひとことで構いません。
> いただいた内容は、こちらで目を通してから地図に掲載します（数日いただきます）。
> ※お子さんのお名前・顔がわかる写真・通っている園や学校がわかる内容は掲載できません。

| # | 質問 | 形式 | 必須 | 備考 |
|---|---|---|---|---|
| 1 | 場所の名前 | 記述（短文） | ✓ | 例: 小金井公園 / 多摩六都科学館 |
| 2 | ひとこと | 段落 | ✓ | **説明に「40字まで（サポーターの方は長めでもOK）」と書く** |
| 3 | お名前・ニックネーム（地図に出ます） | 記述（短文） | | 空欄なら「ご近所の方」と表示 |
| 4 | お住まいのエリア・お子さんの年齢 | 記述（短文） | | 例: 小平・4歳2歳。**市区町村より細かくは書かないよう説明に添える** |
| 5 | 合言葉（応援サポーターの方のみ） | 記述（短文） | | **正しく入力されている場合だけ、長文と写真が掲載対象になる** |
| 6 | 写真（サポーターの方のみ） | ファイルのアップロード | | Googleアカウントが必要。**顔が写っていないもの**と説明に明記 |
| 7 | 掲載についての確認 | チェックボックス | ✓ | 「掲載前に運営が確認すること、掲載を見送る場合があることに同意します」 |

### 無料 / サポーターの線引き（フォームでの表現）

- 設問2の説明: 「**40字まで**でお願いします。応援サポーターの方は長めに書いていただけます（下の合言葉欄にご記入ください）。」
- 合言葉が空 or 不一致 → **40字に切り詰めて掲載・写真は載せない**（切り詰める場合はその旨を本人に伝える必要はない。無理に削らず、長ければ掲載を見送るのでも可）
- 合言葉が一致 → 長文可・写真可

> **注意**: 合言葉はスプレッドシートに平文で残る。シートは**絶対に共有しない・公開しない**。
> 後述の「公開用シート」には合言葉の列を含めないこと。

## 2. スプレッドシート側の準備

フォームの回答先スプレッドシートで、以下を1回だけ設定する。

1. 回答シートの右端に **`承認`** 列を作り、**チェックボックス**にする（挿入 → チェックボックス）。
   - オーナーがここに ✓ を入れたものだけが公開される。
2. 別シート **`公開用`** を作り、A1 に次を入れる。合言葉・メールアドレスなど**公開してはいけない列を除いて**転記する。
   ```
   =QUERY('フォームの回答 1'!A:H, "select A,B,C,D,E,H where H = TRUE", 1)
   ```
   ※列の記号は実際のシートに合わせて直す（A=タイムスタンプ, B=場所, C=ひとこと, D=名前, E=エリア年齢, H=承認 の想定）。
   **合言葉の列と写真の列は入れない。**
3. `公開用` シートだけを **ファイル → 共有 → ウェブに公開 → 形式=カンマ区切り(.csv)** で公開する。
   - 出てきたURLを GitHub の Secrets に **`MAP_SHEET_CSV`** として登録。
   - 「ウェブに公開」はURLを知る人なら誰でも読めるが、**このシートには承認済み＝もともと公開する内容しか入らない**ので問題ない。
4. フォームの回答URLを、GitHub の Variables に **`MAP_FORM_URL`** として登録（マップの「書き込む」ボタンの飛び先）。

## 3. 毎日の取り込み

`scripts/map-ingest.mjs` が毎日:

1. `MAP_SHEET_CSV` を取得
2. **新着（前回まで見ていない行）** を `data/map-pending.json` に記録し、内容の所見をつける
   - 個人が特定できそうな記述、園・学校名、電話番号、URL、営業妨害的な内容などを機械的にチェック
3. **承認済みの行**を `data/map-posts.json` に反映 → `scripts/build-map.mjs` でマップを再生成 → コミット
4. 新着があった日だけ、オーナーに通知する

> 承認は**スプレッドシートで完結**する。チャットで「1と3を承認」と返す必要はない。
> オーナーは通知を見て、シートを開いて ✓ を入れるだけ。

## 4. 掲載を見送る基準（Claudeの所見と、オーナーの判断の共通のものさし）

- お子さんの氏名、通っている園・学校、住所番地、電話番号が書かれている
- 顔がはっきり写った写真（本人以外の子が写り込んでいるものは特に）
- 特定の店舗・個人への批判や、事実か確認できない苦情
- 宣伝・勧誘・外部サービスへの誘導
- 場所が実在するか確認できない

判断に迷ったら**載せない**。あとから足すことはできるが、消しても見た人の記憶は消えない。
