# 多摩六都科学館 — リールを作るための資料

**使い方**: 撮ってきた写真・動画と、この1枚を渡せば、Instagramリールの原稿が作れる。
渡した先（別のAIでも可）は、**この資料に書いてあることだけ**を使う。
書いていないことは調べずに、**その話に触れない**。もっともらしい補足が1つ混ざるだけで、
「一件ずつ確かめています」という土台が崩れる。

## 🔒 0. 必ず入れる一文

> **※最新の情報は多摩六都科学館ウェブサイトでご確認ください。**

**館名を明示して、必ず添える。**これは先方との約束で、**掲載の条件**。
リールなら**キャプションの末尾**（画面の文字ではなく本文）。省略しない。

## ⭕️ 0-2. この回だけ「行ってきました」と書いてよい

ふだんイベント情報について「自分の足で確かめて」と書くのは**嘘**なので禁じている。
ただし今回は**実際に館内で撮っている**ので、

- ⭕️ 「行ってきました」「見てきました」「うちの子はここが長かったです」
- ❌ それでも、**撮っていないもの**を見たように書かない（プラネタリウムに入っていないなら、入った体で書かない）

## 4. リールの作り方

### 型（15〜30秒）

1. **最初の1.5秒で場所を見せる。**建物の外観かドーム。ここで離脱が決まる
2. **子どもが何かをしている画**を2〜3カット
3. **実用情報を1つ、画面の文字で**（例：ベビーカーはプラネタリウムに入れません）
4. **最後に1カット、余韻**

### 文字

- **音を消して見られる前提。**言いたいことは画面の文字に置く
- 1画面**15字以内**。2行まで
- 数字は強い。「520円」「1億4000万個」「27.5m」「0歳から」

### キャプション

```
（本文2〜4行。撮ったものについて、見たまま）

多摩六都科学館（西東京市芝久保町5-10-64）
展示室は大人520円・小人210円（4歳〜高校生）
9:30〜17:00／月曜休み

※最新の情報は多摩六都科学館ウェブサイトでご確認ください。

#多摩六都科学館 #西東京市 #小平 #花小金井 #雨の日のおでかけ
```

🔴 **ハッシュタグは5つまで。**2025-12-19に発表、2026年から実施。
6つ目以降は入力できないか、剥がされる。**どれを残すかは自分で決める。**
残す基準は §7 のとおり**地名中心**。館の共同運営5市（東村山・清瀬・東久留米）は、
宛先が小平である以上、優先度は下。最後の1枠はその回の題材で入れ替える
（雨／未就学児／プラネタリウム など）。

### トーン

- ❌ 「必見」「絶対」「今だけ」「損」「ママ目線で厳選」
- ❌ 効果の断定（「賢くなる」「集中力がつく」）
- ⭕️ 見たまま、具体的に。**うちの子がどうだったか**は書いてよい（事実だから）

## 7. 使う道具（2026-09 調べ）

### 🔴 Gemini は、この用途では違う

Geminiの動画機能（Veo）は、**テキストや画像から映像をゼロから生成する**もの（最大8秒）。
**撮ってきた実物の素材を編集する道具ではない。**

そして**この事業では使ってはいけない**。実在する館のリールにAIが作った映像を混ぜたら、
「市や施設のページで一件ずつ確かめています」の**真逆**をやることになる。
Meta自身も投稿時に「AIラベル」を求めている。

⭕️ ただし**別の場所では効く**。撮った動画を読ませて、
**使えるカットを選ばせる／原稿と字幕を書かせる**のは正しい使い方。

### 仕事は3つに分かれる。道具が要るのは真ん中だけ

| | 何で | 目安 |
|---|---|---|
| 素材を選ぶ・原稿を書く | Claude / Gemini（この資料を渡す） | 5分 |
| **組み立てる（尺・字幕・音）** | **Edits** | 10〜15分 |
| 出す | Edits からそのまま投稿 | 1分 |

### 第一候補: **Edits**（Meta純正・無料）

- **透かしが付かない**
- **日本語の自動字幕。**音を消して見られる前提なので、ここが本体
- **Instagramにそのまま投稿できる**（書き出して別アプリに移す手間がない）
- 投稿後の**分析がアプリ内**で見られる
- Metaのアプリなので、音源と仕様がリールに合っている

### 次点: CapCut

機能もテンプレートも多い。ただし**ByteDance製**で、Metaに出す前提だと
音源の扱いなどで詰まることがある。**Editsで足りなくなったら**移る。

### 「バズらせる」について

道具では決まらない。そして**バズはこの事業の目的ではない。**

リールが10万回再生されても、見ているのが全国の人なら、
**小平の子育て世帯は1人も増えない。**欲しいのは花小金井から30分の人だけ。

狙うのは**地元に刺さること**。効くのはこの3つ。

1. **最初の1.5秒で地名を出す**（「西東京の多摩六都科学館」）
2. **実用情報を1つ入れる**（ベビーカーはプラネタリウムに入れない）
3. **ハッシュタグを地名中心に**（#西東京市 #小平 #花小金井 など）。**ただし5つまで**（§4）

### 🔴 同じ素材を Threads にも出す

**これがいちばん効く。**Threadsは動画を出せて、しかも**実際に人が来ている経路**
（2026-09-03〜10 の1週間で10件。（未知）を除けば最大）。
**1回撮ったものを2か所に出すだけ。**手間は増えず、届く可能性は上がる。

🔴 **2026-09-12に実際に両方へ出した結果は §9。**
「Threadsのほうが効く」は**半分だけ当たっていた**。2つは競合ではなく、**役割が違う**ことが分かった。

### 🔴 ここから分かったこと（次の1本はこれで作る）

**① 2つは役割が違う。両方出す理由がはっきりした。**

| | 誰に届くか | 何が起きたか |
|---|---|---|
| **Instagram リール** | **知らない人**（フォロワー以外99.2%） | **出会う**。ただし5秒で離脱し、フォロー0 |
| **Threads** | 既存のつながり（ホーム92%） | **動かす**。プロフィール遷移12を生んだ |

Instagram を「まだ効いていない」と切らない。**新規と出会えているのは Instagram だけ。**
Threads は出会いを作っていない（ホーム92%）。**どちらか一方では回らない。**

**② 届け先は合っている。中身の前半だけが合っていない。**
25〜44歳が約78%、女性84%。**未就学児・小学生の親そのもの。**
狙ってこの層に届いているのに、**5秒で帰られている。**直すのは配信でも題材でもなく、**冒頭**。

**③ 損をしたのは「冒頭の画」ではなく、「カバー」だった。**

冒頭は**外観を下から上へ見上げるティルトアップで、サイエンスエッグ（ドーム）まで振り切っている**。
🔴 **これは強いカットで、冒頭に置いていて正しい。**ドームは形が特徴的なので、
初見の人にも「知らない建物」ではなく「なんだこれ」として届く。**差し替える必要はない。**

🔴 **問題はカバーが、そのティルトのいちばん下＝地面のフレームで止まっていたこと。**
Editsでカバーを選ばずに投稿すると先頭フレームが使われる。つまり
**いちばん強い1枚（ドーム）が動画の中にありながら、一覧には草と敷石が並んでいた。**
本編に動きがあっても、**一覧に出るのは静止画1枚**なので、ここは動きでは救えない。

**次回、まずこれをやる**（コストゼロで、効きがいちばん大きい）:

1. 🔴 **カバーを手で指定する。**自動に任せない。**ティルトが振り切った先＝ドームのフレーム**を選ぶ
2. **ティルトの下1秒を切って、早くドームに着かせる。**地面を見せている時間が短いほどよい
3. **ドームが出たところに数字を乗せる。**§4のとおり数字は強く、§1〜§2で裏が取れている
   （例：**ドームは27.5m 世界最大級** / **星は1億4000万個**）。
   初見の人に「何の施設か」を0.5秒で渡せる
