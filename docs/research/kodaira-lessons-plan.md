## 1. 何を知りたいか（決めたいことから逆に）

| 決めたいこと | 知りたい数字 |
|---|---|
| 毎週の通信（年齢別ページ）に習い事を入れる価値があるか | **日付のある体験会・説明会・季節の講座**が、ひと月に何件あるか（＝毎週の素材の量） |
| 「通信を見た」で入会金無料などの特典が成り立つか（成果報酬の形） | **入会金がある教室の割合**と金額／入会キャンペーンをやっている割合 |
| 教室にとって困りごとがあるか（営業の言葉） | **募集中**の割合／**見つけてもらいにくい**割合（Instagramだけ・ポータルに出ていない・更新が古い） |
| いつでも探せるガイド（ポータル）の価値 | 体験が**いつでもできる**割合／子連れの条件（曜日・時間・送迎・きょうだい）が公式に書いてある割合 |
| どの教室から話を聞くか | 個人で、募集中で、発信が弱い教室 |

**ポータルへ舵を切るかは、教室の数字だけでは決めない**。読者の側の数字（カフェ情報のページ・スクールガイドのページが見られた数、アンケート）と合わせて決める。
いまの形（LINE＝毎週の入口、ホームページ＝中身）は、もともとポータル寄り。問いは「どちらに手間をかけるか」

## 2. 何を「個人の教室」とするか（4つのAIで同じ定義）

- 小平市内で、子ども（0〜12歳）向けの、**民間の有料の**習い事
- **先生が1〜数人・教室が1〜2か所**（自宅・貸しスペース・公共施設を借りる・自分の小さな教室）
- 全国チェーンの直営は**除く**。公文・学研など**フランチャイズを個人が開いている教室は「フランチャイズ（個人運営）」として分けて**入れる
- 公民館のサークル・市の講座・市の委託は除く

## 3. 1教室ごとに取ること（タブ「教室しらべ」の列）

教室の名前／ジャンル／教室の形（自宅・貸しスペース・公共施設／自分の教室／フランチャイズ（個人運営）／不明）／場所（町名・最寄り駅）／対象年齢／**入会金**（〇円・なし・不明）／月謝の目安／そのほかの費用（教材費・年会費・施設費）／**体験**（無料・有料・見学のみ・なし・不明）／**日付のある体験会・説明会**（ここ3か月で見た日付）／季節の講座・発表会／**入会キャンペーン**／**募集の様子**（募集中・空き少し・満員・不明）／子連れの条件（曜日と時間・送迎・きょうだい・駐車場・ベビーカー）／発信している場所（ホームページ・Instagram・LINE公式・X・ポータル名）／最後の更新／出典URL／見つけた人（Claude・Gemini・Muse・Grok）／Claudeの確認（公式で確認・一部確認・未確認・対象外）／メモ

- 「不明」は「無い」と分けて数える（不明が多いこと自体が、見つけにくさの数字になる）
- 見ていないことは書かない。数字は公式（教室のホームページ・Instagram・ポータルの教室ページ）に書いてあるものだけ

### 決めたいことごとの数字と、Claude の考え

1. **毎週の通信に入れる価値**
   - 会員以外も参加できる日付つきの催し（季節の講座・体験会）が2026年に書いてあったのは **14か所**（これから 7・終わった 7）
   - これからの7つ: ミュウテックのクリスマス工作／なつやすみの年末年始の親子料理／田中書道の書き初め（締切済み）／玉川習字の書き初め体験 12/28（申込は12月1日8時から先着。サイトの「12/1(月)」は曜日が合わない）／Colorato のリトミック体験 12/10／アトリエぽっけのクリスマス会（会員以外も）／BE studio の国語の体験（締切済み）
   - → **ひと月に2〜4件**。12月（クリスマス・書き初め）と2〜4月（春の入会・体験会）に寄る。毎号の柱にはならない。**年齢別ページに1枠**なら、この2つの時期は埋まる
2. **「通信を見た」で入会金無料（成果報酬の形）**
   - 入会キャンペーンがある: 分かっている60か所のうち **20か所（33%）**。期間限定 6（秋・春の入会金半額など）／**体験したその日の入会で入会金や体験料が無料 7**／いつもの割引 6（きょうだい・初月無料・SNSフォロー）／内容不明 1
   - → 入会金を値引きに使う教室は多い。「通信を見た」で入会金無料は、教室がいつもしていることの延長なので頼みやすい
   - → 読者にとっての良さは「**その日に決めなくても**入会金が無料」。体験の当日に入会をせかされない形で、通信のトーンにも合う
   - → 紹介料1万円は、入会金の中央値（5,000円）の2倍、月謝（ざっと見て多くが月5,000〜10,000円）の1〜2か月分。先生1人の教室には重いかもしれない。**入会金と同じくらい（5,000円前後）**のほうが話しやすい
3. **教室の困りごと（話を聞くときの言葉）**
   - 募集の様子が外から分からない: **41か所（51%）**。分かる40か所は 募集中 28・空き少し 8・満員/募集終了 4
   - 自前のホームページが無い: ポータルの教室ページだけ 8・SNSだけ 7・看板だけ 1（計16・20%）。集め方がウェブ中心なので、SNSだけの教室は少なく出ている（Muse が拾った Instagram の教室は、7つのうち6つを開けず確かめられなかった）
   - 最後の更新: 2026年 47・2025年 3・2024年以前 11・分からない 20
   - → 「空きがあるか」「いつ体験できるか」を書いていない教室が半分。**そこを確かめて1行で載せる**ことが、教室にも親にも役に立つ
4. **ポータルへ舵を切るか**
   - 教室の数はある: ウェブで見つかるだけで81（看板だけの教室もあるので、実際はもっと多い）
   - コドモブースター（小平 358件）の1ページ目20件はほぼチェーン。81のうちコドモブースターに載っているのを見かけたのは4か所（全部は照らし合わせていない。2ページ目から先は機械では開けない）
   - ただし、ポータルは**中身を新しく保つ手間**が大きい（半分は空きが分からず、更新が古いか分からない教室が4割弱）。並べるだけなら「静かな一覧」になり、コドモブースターと同じ土俵になる
   - → **いまは舵を切らない。通信が入口のまま、ホームページに「習い事」のページを1つ足す**（ジャンル別・年齢別。体験・入会金・子連れの条件だけ）。毎週の号からは、日付のある催しがあるときにそのページへ案内する。見られた数で次を決める
   - → 理由: ポータルが回るには読者の数が要る（いまは約230家庭）。読者を連れてくるのは毎週の通信。順番は「通信で読者を増やす → 習い事のページが見られる → 教室に成果報酬の話ができる」
5. **話を聞く教室の候補**（個人・募集中・新しい。売り込まずに `docs/school-guide-brainstorm.md`「次に確かめたいこと」を聞く）
   - 小平駅南口 トリスタンピアノ教室（2026年7月にホームページ開設・募集中）
   - フィットネス＆ダンススタジオ ゆいベリ（2024年9月開業・募集中・体験の当日入会で入会金無料）
   - JPCスポーツ教室 小平店（フランチャイズの個人運営・12/5から土曜午後クラス）
   - ほかに、すでに付き合いのあるミュウテック（Threads から7回・申込0、は聞けている）
