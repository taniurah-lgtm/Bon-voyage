## 1. 何を知りたいか（決めたいことから逆に）

| 決めたいこと | 知りたい数字 |
|---|---|
| 毎週の通信（年齢別ページ）に習い事を入れる価値があるか | **日付のある体験会・説明会・季節の講座**が、ひと月に何件あるか（＝毎週の素材の量） |
| 「通信を見た」で入会金無料などの特典が成り立つか（成果報酬の形） | **入会金がある教室の割合**と金額／入会キャンペーンをやっている割合 |
| 教室にとって困りごとがあるか（営業の言葉） | **募集中**の割合／**見つけてもらいにくい**割合（Instagramだけ・ポータルに出ていない・更新が古い） |
| いつでも探せるガイド（ポータル）の価値 | 体験が**いつでもできる**割合／子連れの条件（曜日・時間・送迎・きょうだい）が公式に書いてある割合 |
| どの教室から話を聞くか | 個人で、募集中で、発信が弱い教室 |

**ポータルへ舵を切るかは、教室の数字だけでは決めない**。読者の側の数字（カフェ情報のページ・スクールガイドのページが見られた数、アンケート）と合わせて決める。
いまの形（LINE＝毎週の入口、ホームページ＝中身）は、もともとポータル寄り。問いは「どちらに手間をかけるか」

## 2. 何を「個人の教室」とするか（4つのAIで同じ定義）

- 小平市内で、子ども（0〜12歳）向けの、**民間の有料の**習い事
- **先生が1〜数人・教室が1〜2か所**（自宅・貸しスペース・公共施設を借りる・自分の小さな教室）
- 全国チェーンの直営は**除く**。公文・学研など**フランチャイズを個人が開いている教室は「フランチャイズ（個人運営）」として分けて**入れる
- 公民館のサークル・市の講座・市の委託は除く

## 3. 1教室ごとに取ること（タブ「教室しらべ」の列）

教室の名前／ジャンル／教室の形（自宅・貸しスペース・公共施設／自分の教室／フランチャイズ（個人運営）／不明）／場所（町名・最寄り駅）／対象年齢／**入会金**（〇円・なし・不明）／月謝の目安／そのほかの費用（教材費・年会費・施設費）／**体験**（無料・有料・見学のみ・なし・不明）／**日付のある体験会・説明会**（ここ3か月で見た日付）／季節の講座・発表会／**入会キャンペーン**／**募集の様子**（募集中・空き少し・満員・不明）／子連れの条件（曜日と時間・送迎・きょうだい・駐車場・ベビーカー）／発信している場所（ホームページ・Instagram・LINE公式・X・ポータル名）／最後の更新／出典URL／見つけた人（Claude・Gemini・Muse・Grok）／Claudeの確認（公式で確認・一部確認・未確認・対象外）／メモ

- 「不明」は「無い」と分けて数える（不明が多いこと自体が、見つけにくさの数字になる）
- 見ていないことは書かない。数字は公式（教室のホームページ・Instagram・ポータルの教室ページ）に書いてあるものだけ
