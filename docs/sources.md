# 巡回先ソース・レジストリ(検証済み)

無料通信の2本柱 **「今週の一推し」×「知らないと損カレンダー」** を支える情報源の台帳。
各ソースは実在確認済み(2026-07時点)。巡回時はここを起点に回す。

## 取得方式の前提(重要)

- **WebSearch(検索)が主**。多摩六都のプラネタリウム番組名・実験日程まで検索結果に出る。
- **WebFetch(URL直取り)は従**。イオン・多摩六都・東京都サイトは**直取りが403で弾かれる**(ボット対策)。
  施設公式は「検索で拾う → 公式URLは裏取り・掲載用リンクとして残す」運用にする。
- **アグリゲータ(いこーよ/ウォーカープラス/tokubai/映画.com 等)** は直取りが通りやすくフォールバックに使える。
- 日付・料金は必ず公式で裏取り。未確定は「(要確認)」を付す(運用ルール準拠)。

## 凡例

- 取得: 🔍WebSearch主 / 📄WebFetch可 / 📰RSS
- 頻度: **毎回**(水・土の巡回で必ず) / 季節(連休・長期休暇前に厚く) / 補助(必要時)
- 柱: 推=今週の一推し / 損=知らないと損カレンダー

### 子連れ上映の日程を自動取得する設計(月次ニュース対策)
公式ページは直取り403だが、**検索エンジンは月次ニュースをインデックスする**。これを使う:

1. **タイミング**: 各劇場は翌月分を**毎月中旬**に更新。→ 月中旬の巡回(第2水曜など)で「映画・子連れ上映チェック」を1回走らせる。
2. **取得(WebSearch主)**: 対象館×プログラムで検索を叩く。
   - `げんきッズシアター 〔翌月〕 むさし村山 上映作品`
   - `ママズクラブシアター 〔翌月〕 〔近隣TOHO館〕 開催日`
   - `T・ジョイ大泉 赤ちゃん 上映 〔翌月〕`
3. **裏取り(📄が通る先)**: 映画.com / ジョルダン「映画の時間」/ ぴあ / いこーよ / mamari 等の特別上映情報で日付をクロスチェック。
4. **掲載ルール**: 日付＋作品が**確定した分だけ**通信に載せる。未確定は日付を書かず、劇場ニュースURLの案内に留める(運用ルール「未確定は載せない」準拠)。
5. **記録**: 確定分は台帳(events/当月)に「映画・子連れ上映」として起票し、次回以降流用する。
