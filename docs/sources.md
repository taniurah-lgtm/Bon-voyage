### 市報こだいらの正は「小平市公式のPDF」

マイ広報紙に記事のテキスト転載はあるが、**機械からは安定して取れない**。
市報を裏取りするときは必ず公式へ。

- 一覧: https://www.city.kodaira.tokyo.jp/shihou/
- 各号の目次ページから**PDF**がリンクされている
- **毎月5日・20日発行**

```bash
# 目次ページから号のPDFリンクを拾う(1号あたり8本前後。att_XXXXXXX.pdf の通し番号)
curl -sL "https://www.city.kodaira.tokyo.jp/shihou/" | grep -o 'href="/shihou/[0-9]*/[0-9]*\.html"'
curl -sL "<各号の目次ページ>" | grep -o 'href="[^"]*\.pdf"'
# 先頭の att_0000138.pdf 相当が「全ページ合本」(7ページ・約4MB)。これ1本で足りる
curl -sL "https://www.city.kodaira.tokyo.jp/shihou/files/<ID>/<ID>/att_0000138.pdf" -o shihou.pdf
pdftotext -layout shihou.pdf -
```

> ✅ **検証済み(2026-08-15、第1661号で実施): テキスト層あり。スクショ不要。**
> 合本7ページから約73,000字が抽出でき、日付・締切・定員・電話番号まで取れた。
> **月2回のスクリーンショット依頼は、市報については廃止してよい**(田無アスタは引き続き必要)。

**取得時の注意(実際に踏んだもの)**:

- **`poppler-data` を必ず入れる**。無いと `Missing language pack for 'Adobe-Japan1'` が大量に出て
  文字が欠ける(第1661号で約300字の欠落)。入れるとエラーゼロになる。
  `apt-get update && apt-get install -y poppler-utils poppler-data`
- **抽出モードを使い分ける**。市報は横組みと**縦組み**が混在し、1つのモードでは記事が壊れる。
  - `-raw`: 横組みの講座一覧(公民館・スポーツ欄)に最適。**縦組みページは記事ごと落ちる**ことがある
    (第1661号では4面の「こだいら防災救急フェア」が `-raw` で完全に消えた)。
  - `-layout`: 2段組みの左右が混ざる。**隣の記事の締切を拾う事故が起きる**ので、必ず係り受けを確認する。
  - **縦組みページは `-bbox` で座標から組み直す**のが唯一確実。単語のxMaxで列を作り、
    列を右→左、列内はyMin昇順で連結する。4面・7面はこれが必要。
- **記事の区切りは座標で判断する**。フィールド記号(`d`日時 / `b`場所 / `t`対象 / `c`定員 /
  `m`申込 / `i`問合せ / `s`費用 / `k`講師 / `n`内容)が記事の切れ目の目印になる。

## 取得方式の前提(重要)

### 取り方の順番 — 必ずこの順で試す

1. **個別ページ・詳細ページ** … 一覧が画像でも、詳細はHTMLのことが多い
2. **PDF** … `pdftotext`(下記)。市報・チラシ・月次カレンダーはここに落ちている
3. **別の一覧** … お知らせ / 新着 / アーカイブ / 月次カレンダー
4. **WebSearch** … URLが分からない、1〜3が全滅
5. **画像として読む** … **最後の手段**。`確度: 未検証` を必ず付ける

> ❌ **2026-08 の失敗**: 田無アスタの月次スケジュールが画像だったので
> 「このサイトはWebに文字が無い」と結論した。**誤りだった。**`asta.co.jp/event/` に
> イベント名・日時・場所が本文テキストで載っていた。**一覧しか見なかったのが原因。**
> 「このサイトは読めない」と書く前に、**1〜4を全部試したか自問する。**

### 骨格は本文テキスト、細部は画像で補う

イベント名・日時・場所は本文に載っていることが多いが、
**参加費・定員・対象年齢はチラシPDF(画像)にしかない**ことがある。
本文で骨格を取り、足りない項目だけ画像で埋める。

### 値が食い違ったら「新しい方・詳細な方」を正とする

同じイベントが複数経路に載っていて内容が違うことがある。
- 例: 7月発行の夏休みカレンダーPDF = 11:00 / 現在の `/event/` = 10:00 → **後者が正**
- **月次カレンダーやチラシは、発行後に変更される。**詳細ページを優先する。

### 「無料」と書く前に、費用を必ず確認する

無料版レポートは「無料・格安を上位に」が方針なので、
費用の誤りは**読者が実際にお金を払う**実害になる。

> ❌ **2026-08 の失敗**: 「田無アスタ2Fセンターコートは入場無料が基本」と書いていたが、
> 8月は 800円 / 500円 / 300円 と**有料が過半**だった。

### 取れなかったソースを、巡回レポートに残す

「巡回設定はあるのに毎回0件」を検出できないと、**静かに落ち続ける**。

> ❌ **2026-08 の失敗**: 田無アスタは「毎回」設定で**毎月0件**だったが、誰も気づかなかった。

0件だったソースは、巡回のたびに1行だけでも記録する。

### PDFの読み方

```bash
# poppler-data が無いと Adobe-Japan1 の言語パック不足で文字が落ちる(市報で約300字欠落した)
apt-get install -y poppler-utils poppler-data

pdftotext -layout doc.pdf -    # 横組み。ただし2段組みは左右が混ざり、隣の記事の締切を拾う事故が起きる
pdftotext -bbox   doc.pdf -    # 縦組み。座標から組み直す。市報の縦組みページはこれが唯一確実
```

**`-raw` 単独は使わない。** 記事ごと消えることがある(市報4面の防災救急フェアが消えた)。

#### ⚠️ 判定は「ステータスコード」でなく「本文」で行う

**この再検証で実際に踏んだ罠**: `www.aeon.jp` は `curl -w '%{http_code}'` が **200 を返すのに、
本文はAkamaiの `Access Denied` ページ**だった。コードだけ見て「解消した」と誤判定しかけた。

```bash
# ❌ これだけでは判定できない
curl -sS -o /dev/null -w '%{http_code}\n' "$URL"

# ✅ 本文に遮断ページの署名が無いかまで見る
body=$(curl -sS -m 25 -L "$URL")
printf '%s' "$body" | grep -qiE 'Access Denied|Request blocked|you have been blocked|Attention Required|errors\.edgesuite' \
  && echo BLOCKED || echo OK
```

遮断ページは**本文が極端に小さい**(数百バイト〜5KB程度)のも目印になる。

### 小平市 公民館の講座一覧 — 「>>◯月◯日より詳細がご覧いただけます」を必ず読む

一覧: https://www.city.kodaira.tokyo.jp/kurashi/043/043741.html (📄 直取り可・JS不要)

市内10館(中央/花小金井南/**花小金井北**/小川/小川西町/上宿/上水南/鈴木/仲町=なかまちテラス/大沼/津田)の

各行は必ずこの3行セットになっている:

```
花小金井北公民館　子育て支援講座　親子でトントン 引き出し付き小物入れづくり
申込期限　8月19日まで
>>7月18日より詳細がご覧いただけます。
```

- ⚠️ **3行目が判断の要。** 「>>◯月◯日より詳細がご覧いただけます。」は
  **個別ページの公開日**を告げている。**その日を過ぎていれば個別ページは必ず存在する。**
  末尾に「(コンテンツは未公開です)」が併記されているときだけ、本当に未公開。
- 1行目の一覧テキストには**開催日が載らない**(載るのは申込期限だけ)。
  **開催日・時間・費用・対象・定員・持ち物・電話番号は個別ページにしかない。**
  つまり **一覧だけ見て「詳細は未公表」と書くのは必ず誤りになる。**
- 個別ページのURLは `/event/128/128696.html` の形。一覧のHTMLから `href` を拾う:

```bash
curl -sSL "https://www.city.kodaira.tokyo.jp/kurashi/043/043741.html" -o /tmp/kmk.html
python3 -c "
import re,sys
s=open('/tmp/kmk.html',encoding='utf-8').read()
i=s.find('親子でトントン')          # 講座名で位置を出す
print(re.findall(r'href=\"([^\"]+)\"', s[i:i+1200])[:2])
"
```

- 個別ページで必ず拾う項目: **開催日 / とき(第1回・第2回の別) / 場所(＋エレベーター有無)
  / 費用 / 対象(学年まで) / 定員 / 保育の有無と月齢条件 / 申込方法と締切 / 抽選か先着か / 電話番号**
- 一覧は**申込期限の降順**に並ぶ。終了分も残るので、**期限が今日より前のものは 終了 として台帳に落とす**。
- 「◯◯公民館まつり」「友・遊こどもまつり」など**申込不要の大型行事**は
  `申込期限` ではなく `開催日　◯月◯日` と書かれている。**これが無料版の一推しになりやすい**ので見落とさない。
