# 郵送とメールだけの営業（2026-11-16〜・内部用・非公開）

> 「日中忙しすぎて、なかなか営業回りが出来ていません」「郵送タイプで営業資料を作成してください。とにかくメールと郵送だけで、営業しまくります。郵送料はなるべく安くしたい」（オーナー・2026-11-16）

**電話も訪問もしない。**最初の連絡はメールか郵送で、返事は**メールかLINE**で受ける。会うのは、相手が会いたいと言ったときだけ。
- 🆕 **2026-11-16 メールを使わない相手のために、お手紙に「LINEでお返事」のQRを足した**（通信の公式LINE。友だち追加してトークに書いてもらう。チャットはオン・夜か週末に返す）。お手紙の電話番号は、オーナーが決めるまで載せない（載せるなら私用の携帯ではなく、留守番電話つきの050番号などを検討）

## 1. どれで送るか（安い順）

| 手段 | 1通 | 使う先 | 決まり |
|---|---|---|---|
| **メール・問い合わせフォーム・Instagram の DM** | 0円 | 公開の連絡先がある先（`docs/sponsor-apo.md`「電話なしで連絡できる先」） | 🔴 メールは**サイトに公開している事業用アドレスだけ**。本文に送り主の名前・連絡先・「不要ならこのメールに返信を」を書く（特定電子メール法）。フォームに「営業お断り」とあれば使わない。下書きは Claude、送るのはオーナー |
| **封書（長4封筒・定形）** | **110円** | 窓口がネットに無い先・チラシを同封したい先 | 50gまで110円（日本郵便の料金表）。お手紙1枚＋チラシ5部＋封筒で約30g。厚さ1cmまで |
| はがき | 85円 | 一度送った先への**ひとことだけ**（お礼・その後のご案内） | チラシも資料も入らない。最初の1通には使わない |
| ミニレター（郵便書簡） | 85円 | 使わない | 25gまで・入るのは薄いものだけ。A4のお手紙とチラシが入らない |

- いちばん効く節約は**メールで済む先をメールにすること**（0円）。郵送は「ネットに窓口がない先」だけ
- 封書はまとめて出す。切手を貼る手間を省くなら**料金別納**（同じ料金のものを10通以上・別納の印を封筒に刷る。料金は変わらない）
- 封筒は長4（B5のお手紙とB5のチラシを三つ折りで。白・100枚で数百円）。宛名は**B5 の紙に12面**（1枚 86×40mm・薄い点線つき）で刷り、点線で切ってのりで貼る（2026-11-16 オーナー「ラベルはB5サイズで」）。A4 の市販ラベル（エーワン 28721）に刷るときは `--label a4`
- 郵便料金は2027年度内に値上げの見込みという報道がある（公式では未確認）。変わったら上の表を直す

## 2. 刷り方（1便ごと）

1. **Claude が送り先の一覧を作る**: `data/kyosan-mail/<日付>.json`。Notion の2つのアポリスト（協賛・チラシ）から選び、**郵便番号は町名から引いて確かめる**（下）
2. `node scripts/make-kyosan-mail.mjs --list data/kyosan-mail/<日付>.json --out <scratchpad の出力フォルダ>`
   - `letters-b5.pdf`（**お手紙・すべてB5**）・`labels.pdf`（宛名ラベル）・`checklist.txt`（同封物と切手）ができる
   - 封筒の裏の差出人ラベルが要るときだけ `--from "差出人の文字"`（🔒 住所はリポジトリに書かない。渡すだけ）
   - 止まるとき: 宛名・郵便番号の欠け／携帯番号／**チラシのお願いにお金の話**／評価の言葉／**お手紙が1枚に収まらない**
3. **オーナー**: B5 の紙に刷る → 三つ折り → **B5のチラシ**（`flyer-b5.pdf`・三つ折り）と一緒に**長4封筒**（9×20.5cm）へ → ラベル → 110円切手 → ポストへ（長4も定形で110円）
4. 送ったら Claude に「送った」→ Notion の状態「資料を渡した」・最終連絡を今日に

## 3. お手紙の型（`docs/print/kyosan/mail-letter.html`）

| type | 何の手紙か | 中身 |
|---|---|---|
| `shokai` | 紹介型（1回3,000円） | 日付のある催しがある先（習い事の体験会・ワークショップ・節句の催し）。`alsoOuen: true` で応援型も1行添える |
| `ouen` | 応援型（年1万円） | 名前を知ってほしい業種（不動産・整体・保険・写真館） |
| `chirashi` | チラシを置いていただくお願い | **お金・協賛の話は一切書かない**（医療機関・園・商店会）。チラシ5部を同封。補充は郵送で |

- どの型も**B5**の片面1枚（2026-11-16 オーナー「協賛の手紙はB5に」「チラシもB5に統一しているので、A4版は不要」）。**協賛の手紙は左下に丸いロゴ**（`docs/print/logo/logo-color-clear.png`・オーナー）。**読者の数字（3つ）**・**お便りした理由（2〜3行・送り先ごと）**・**お返事はメールかLINEで**
  - B5 は文字を詰めてある（本文 8.3〜8.5pt）。理由を4行以上にすると1枚からあふれて、スクリプトが止まる
- 🆕 **2026-11-16 オーナー**: 敬称は「さま」でなく**「様」**。**金額は強調しない**（大きな字・表のいちばん上をやめ、表の下のほうの「掲載料」の行に普通の字で。消しはしない＝QRの先の案内ページに金額があり、知らずに会うと気まずくなるため）。
  協賛の型の締めは「**詳しくご説明に伺います（メールやLINEでのご説明もできます）**」を残す（「お電話しません」「破棄してください」は消した）。伺うのは**相手から返事があった先だけ**
- 協賛の型は右下に `/kyosan/` のQR（掲載イメージと申込書）
- 🆕 **2026-11-16 営業の見直し**（オーナー「『ご協賛』と書いて依頼来ますかね？ 向こうにイニシアティブがある見出し・書き出しに。人は上から読むので、興味のある順・需要のある順に」→ 営業の目でチェックして作り直した）
  - **見出しは相手の得**（「〜のご案内」で始めない）。型の既定と、送り先ごとの `headline`（`\n` で改行）:
    - 応援型「小平の子育て家庭に毎週届く通信のページに、お店のお名前を載せませんか」
    - 紹介型「体験会の日を、その年齢のお子さんがいるご家庭に届けませんか」
    - チラシ「（`place`）に、小平の子育て家庭向けの無料チラシを置かせていただけませんか」
  - **書き出しは「なぜあなたに」の1文**（`opening`。例: 「こだキッズタウンのチラシの協賛欄でお名前を拝見して」「1〜3月の住みかえの時期を前に」）→ そのあとに通信の自己紹介（共通）
  - **上からの並び**: 協賛＝見出し → 書き出し → 数字3つ → お便りした理由（2〜3行）→ 載せ方と掲載料 → 締め／チラシ＝見出し → 書き出し → **お願い（負担がないことを先に）**→ 数字3つ → 締め
  - **数字は型ごとに相手に近い3つ**（`NUMS`）: 応援型＝花小金井駅11人・226人・23館／紹介型＝習い事9人・14〜20%・226人／チラシ＝23館・226人・11人。アンケートは「答えた17人のうち」と母数をつける
  - **締めは、返事の手間を一言に**: 応援型「『話を聞きたい』とだけ」／紹介型「体験会の日にちだけ。紹介文の案を作ってお見せします。載せるかは仕上がりを見てから」／チラシ「『置きました』とだけ。置けない場合はお返事不要」
  - 営業の指摘のうち採らなかったもの: 「毎週開く」（開くのは届いた人の14〜20%。「毎週届く」と書く）・見出しに金額（金額は表の中のまま）・敬称「さん」（様のまま）
  - チラシのお願いは字を大きく（`roomy`。待合室・お店の方向け）
  - 🆕 **見出しの下の1行（サブタイトル）は置かない**。宛先を下げ、見出しの前後に余白をとって、見出しだけが目に入るようにする（オーナー「下に余白があるので宛先をもう少し下」「見出しの前後に余白を」）
  - 🆕 **1業種1社は、見出しにも「いま空いています」にも書かない**（オーナー「サブタイトルに1業種1件とか書かなくていい」「そもそも書く必要ありますか？」）。
    応援型だけ、表の「枠」の行に**相手の得として1行**（「同じ業種のお店は、ほかに載せません（協賛は全体で7社まで）」＝同業の隣に並ばない・名前が埋もれない）。
    紹介型は「枠」の行ごと消した（1号に1件・同じ月に同じ業種1件は、相手が申し込むときにこちらが調整する話）。「いま空いています」は急かす言い方なので使わない。決まりそのもの（`docs/sponsor-plan.md`）は変えない
- 送り先ごとに変えるのは「見出し・書き出し・お便りした理由」。**確かめた事実だけ**（相手がどこに広告を出しているか、アンケートの数字など）。評価の言葉・推測・煽り（おすすめ・今だけ・お得 など）は書かない（スクリプトが止める）
- 🆕 **数字（2026-11-16 差し替え）**: オーナー「強い数字だけで勝負したい」「17人だと、アンケート答えた人少ねえ、とならないか」「チラシは幼稚園や多摩六都にも置いていて、23どころじゃない」
  - **233人**（毎週水曜にLINEで届いている人数＝LINE公式の「配信できる友だち」11/16）／**3.5倍**（9月はじめ66人から）／**62.5%**（10/28号の開封率。200人に届き125人が開封）／**32%**（10/28号・開いた人のうちリンクを押した人＝40人）／**40か所以上**（チラシ設置）
  - 型ごと（`NUMS`）: 応援型＝233人・3.5倍・62.5%・40か所以上／紹介型＝233人・62.5%・32%・3.5倍（届く→開く→ページへ、の順）／チラシ＝40か所以上・233人・3.5倍
  - **アンケートの数字（17人中〇人）は大きく出さない**。理由の文に「アンケートでも〇〇が多かった」と、母数をつけずに書くのはよい（「いちばん」は確かめていないので書かない）
  - 40か所の内訳（Notion のチラシのアポリストで「置けた」「郵送で継続」・11/16）: 地域センター＋元気村20・児童館3・あすぴあ・おひさまひろば・ルネこだいら・花小金井南公民館・多摩六都科学館・こだいら観光まちづくり協会・幼稚園とこども園7（弥生台・みどり・白梅・神明・花小金井幼稚園・ひめゆり・あおば＝4園は11/16 オーナー「郵送している」）・お店4（しゅしゅ・ロースターズクラブ・かぶとパン・ビッグ・エー＝ポスター）。🔴 **ちょうど40**。置き先が減ったら「40か所以上」は使えない（「40か所近く」に戻す）

## 4. 送る順番の決まり（`docs/sponsor-apo.md` と同じ）

- **応援型は1業種1社**。郵送でも、同じ業種には同時に出さない。1番手に送って**2週間返事がなければ**2番手へ（「ご不要なら破棄を」と書いているので、催促はしない）
- **医療・園はチラシが先**（`chirashi` 型）。置いてもらえたら、次の補充のときに院長あての協賛の資料
- **無料で載せたばかりの先には送らない**（子連れカフェ8軒・花小金井陶芸教室など）。お礼だけ
- 催しの主催者（マルシェ・夜市・キッズタウン）には協賛の手紙を送らない
