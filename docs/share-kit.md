## 5. 有料会員へのご案内(会員ページ動線)

有料(note メンバーシップ)に参加した人へ、**会員ページURL＋合言葉**を届ける導線。
合言葉は公開の通信には載せず、**note のメンバー限定投稿**か **LINE 1:1** で渡す(課金者だけが知れる)。
※合言葉の現在値はリポジトリに書かない(オーナーが管理)。変更は Claude に「合言葉を◯◯に」で再ビルド。

（気になった予定をワンタップでご自分のカレンダーに追加できます）や、
これから育てる「みんなの投稿マップ」（準備中）をお届けします。

▼会員ページ

※合言葉はご本人限りでお使いください。

### 導線まとめ
1. ホームページ「応援する」→ note メンバーシップ(300円)に参加。
2. 参加者に **note メンバー限定投稿**（or LINE 1:1）で **会員ページURL＋合言葉**を渡す。
3. 会員ページで合言葉を入力 → おでかけカレンダー等が表示。
4. 身内は、同じ合言葉をオーナーが個別に伝える。
