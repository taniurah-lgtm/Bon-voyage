## 5. 有料会員へのご案内(会員ページ動線)

有料(note メンバーシップ)に参加した人へ、**会員ページURL＋合言葉**を届ける導線。
合言葉は公開の通信には載せず、**note のメンバー限定投稿**か **LINE 1:1** で渡す(課金者だけが知れる)。
※合言葉の現在値はリポジトリに書かない(オーナーが管理)。変更は Claude に「合言葉を◯◯に」で再ビルド。

### note メンバー限定投稿「会員ページのご案内」

```
これから育てる「みんなの投稿マップ」（準備中）をお届けします。

▼合言葉
```

### LINE 1:1 でのご案内（短め）

### 導線まとめ
1. ホームページ「応援する」→ note メンバーシップ(300円)に参加。
2. 参加者に **note メンバー限定投稿**（or LINE 1:1）で **会員ページURL＋合言葉**を渡す。
3. 会員ページで合言葉を入力 → おでかけカレンダー等が表示。
4. 身内は、同じ合言葉をオーナーが個別に伝える。

## 6. ジモティー（地元の無料掲示板）

地元の人が見る無料掲示板。1回投稿しておくと検索に残り、地味に効く入口になる。

### カテゴリ・地域
- **カテゴリ**: 「メンバー募集」→ 地域コミュニティ系（無ければ「イベント」でも可）。
- **地域**: 小平市（＋西東京市）を選ぶ。花小金井を含むエリアに。
- **画像**: `docs/homepage/assets/ig-story.png` か `flyer-a5.png` を添付すると目にとまりやすい。

### タイトル
```
【無料】花小金井まわり 週末おでかけ情報｜未就学〜小学生の家庭へ
```

### 本文
```
花小金井エリア（小平・西東京など）の、未就学児〜小学生のいるご家庭に向けて、
週末のおでかけ情報を無料でお届けしています🎈

■お届けする内容
・お祭り／花火／水あそび・プール
・雨の日の室内あそび・科学館
・電車でおでかけ（西武新宿線ぞい）
・連休のおでかけアイデア など
天気に合わせた「今週これ」を、地元目線でやさしくまとめています。

■費用
無料です（営利の勧誘ではありません）。

■受け取り方
まずはホームページからご覧いただけます。LINEの友だち追加で毎週おとどけ。
→ https://bonvoya.nicomaru.tokyo/f
友だち追加で「花小金井 子連れおでかけガイド」もプレゼント。

※おためし運用のため、予告なく内容が変わる場合があります。
```

### 投稿のコツ・勝ち筋
- **飛び先はホームページ（/f）に**。LINEの生リンク直貼りは掲示板でスパム扱いされやすいので、まずHPを見てもらう形にする（動線も統一済み）。
- **売り込まない・淡々と事実で**。無料・非営利・地域向けを前面に（`CLAUDE.md` のトーン方針どおり）。
- **消えたら/下がったら再投稿**。ジモティーは新しい投稿が上に来るので、月1回など軽く再掲すると露出が保てる。
- 反応は薄くても**無料で検索に残る資産**。掲示（①）やSNS（③）と合わせ技で。
