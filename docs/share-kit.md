## 5. 応答メッセージ（メッセージをいただいたときの自動返信）

LINE Official Account Manager → **ホーム → 応答メッセージ**。
**応答メッセージは無料枠の通数を消費しない**（配信数に数えられない）。

> ⚠️ 2026-09-04 まで、この文面の末尾に**月300円のサポーターへの案内**と
> `https://bonvoya.nicomaru.tokyo/#more` へのリンクが入っていた。
> 月額制度の廃止でそのページは無くなったので、**リンク切れのまま返信し続ける状態**だった。
> 下の文面に差し替えること。

```
メッセージをありがとうございます🎈

後ほどメッセージを確認させて頂きます☺️
情報の間違いは、すぐ直して次の通信に反映します。
おすすめの場所は「みんなのおでかけマップ」に加えさせていただきます。

▼ みんなのおでかけマップ
https://bonvoya.nicomaru.tokyo/map.html

始めて間もない小さな通信です。
「ここが良かった」「この情報がほしい」など送っていただけるほど、
中身が良くなっていきます。
お知り合いにも役に立ちそうでしたら、教えていただけるとうれしいです。

通信はこれからも無料でお届けします。
```

- **お金の話は入れない。**「応援」「サポーター」も書かない（`docs/strategy-2026-09.md`）
- 情報提供のお礼として**マップに載せる**ことを明示している。これが投稿を増やす導線になる
- 最後の1行は、読者からの「これ有料なの？」という迷いを先に消すためのもの

## 6. ジモティー（地元の無料掲示板）

地元の人が見る無料掲示板。1回投稿しておくと検索に残り、地味に効く入口になる。

### カテゴリ・地域
- **カテゴリ**: 「メンバー募集」→ 地域コミュニティ系（無ければ「イベント」でも可）。
- **地域**: 小平市（＋西東京市）を選ぶ。花小金井を含むエリアに。
- **画像**: `docs/homepage/assets/ig-story.png` か `flyer-a5.png` を添付すると目にとまりやすい。

### タイトル
```
【無料】花小金井まわり 週末おでかけ情報｜未就学〜小学生の家庭へ
```

### 本文
```
花小金井エリア（小平・西東京など）の、未就学児〜小学生のいるご家庭に向けて、
週末のおでかけ情報を無料でお届けしています🎈

■お届けする内容

■費用
無料です（営利の勧誘ではありません）。

■受け取り方
まずはホームページからご覧いただけます。LINEの友だち追加で毎週おとどけ。
→ https://bonvoya.nicomaru.tokyo/f

※おためし運用のため、予告なく内容が変わる場合があります。
```

### 投稿のコツ・勝ち筋
- **飛び先はホームページ（/f）に**。LINEの生リンク直貼りは掲示板でスパム扱いされやすいので、まずHPを見てもらう形にする（動線も統一済み）。
- **売り込まない・淡々と事実で**。無料・非営利・地域向けを前面に（`CLAUDE.md` のトーン方針どおり）。
- **消えたら/下がったら再投稿**。ジモティーは新しい投稿が上に来るので、月1回など軽く再掲すると露出が保てる。
- 反応は薄くても**無料で検索に残る資産**。掲示（①）やSNS（③）と合わせ技で。
