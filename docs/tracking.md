# どの配布先からLINE登録につながったかを測る

**目的**: チラシ・ポスターを置いた場所ごとに、実際に人が来たかを知る。
残り400枚をどこに置くかを、勘ではなく数字で決められるようにする。

**いまの状態**: 仕組みは用意済み。**GoatCounterのコードを1行入れるまで、数え始めません。**

## 2. 有効にする手順（5分・無料）

1. https://www.goatcounter.com/ で登録。**コード名を決める**（例 `bonvoya`）
2. `docs/homepage/assets/analytics.js` の `var SITE = '';` を `var SITE = 'bonvoya';` に書き換える
3. push。以後 `https://bonvoya.goatcounter.com` で見られる

**GoatCounterを選んだ理由**
- 無料（個人利用）
- **Cookieを使わず、訪問者を個人として追跡しない。**IPも保存しない設計
- **パスごとに集計する**ので `/f/rokuto` `/f/asupia` が別々の行で出る＝そのまま配布先の成績になる

> `SITE` が空のあいだは**スクリプトを1つも読み込まない＝どこにも通信しない。**
> 入れるまでは、これまでと何も変わらない。

## 3. 読み方

GoatCounterの画面で `/f/` で絞ると、配布先ごとの数字が並ぶ。

- **`/f/<場所>` の数 = QRを読んだ人**（＝チラシに反応した人）
- **`/` の数 = ホームページを見た人**
- **LINEの友だち数（`insight/followers` の targetedReaches）= 実際に登録した人**

この3つの差が、どこで人が離れているかを示す。

| 見え方 | 意味すること |
|---|---|
| QRは読まれるが登録が増えない | **ホームページで止まっている。**説明か導線の問題 |
| そもそもQRが読まれない | **チラシが見られていない。**置き場所か、紙面の訴求の問題 |
| 特定の場所だけ数字が出る | **そこに寄せる。**残りの部数の配分を変える |

## 4. 数字を見るときの注意

- **母数が小さい。**いま到達47人。3人と5人の差に意味は無い。**0か、二桁か**くらいの粒度で見る
- **同じ人が複数回読むことがある**（家で見返す等）。登録数と一致しなくて当然
- **紙は遅れて効く。**置いた翌日ではなく、2〜4週間で見る
- **「置いた日」を `docs/distribution.md` に必ず書く。**いつからの数字か分からないと比較できない

## 5. 外注するときの材料になる

ココナラ等で相談するなら、この3層の数字を渡すと話が具体になる。
**「友だちを増やしたい」ではなく「QRは読まれているのに登録に至らない」と言えるかどうか**で、
返ってくる助言の質が変わる。

## 4. 🔴 LINE自身が経路を計測できる（2026-09-08 判明）

**`分析 → 友だち → 追加経路`。**配布先ごとに友だち追加のQR／URLを発行しておくと、
**実際に登録した人数**が経路別に出る。

GoatCounter は「QRを読んで着地ページに来た人」まで。LINEは「**登録した人**」。
**登録まで見えるLINEのほうが本命。**両方あると「読んだのに登録しなかった」も分かる。

## 5. ホームページへの入口を読む（GoatCounter）

`https://bonvoya.goatcounter.com` ／ 期間を **2026-09-06〜今日** にする。

### Pages ＝ 入口の内訳

| パス | 何から来た人か | 状態 |
|---|---|---|
| **`/f`** | **すでに配った497枚のチラシ・ポスターのQR** | ⭕️ 読める |
| `/f/<場所>` | 配布先ごとのQR | ❌ **まだ0。この版は未印刷**（10月の刷り直しから） |
| `/` | 検索・直接・SNS・LINE | ⭕️ |
| `/calendar.html` `/map.html` `/ai/` | 中の道具 | ⭕️ |

**いちばん見たいのは `/f`。**これが「紙を見てQRを読んだ人」そのもの。

### 🔴 Top referrers だけ見ると誤読する

**QRからの流入は referrer が付かない。**必ず「direct（空欄）」に混ざる。
LINEアプリ内からのタップも同じ。
→ **紙の効果はパス（`/f`）で見る。**referrerが空でも紙が効いていないわけではない。

| 出方 | 意味 |
|---|---|
| `Google` | 検索から。**SEOが効き始めた合図** |
| `kodaira-shiminkatsudo-ctr.jp` | あすぴあのサイトから |
| `note.com` / `threads.net` | SNSのプロフィールから |
| (空欄・direct) | URL直打ち／ブックマーク／**QR**／アプリ内リンク |

### ⏳ 数字が少ないうちに結論を出さない

計測は **2026-09-06 開始**。最初の2日はオーナー自身のテスト。
**1〜2週間ためてから読む。**目安として `/f` が週5件出れば「紙は効いている」。

### 紙以外の入口を分ける（Campaigns）

いま note・Threads・メール署名からの流入が区別できない。
**プロフィールに置くURLを差し替えるだけ**で Campaigns に分かれて出る。

```
note      https://bonvoya.nicomaru.tokyo/?utm_campaign=note
Threads   https://bonvoya.nicomaru.tokyo/?utm_campaign=threads
X         https://bonvoya.nicomaru.tokyo/?utm_campaign=x
メール署名  https://bonvoya.nicomaru.tokyo/?utm_campaign=mail
```

- [ ] note のプロフィールを差し替えた
- [ ] Threads のプロフィールを差し替えた
- [ ] X のプロフィールを差し替えた
- [ ] メール署名を差し替えた
