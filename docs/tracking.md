# どの配布先からLINE登録につながったかを測る

**目的**: チラシ・ポスターを置いた場所ごとに、実際に人が来たかを知る。
残り400枚をどこに置くかを、勘ではなく数字で決められるようにする。

**いまの状態**: 仕組みは用意済み。**GoatCounterのコードを1行入れるまで、数え始めません。**

---

## 1. 仕掛け

配布先ごとに**URLだけが違う**ランディングページを用意した。読者から見える中身は同じ。

| 子ども家庭支援センター | `…/f/kodomo` | `f-kodomo.png` |
| 多摩六都科学館 | `…/f/rokuto` | `f-rokuto.png` |
| せいぶ通り商店会 | `…/f/seibu` | `f-seibu.png` |

- `/f/` は `robots.txt` で `Disallow`。検索には出ない（ランディングなので正しい）

## 2. 有効にする手順（5分・無料）

1. https://www.goatcounter.com/ で登録。**コード名を決める**（例 `bonvoya`）
2. `docs/homepage/assets/analytics.js` の `var SITE = '';` を `var SITE = 'bonvoya';` に書き換える
3. push。以後 `https://bonvoya.goatcounter.com` で見られる

**GoatCounterを選んだ理由**
- 無料（個人利用）
- **Cookieを使わず、訪問者を個人として追跡しない。**IPも保存しない設計
- **パスごとに集計する**ので `/f/rokuto` `/f/asupia` が別々の行で出る＝そのまま配布先の成績になる

> `SITE` が空のあいだは**スクリプトを1つも読み込まない＝どこにも通信しない。**
> 入れるまでは、これまでと何も変わらない。

## 3. 読み方

GoatCounterの画面で `/f/` で絞ると、配布先ごとの数字が並ぶ。

- **`/f/<場所>` の数 = QRを読んだ人**（＝チラシに反応した人）
- **`/` の数 = ホームページを見た人**
- **LINEの友だち数（`insight/followers` の targetedReaches）= 実際に登録した人**

この3つの差が、どこで人が離れているかを示す。

| 見え方 | 意味すること |
|---|---|
| QRは読まれるが登録が増えない | **ホームページで止まっている。**説明か導線の問題 |
| そもそもQRが読まれない | **チラシが見られていない。**置き場所か、紙面の訴求の問題 |
| 特定の場所だけ数字が出る | **そこに寄せる。**残りの部数の配分を変える |

## 4. 数字を見るときの注意

- **母数が小さい。**いま到達47人。3人と5人の差に意味は無い。**0か、二桁か**くらいの粒度で見る
- **同じ人が複数回読むことがある**（家で見返す等）。登録数と一致しなくて当然
- **紙は遅れて効く。**置いた翌日ではなく、2〜4週間で見る
- **「置いた日」を `docs/distribution.md` に必ず書く。**いつからの数字か分からないと比較できない

## 5. 外注するときの材料になる

ココナラ等で相談するなら、この3層の数字を渡すと話が具体になる。
**「友だちを増やしたい」ではなく「QRは読まれているのに登録に至らない」と言えるかどうか**で、
返ってくる助言の質が変わる。
