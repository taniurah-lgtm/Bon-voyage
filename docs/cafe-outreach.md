# カフェ14軒への「載せました」の連絡（2026-11-23）

オーナー「各店舗に掲載しました、と連絡したい。間違いがないか確認してほしいこと。良ければ配信登録してください、的な。協賛の話はまだしない」。

- 🆕 **送るのは 11/25（水）の配信の前**（2026-11-23 オーナー「古い情報で、いまはキッズスペースをやっていない、などがあるかもしれないから」）。ページ（/cafe.html）はもう出ている。文は「配信の前にお伝えしたく」
- 🆕 **なるべく短く端的に**（2026-11-23 オーナー）。載せた内容の箇条書きは書かない（リンク先のページにある）
- 古い投稿から拾ったもの（ふらっと 2023・もぐもぐの森 2023・MammaCafe 2024・なっちゃんち 2025-06・フラワー 以前のホームページ）は、**何年の投稿で見たかを書いて**「いまもあるか」をたずねる（いまのことはお店しか知らない）。「載せないでほしい場合は」の一文で断れるように
- 🆕 **家族で行って分かっていること**（2026-11-23 奥さまのコメント: フラワー・ふらっと＝ベビーカーで入れる、eggg Park＝子ども用の椅子がある）は**質問にしない**。「家族で伺ったときに確かめたので、ページに書いています」と伝える。オーナー「最近行ったので、確認しなくていい」→ **ページに「最近、家族で行って確かめたこと」として、お店の案内とは分けて載せた**（`data/cafes.json` の visited）
- 🔴 配信までに「もうやっていない」と返事が来たら: そのお店を `pages: false` にして、年齢別ページの8軒から外し、案内画像の軒数（14軒）を直して書き出し直す
- 送り先は、通信の Instagram からお店の Instagram へ DM（Claude は送らない）
- 🔴 `docs/org.md`「先方に校閲をさせない」: 「間違いがあれば直してください」とは書かない。**お店の案内で確かめたことだけを見せて「この内容でよろしいでしょうか」**。質問は**お店しか知らないこと**（ページで「要確認」にしているもの）だけ
- 協賛の話はしない（`CLAUDE.md`「無料で載せた店には『載せました』のお礼だけ」）
- 返事が来たら Claude に貼る → `data/cafes.json` に反映（お店本人の返事＝お店の発信として扱う。日付と「DMの返事」と書く）
- 版下: スクラッチの gen.py（この md と、コピー用のアーティファクトを同じ中身から作る）
