## 2. 🔴 絶対に守ること（5つ。ここを外すと取り返しがつかない）

### ① 作り方を公開物に書かない

外に出るもの（投稿・キャプション・ホームページ・チラシ）に、次を**一切書かない**。

- 巡回の仕組み・頻度・**自動化の有無**・使っている道具や技術の名前
- 巡回先の一覧そのもの
- 台帳・スクリプト・ファイル名・内部の判定理由
- 計測の仕組み（`/f/xxx` の一覧、解析の設定）

⭕️ 書いてよいのは**結果と根拠**だけ。
「市や施設の公式ページで一件ずつ確かめています」「まとめサイトからの転載はしません」
——これは**何をしたか**であって、**どうやったか**ではない。

### ② 多摩六都科学館に触れたら、必ずこの一文を添える

> **※最新の情報は多摩六都科学館ウェブサイトでご確認ください。**

**先方との約束＝掲載の条件。**枠ごとに、館名を明示して入れる。
（小金井公園に触れる場合も同じ強さで「※最新の情報は小金井公園の公式サイト・Xでご確認ください。」）

### ③ 「行ってきました」と書いてよいのは、実際に撮った場所だけ

❌ **イベント情報は現地確認していない。**「自分の足で確かめて」「実際に行って」は**嘘になる**。
⭕️ **多摩六都科学館は、実際に館内で撮影した。**この回は「行ってきました」と書いてよい。
　→ **リールは基本これ。**撮った場所のことしか話さないなら、この問題は起きない。

### ④ 施設の案内に書いていないことは「(要確認)」を付ける

ベビーカーの可否・オムツの規定・年齢制限など。**推測で断定しない。**

### ⑤ 個人の連絡先を撒かない

公開してよいのは**公式の代表番号だけ**。主催者個人の携帯（080/090）やフリーメールは出さない。

### 🔴 伸びなかった原因のうち、1つは特定できている

Instagram のプロアカウントのカテゴリ設定で、そう選ばれた状態になっていた。

**いちばん言われたくないことが、プロフィールの一番上に出ていた。**

→ 対処は「プロフィールを編集 → カテゴリ」を変える、または**カテゴリラベルの表示をオフ**にする。
　**2026-09-13 時点で、オーナーは原因を把握済み。対処したかは会話の最初に確認すること。**

### ブランチ

**名前は何でもよい。**新しいセッションが勝手に付けた名前をそのまま使ってよい
（既存の `...-rfwmo8` `...-yefv9l` の末尾6文字も、人が考えたものではなく自動で振られたもの）。

🔴 **大事なのは名前ではなく、この3つ。**

1. **`claude/line-message-resend-yefv9l` から切る**
2. **yefv9l に直接 push しない**
3. **`claude/family-event-planning-rfwmo8` は触らない**

```
git fetch origin claude/line-message-resend-yefv9l
git checkout -b <このセッションのブランチ名> origin/claude/line-message-resend-yefv9l
git push -u origin <このセッションのブランチ名>
```

※ セッションの指示で別のブランチ名が指定されていたら、**その名前でよい。**
　ただし**必ず yefv9l から切る**こと（`origin/main` や既定のブランチから切ると、
　`docs/rokuto-reel.md` も `docs/homepage/` も入っていない）。

理由:

- `docs/rokuto-reel.md` も `docs/homepage/` も **yefv9l** にある
- 🔴 **yefv9l には別の会話が push している。**直接触るとぶつかる
  （2026-09-13 に実際に push が弾かれた）
- 🔴 **`claude/family-event-planning-rfwmo8` では毎週の巡回**（台帳・レポート・LINE配信）が
  自動実行されている。**壊すと通信が止まる**
- ホームページの公開は **yefv9l への push でしか起きない**。
  別ブランチで作業しているあいだは**外に出ない＝安全**。まとまったらマージする

> ⚠️ **`events/` と `reports/` には触らない。**あれは毎週の巡回のもので、この会話の担当ではない。

### 動画ファイルはコミットしない

素材は Drive に置いたまま。リポジトリに入れるのは**文章（台本・キャプション・手順）**と、
必要なら**軽い静止画**だけ。
