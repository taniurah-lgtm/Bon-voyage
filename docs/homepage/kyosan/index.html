Rules

掲載のきまり

読者に信頼される紙面であることが、協賛の価値だと考えています。

  • 「PR」と、はっきり表示します景品表示法のステマ規制（2023年10月〜）に沿って、項目の頭に、周りと同じ大きさで入れます。規制で問われるのはお店の側なので、表示はこちらで必ず入れます。
  • 原稿はこちらで書き、掲載の前にお見せしますほかの催しと同じ書き方で、事実だけを書きます。「いちばん」「必ず上達」のような言い方は使いません。
  • 子連れに向かないものは、お断りしています金額にかかわらず。政治・宗教、ギャンブル、貸金や投資の勧誘、連鎖販売、美容医療、健康食品の効果、お酒・たばこに関わるものは載せません。
  • 医療機関は「応援型」でお受けします医療広告のきまりの範囲（名称・診療科・場所）で、お名前を載せます。

Flow

お申し込みから掲載まで

  1. ご相談載せたい催しと時期をうかがいます。紹介型は、載せたい号の2週間前までが目安です。
  2. 掲載申込書紙でも、写真やPDFをメールで送っていただいても大丈夫です。
  3. 原稿づくりこちらで書いて、お見せします。直しは、載せる号の前の週の金曜まで。
  4. 請求書・お振込原稿をご確認いただいたあとに、請求書をお送りします。紹介型は、載せる号の前の週の金曜までにお振込を。
  5. 掲載水曜の朝9時に、LINEでお届けします。
  6. 翌月のご報告届いた人数・開いた人数・押された数をお送りします。

お振込は、原稿をご確認いただいてからです。催しが中止になったときや、こちらの事情で載せられなかったときは、全額お返しします。

Q&A

よくあるご質問

無料で載っている催しもありますが、何が違いますか？

ふだんの掲載は、編集の判断で選んでいます。載るかどうか、いつ載るかはお約束できません。

紹介型は、ご希望の号に、LINEの本文とページのカードの両方で必ず載ります（掲載のきまりを満たす場合）。原稿もお店に確かめてから書き、翌月に数字をご報告します。

200人で、効果はありますか？

人数は多くありません。そのかわり、届くのは子育て中のご家庭だけです。チラシのポスティングのように、子育て中でないお宅に配られることがありません。ブロックは2%です。

読者は9月はじめの約3倍になり、11月からは市内の地域センター・児童館にもチラシが並んでいます。

効果は、どうやって分かりますか？

翌月に、届いた人数・LINEのメッセージを開いた人数・ページで見られた回数・ボタン（公式サイト・地図・カレンダー登録）が押された回数をお送りします。

「通信を見た」とお伝えいただいた方への小さな特典を用意していただくと、来店の数も分かります。特典の中身は、お店で決めてください。

原稿は自分で書くのですか？

こちらで書きます。うかがった事実（日時・場所・料金・対象年齢・予約・ベビーカー・おむつ替え）をもとに、ほかの催しと同じ書き方にします。掲載の前にお見せします。

写真やロゴは載せられますか？

紹介型は、ほかの催しと同じく文字のカードです。お店のInstagramの投稿（前回の様子など）を開くボタンを、1つ付けられます。

応援型は、ページの下にロゴを載せられます。正方形の画像をお送りください。

途中でやめられますか？

紹介型は1回ごとのお申し込みなので、続けるかどうかは毎回決めていただけます。応援型は1年ごとで、自動では更新しません。
