## 0. 「買い手」をどこから拾ったか

**いちばん効く物差しは「すでにお金を払って、子育て家庭を集めているか」。**店があるだけの一覧より、証拠のある相手から当たる。
Notion の「根拠」の列がこれ。

### 調べて分かったこと（営業の前提）

- **ホームメイトFC花小金井店の運営は、花小金井の地元の会社（株式会社テイクコーポレーション・花小金井1-11-1）。**
  商品券の「住まい8社」の1社で、子育てガイドにも広告。**フランチャイズの看板だが決めるのは地元の社長**
- **のま整骨院（小川町）は、こだキッズタウンの協賛欄に名前がある。**「子どもの行事を協賛で応援している」ところから話に入れる
- **紹介型の「いま売れる」ネタは、民間のワークショップに出ていた。**ミュウテック工房（花小金井南町3丁目）のクリスマス工作が
  **11/15〜12/20の日曜6回**。日付のある有料の催しで、紹介型の形そのもの
- **習い事の体験会の山は1〜3月**（4月の入会に向けて）。11〜12月に話をすると、その山に間に合う
- **保険は、地元の代理店の情報が古い**（エキテンの掲載が2013年のまま）。オーナー自身の家の保険の担当者に聞くのがいちばん早い
- **写真館は12月**（10〜11月は七五三で忙しい）。**摘み取り農園は5〜6月**（7〜8月は摘み取りで忙しい）。**雛人形は11月下旬〜12月**（1月の号に間に合わせる）

## 1. 優先と型の決め方

| 優先 | 意味 |
|---|---|
| **S 今月** | 決める人がその場にいる × 子育て家庭にお金を使っている証拠がある × 11〜12月に載せるネタがある（または業種の1番手） |
| **A** | 次の1〜2か月。または1業種1社の2番手 |
| **B** | 時期が来たら・条件がそろったら（法人・フランチャイズ・季節もの・医療の順番待ち） |
| **C** | 余力があれば（一覧サイトだけ・遠い・順番待ち） |
| **保留** | いまは声をかけない（理由つき） |

**応援型は1業種1社。同じ業種は同時に声をかけない**（2社から「はい」と言われて片方を断るのがいちばん気まずい）。順番:

| 業種 | 1番手 → 2番手 → … | メモ |
|---|---|---|
| 不動産 | **ホームメイトFC花小金井店** → ことぶき不動産 → ダイワ住友・そのだ不動産 → 藤友 → ほか | ダイワ住友・そのだは9/3のチラシの返事が先 |
| 整体・産後 | **のま整骨院** → きしの美容整体院 → 笑顔道 花小金井駅前 → ほか | |
| 小児科 | 比留間医院 → がんぼクリニック → ほか | 🔴 医療は**チラシが先** |
| 歯科 | はなここどもの歯のクリニック → 神津歯科 → ほか | 同上 |
| 産科 | 花小金井レディース → ジュンレディース → … → 中野産婦人科は最後 | 同上。中野は本命なので実績ができてから |
| 保険 | （弱い）オーナー自身の保険の担当者 → トライ・スタッフ／ユニオン | エキテンの情報が古い |

**紹介型は1号1件**（同じ業種は同じ月に2件入れない）。業種の順番はないので、催しの日に合わせて並べる。
