# 精度のルール（厳守）

1. **出典URLのない情報は書かない。** 書く場合は必ず「未確認」と明記する。
2. **電話番号・住所を推測で書かない。** 確認できなければ空欄にして「要確認」とする。
3. **実在が確認できない店舗は載せない。** 数を水増ししない。
4. 「◎/○/△/×」の見込みは**あなたの推測でよいが、推測であることを明記**し、根拠を1行で書く。
5. チェーン店は、**本部一括の掲示ポリシーがあって個店では断られやすい**ことが多い。分かる範囲でその点に触れる。
6. 情報が古い可能性がある場合（閉店・移転）は、その旨を書く。
