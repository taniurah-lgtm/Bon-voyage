# Gemini（または Muse）用 — 小平市のチェーン教室の「公式のURL」さがし（1回だけ・2026-11-27）

> スクールガイドのチェーン教室のうち、Claude の環境から公式サイトが開けなかった6つ（`docs/school-guide-launch.md`）。
> **AI に頼むのは公式のURLを集めることだけ。**教室の中身（年齢・駅・体験）は、Claude がそのURLを開いて確かめる（AIの写しだけでは載せない）。
> 学研・ECC は Claude から開けないので、URL が分かったら**オーナーのスマホで公式の「小平市の教室一覧」のスクショ**をもらう。
> 向き: 公式サイトさがしは **Gemini**（Google の検索）。Muse は Instagram・Threads に強い（`docs/prompts/meta-ai-weekly.md`）。

## 送る文（そのまま貼る）

東京都小平市にある、次の6つの習い事チェーンの教室を、各社の公式サイトの教室検索で調べてください。

1. 学研教室（kyoshitsu.gakken.jp）
2. ECCジュニア（eccjr.co.jp）
3. ヤマハ音楽教室（school.jp.yamaha.com）の、子ども向けコース（幼児科など）の会場
4. カワイ音楽教室（music.kawai.jp）
5. セイハ英語学院（seiha.com）
6. ブリヂストンスポーツアリーナ小平のスイミングスクール（公式サイト）

チェーンごとに、次を書いてください。
- 公式の「小平市の教室一覧」のページのURL（無ければ「なし」）
- 小平市内の教室ごとに、教室名と、その教室の公式ページのURL

決まり:
- URLは各社の公式サイトのものだけ。塾ナビ・ダイヤモンド・コエテコ・いこーよ・エキテンなどのまとめサイトは使わない
- 見つからないものは「見つからない」と書く。推測でURLを作らない
- 住所・電話番号・先生の名前は要らない
