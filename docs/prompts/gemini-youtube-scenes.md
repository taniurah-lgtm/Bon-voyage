# Gemini 用 — YouTube で「昨年の様子」の動画をさがす（2026-11-25〜）

オーナー「Gemini は YouTube からリサーチするとかはどうですか？」→ Claude の考え（2026-11-25）:

- **催しをさがすのには向かない。**動画は催しが**終わってから**上がる。題名の日付は去年のもの。主催の告知でもない（台帳の根拠にならない）
- **年齢別ページの「📷 昨年の様子」には向いている。**
  - 11/18号の一推しの「昨年の様子」は9回押された（`docs/weekly-pages.md`）。**一推しには様子のリンクを必ず付ける**と決めた
  - インスタはログインしないと見られず、さがすのはオーナーの手だった。**YouTube はログインなしで見られ、Claude も題名・チャンネル名・公開日を確かめられる**（2026-11-25 に試した: 動画の情報と、ページの公開日が読めた）
  - Gemini は YouTube と同じ Google のもので、動画をさがすのが得意
  - ページの側は対応ずみ（YouTube の URL なら「〇〇のYouTube」と出る。`scripts/build-weekly.mjs`）
- **いつ**: 月曜。Gemini の定期実行（`docs/prompts/gemini-weekly-research.md`）とは**別に**頼む（混ぜると、どちらも薄くなる）。
  2つめの定期実行がプランで作れるなら「毎週月曜」にする。作れなければ、月曜にオーナーが貼る
- **答えが来たら**: フォーム「AIのさがしもの」か Claude に貼る → Claude が動画を開いて（題名・チャンネル・公開日）、号の web の `insta` に入れる。
  `when` は**動画の公開日ではなく、写っている催しの年月**。`by` はチャンネル名（20字まで）
- **どの動画を使うか**（`docs/weekly-pages.md`「どの投稿を使うか」と同じ順）:
  1. 主催・会場の公式チャンネル／市の公式チャンネル
  2. 地元のテレビ・ラジオ・新聞（J:COM・FM西東京など）、出演者・お店、発信を仕事にしている人
  3. ふつうの家族の動画は**使わない**（先に一言ことわる決まりだが、YouTube では連絡がつけにくい。子どもの顔も写る）
  - 🔴 議員・政党・選挙に出る人のチャンネルは使わない
- 🔁 **2026-11-25 1回目の答えを見て直した**: Gemini は /ai/ の一覧（odekake.txt）を「アクセス制限で開けなかった」と言い、カレンダー（calendar.html）で探した → 指示文をカレンダーに変えた。
  三鷹（国立天文台）・抽選の締切が過ぎた催し（狭山公園の親子自然あそび）まで探していた → 行き先と「締切済みは探さない」を足した。年月が「不明」の動画が多かった → 画面の文字からも探すよう足した
