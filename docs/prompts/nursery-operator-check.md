# 守ってほしいこと
- 根拠にするのは、園・法人の公式サイト、園の Instagram（プロフィール・投稿）、小平市・東京都のページだけです。
  口コミサイト・求人サイト・まとめサイトは使わないでください
- 法人名は、書いてあるとおりに（「社会福祉法人〇〇会」「学校法人〇〇学園」など）、URL をつけて書いてください
- 「姉妹園」「系列園」「同じ法人の〇〇幼稚園」「連携施設」と書いてあれば、その文をそのまま書いてください
- 名前が似ている・住所が近い、だけで「同じ法人」と決めないでください
- 見つからなかったときは「見つかりませんでした」と書いてください
