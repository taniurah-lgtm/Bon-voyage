# 「ぼんぼやーじゅ通信」で検索してもホームページが出ない — 調査と対処

**症状**（オーナー報告 2026-08-30）: 以前は検索でホームページが出ていたが、いま出ない。

---

## 1. サイト側は健全だった（2026-08-30 実測）

| 調べたこと | 結果 |
|---|---|
| トップの応答 | **HTTP 200**（GitHub Pages・正常配信） |
| `X-Robots-Tag` ヘッダ | **noindex なし** |
| `<meta name="robots">` | **公開ページには無し**（版下・印刷用ページのみ noindex。正しい） |
| `robots.txt` | `Allow: /`。塞いでいるのは `/f/` `/m/` と版下だけ |
| `canonical` | `https://bonvoya.nicomaru.tokyo/`（自己参照・正常） |
| `<title>` / `description` | 正常。ブランド名を含む |
| `sitemap.xml` | **HTTP 200**、6URL、`lastmod` も更新されている |
| **Search Console の認証タグ** | **入っている**（`google-site-verification`） |

→ **サイトが検索から締め出されている、という技術的な原因は無い。**

> ⚠️ 調査中に「tokushoho.html が sitemap にあるのに noindex」と一度誤認した。
> 実際は「**noindex にしない**」と書いたコメントに引っかかっただけで、矛盾は無い。

## 2. 足りなかったもの → 対処済み

- **構造化データ（JSON-LD）が無かった** → `index.html` に追加した（2026-08-30）
  - `WebSite`（name: ぼんぼやーじゅ通信 / alternateName に表記ゆれ）
  - `Organization`（ぼんぼやーじゅ通信の会・あすぴあ登録団体・areaServed に5市）
  - `WebPage`
  - **狙い**: 「ぼんぼやーじゅ通信」という名前を、検索エンジンに**実体として認識させる**こと。
    造語なので競合は無く、認識さえされれば1位に出るはずの語である。

## 3. ⚠️ 本当の原因は、たぶん「被リンクがゼロに近い」こと

- ドメインは `nicomaru.tokyo` の**サブドメイン**で、それ自体の評価はほぼ無い
- **外部からリンクされていない**。検索エンジンは、どこからも参照されないサイトを
  「見つけにくく、重要度も低い」と扱う
- 造語のブランド名は、**インデックスされてさえいれば必ず出る**。出ないのは
  インデックスされていないか、評価が低すぎて落とされているかのどちらか

### オーナーにしかできない対処（効果の大きい順）

1. **Search Console で「インデックス登録をリクエスト」する** ← 最優先・数分で終わる
   - search.google.com/search-console → URL検査 → `https://bonvoya.nicomaru.tokyo/` を入力
   - 「インデックス登録をリクエスト」を押す
   - あわせて **サイトマップを送信**（`sitemap.xml`）
   - 「ページ」レポートで **除外の理由**を見る。ここに答えが書いてある可能性が高い
     （「検出 - インデックス未登録」なら評価不足、「クロール済み - 未登録」なら内容が薄いと判断された、など）
2. **外部リンクを作る。いま進めている営業がそのまま効く**
   - **あすぴあのHPへの団体情報掲載**（登録団体としてリンクが付く／`docs/asupia-registration.md` の宿題）
   - **こだいら市民活動ナビ**（kodaira-navi.net）への団体登録
   - **多摩六都科学館**などの掲載
   - → いずれも**地域の実在ドメインからのリンク**。数は少なくても質が高い
3. **チラシ・ポスターのQRから実アクセスが積み上がること**も、間接的に効く

## 4. やらないこと

- 被リンクを買う、相互リンク集に登録する等は**やらない**。逆効果になる
- 同じ内容のページを量産しない

### ② note の記事が検索に出ない理由

🔴 **ホームページから note へのリンクが、1本も無い。**
（Instagram と Threads はフッターにあるが、note は無い）

**外からリンクされていないページは、見つけてもらいにくい。**

🔴 **さらに、公開した note 記事のURLを、こちらが1件も持っていない。**
`note/<日付>.md` は下書きを作るだけで、**貼ったあとのURLを記録していなかった。**
**URLが無いので、ホームページに一覧を作ることもできない。**

→ **2026-09-23、`scripts/build-note-draft.mjs` に `published:` の行を足した。**
**note に貼ったら、そこにURLを書く。**溜まったら、ホームページから一覧でリンクする。

### 🔴 順番を守る

**note をホームページからリンクするのは、メンバーシップを止めてから。**
**先にリンクすると、廃止したはずの月額プランへ人を送ることになる。**

効くのは**プロフィールに「小平」「花小金井」を入れておくこと**くらい。
