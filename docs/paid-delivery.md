# 有料(応援サポーター)配信 運用手順 — Phase 0(手動MVP)

有料の人への **手動配信＋Googleカレンダー登録代行** の運用手順。
配信経路は当面 **手動(1:1 LINE/メール)**(決定: 2026-07-18、`docs/paid-roadmap.md`)。

## 前提
- 課金は **note メンバーシップ(月300円)**。特商法表記・支払・解約は note が内包。
- 個人情報(連絡先・Gmail)は **プロフィールに書かず、フォーム回答シートで別管理**(`docs/onboarding-form.md`)。
- カレンダー代行の器は **共有カレンダー「ぼんぼやーじゅ・おすすめ」1本**(希望者のみ個別ゲスト招待を併用)。

## 週次フロー(水・土)
1. **生成**: 巡回セッションが `plan: paid` かつ `active: true` の各人ぶんの個別レポートを `reports/<id>/YYYY-MM-DD.md` に生成する。
   - 共通調査(1回)→ プロフィールの `coverage`/`categories` で絞込・並べ替え。
   - **各おすすめに 📍地図＋公式リンク**を添える(`CLAUDE.md` 有料版の既定)。
   - 末尾は **有料版フッター**(カレンダー登録の案内・前日リマインダー付き。`docs/freemium-plan.md`)。
2. **手渡し**: オーナーが各人へ本文をコピペで手渡し(LINE 1:1 or メール)。`delivery: manual`。
3. **カレンダー登録代行**: 「E3を登録」「E3とE5を登録」等の返信を受けたら、このリポジトリの Claude に渡す → Google Calendar MCP で **共有カレンダー**に登録。
   - タイトル=イベント名／場所・開始終了時刻／説明欄に 📍Googleマップ・公式URL・子連れメモ／タイムゾーン Asia/Tokyo／**前日18:00 リマインダー(popup)**。終日系は allDay。
   - 台帳(`events/`)のステータスを「登録済」に更新し、カレンダーのイベントIDをメモ(`CLAUDE.md` 承認→カレンダー登録)。

## 使う Google アカウント(重要)
- 共有カレンダーやゲスト招待は **相手にアカウント名が見える**。→ **個人アカウント(h.taniura…)は使わない**方がよい(プライバシー。ドメインで実名を隠した方針と同じ)。
- **運用専用アカウント**を1つ使う。候補:
  - 既存の `tokyo.papa.home@gmail.com`(DIY用に作成済)を **ニコマルの運用共通アカウント**として、ぼんぼやーじゅ用カレンダーも同居させる(カレンダーは用途別に分けられる)。手数最小。
  - もしくは、ぼんぼやーじゅ専用に新規アカウントを1つ作る(将来の分離がきれい)。
- 推奨: まずは **`tokyo.papa.home` に「ぼんぼやーじゅ・おすすめ」カレンダーを作る**で開始。分離が必要になったら専用アカウントへ引っ越し。
