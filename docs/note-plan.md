# note の使いかた（2026-09-04 見直し）— 課金の入口から、検索の入口へ

`note.com/bon_voyage_mail` は、これまで**メンバーシップ（月300円）の決済窓口**だった。
月額制度の廃止（`docs/strategy-2026-09.md`）でその役目は終わったが、
**「ぼんぼやーじゅ通信」で検索したときに出てくる数少ない場所**なので、閉じずに役目を変える。

---

## 1. まず結論 — 完全自動投稿はやらない

| | 結論 |
|---|---|
| note に公式の投稿APIは | **無い**。外部から記事を投稿する公式手段は提供されていない |
| 非公式API（`/api/v3/...`）は | 存在するが**規約・robots.txt のグレーゾーン**。予告なく壊れる |
| Selenium等のブラウザ自動化は | 規約違反の疑い。**アカウント停止のリスク** |

**検索で当たる資産をアカウント停止で失うのは、自動化で浮く数分と釣り合わない。** だからやらない。

### 代わりにやること — 「毎日自動で原稿ができる → 貼るだけ」

| やり方 | 手間 | 費用 |
|---|---|---|
| **A. 原稿を自動生成 → 毎日そのまま貼る** | 1日1〜2分 | ¥0 |
| **B. 原稿を自動生成 → 週末に7本まとめて予約投稿** | **週1回15分だけ** | **月500円**（note プレミアム） |

> ✅ **推奨は B。** note の予約投稿は**プレミアム（月500円・Webブラウザ限定）**の機能。
> LINEライト（月5,000円）を払うと決めた以上、500円は誤差。しかも**検索の資産に直接効く**。
> 週末に7本予約しておけば、外から見れば「毎日更新されているブログ」になる。

生成はリポジトリ側でやる（`reports/` と同じ形で `note/YYYY-MM-DD.md` に出す）。
GitHub Actions の cron に載せられる。**実装はまだ。やるなら着手する。**

## 2. 記事の型 — LINEの通信をそのまま貼らない

通信は「40行・箇条書き・絵文字・URLは1本だけ」。**これは読み物として弱く、検索にも当たらない。**
note はブログなので、別の型で書き直す。

### 共通のきまり

- **1,000〜1,800字**。見出し（H2）を3〜4本立てる
- **書き出しの2〜3行で誰向けかを言う**（「花小金井から、2歳と5歳を連れて行ける場所を探している方へ」）
- 絵文字は**見出しに1つまで**。本文は普通の文章
- **一次情報のリンクを本文に置く**（公式サイト・市のページ）。LINEと違って制限しない
- 末尾は共通フッター（下記）

### 3つの型をまわす

| 型 | 頻度 | 中身 | ねらい |
|---|---|---|---|
| **① スポット1本記事** | 週3 | 1か所を深く。行き方・駐車場・授乳室・おむつ替え・混む時間・雨のとき・近くのもう1か所 | **検索の本命。**「花小金井 じゃぶじゃぶ池」のような長い語で当たる |
| **② 今週のおでかけ** | 週1（水） | その週の通信を、ブログ文体に書き直す | 継続の芯。LINE登録への導線 |
| **③ まとめ・季節もの** | 週3 | 「2026年 小平の秋祭りまとめ」「はじめての花火、持ち物」 | まとめ記事は検索に強い。使いまわしが効く |

### タイトルの型

```
【2026年】小平市の〇〇｜子連れで行くなら
花小金井の〇〇に、2歳と5歳と行ってきた
〇〇のじゃぶじゃぶ池はいつから？ 混む時間と持ち物
```

**地名（花小金井・小平・西東京）＋年＋子連れ**を入れる。ブランド名だけのタイトルは検索に当たらない。

### ネタは足りている（作り話をしなくていい）

- `data/map-spots.json` … **46スポット**
- `data/events.json` … **60件超**のイベント（出典URL・子連れ適性つき）
- `reports/free/` … 過去号7本
- `events/camp.md` … キャンプ場

**①だけで46本＝週3本なら3か月半ぶん。** 1日1本でも1か月半は在庫がある。

```
東京都小平市・花小金井のまわりで、子どもと行ける場所とイベントを毎週さがしています。お祭り・花火・水あそび・科学館・電車でおでかけ。未就学〜小学生のご家庭へ、毎週水曜の朝にLINEで無料でお届けしています。小平市民活動支援センターあすぴあ 登録団体（第254号）。
```
