## 3-2. 🔴 風船の計算（2026-09-20）— ヘリウムにすると出店料より高くつく

オーナーが見つけたのは **Amazon「バルーン30個 ゴムバルーン 黄・白・デイジー ¥749」**。

### まず、この商品にガスは入っていない

商品名に「ヘリウム風船」という語が入っているが、**それは検索用の語で、中身はゴム風船と
リボンと紙吹雪だけ。****ヘリウムガスは別に買う。**ここを取り違えると当日ガスが無い。

### 30個ぜんぶ浮かせるといくらか

| | |
|---|---|
| 風船30個 | **¥749** |
| ヘリウム | 直径30cmのゴム風船で、**小ボンベ約13個 / 大ボンベ約26個**。**200L ≒ ¥5,500 / 400L ≒ ¥6,500** |
| **30個ぶんの合計** | **約 ¥7,250**（400Lボンベ1本＋風船）＝ **1個あたり約240円** |

🔴 **払いたくなかった出店料は ¥5,000。****30個配るだけで、それを超える。**
**「ブース代を節約するために風船」が、逆になっている。**

### もう1つ、手間も減らない

**ゴム風船にヘリウムを入れて浮くのは 5〜7時間**（25cmで約12時間という数字もある）。
イベントは **10:00〜16:00＝6時間**。**前日に膨らませて持って行くことはできない。**
搬入8:00に全部入れても、午後には沈み始める。**結局、当日その場で1個ずつ入れることになる。**
（ハイフロートで1週間もつが、塗って乾かす手間と費用が増える）

### 11月の屋外であること

- **風がある。**浮く風船は**手を離した瞬間に無くなる。**もらった子が泣く
- **公園に飛んでいく。**市の公園で、主催に市議がいる。**事務局が渋る理由になりうる**

### 代案 — 「浮かせる」と「配る」を分ける

| | 何に使うか | なぜ |
|---|---|---|
| **浮かせる（ヘリウム）** | **ブースの上に数個だけ。看板として** | 遠くから見える。**ここは浮く価値がある。**数個ならボンベは小で足りる |
| **配る（空気＋持ち手の棒）** | **登録のお礼はこちら** | **飛んでいかない。前日に膨らませておける。**電動エアポンプ（概算¥2,000前後・要確認）なら1個数秒 |

**この形なら、事務局の許可も取りやすい。**「配るぶんは飛びません」と言えるため。
初回の持ち出しも、ヘリウム30個ぶんより安くなる見込み（ポンプは次回以降も使える）。

### 色について

**要項に色の指定は書かれていない。**「スパンコールキラキラのギッラギラ」とあるだけ。
**黄色がテーマカラーというのは、いまのところオーナーの見立て**（夜市の幟は黄色だった）。
ただし**この商品の「金の紙吹雪入り」はスパンコールに寄っていて、テーマには合う。**
色を確実にしたいなら、**出店が決まったあとの公式LINEで聞けば足りる。**いま急ぐ話ではない。
