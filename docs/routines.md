# 定期実行(Routine)の約束ごと

## 🔴 いちばん最初に add_repo を呼ぶ

定期実行で起動したセッションには、**このリポジトリが authorized set に入っていない**。
その状態では git プロキシが認証情報を注入しないので、`git clone` も `git push` も
`access denied by the git proxy ... 403` で必ず落ちる。

```
remote: access denied by the git proxy: taniurah-lgtm/Bon-voyage is not in this
session's authorized repository set, so the proxy will not inject a credential
for it. To fix, add the repository to the session's sources.
```

**対処**: セッションの最初に `add_repo` ツールを呼ぶ。
`owner: "taniurah-lgtm"` / `repo: "Bon-voyage"` / `access: "push"`。

⚠️ **2026-09-09 まで、3つのRoutineのプロンプトには
「認証はこの環境の git プロキシが持っているので、そのまま通る（検証済み）」と書いてあった。
これはもう正しくない。**この日、水曜巡回は09:08に発火して3分半で死んだ。
通信が届いたのは、オーナーとの対話セッションから手で送ったから。
**Routineは落ちたことを自分で報告できない。**

## 🔴 草案があるときは、書き直さない（2026-09-16 の事故を受けて）

### 何が起きたか

火曜のうちにオーナーと詰めた 9/16号の草案があった。**それが使われず、Routine が一から書き直した。**
結果、**連休の天気を「くもり40〜50%」と書いて配信した。実際は4日とも降水確率90%。**
その予報にもとづいて、気温23〜25℃・降水確率90%の連休に**プールを薦めていた。**
訂正のため、同じ朝に**3通**を送ることになった。

### 原因

**草案は `claude/line-message-resend-yefv9l` に置かれ、Routine は `claude/family-event-planning-rfwmo8` で動く。**
rfwmo8 に 9/16号は存在しなかったので、Routine から見れば「今日の号はまだ無い」だった。

⚠️ **この危険は事前に気づいていて、対策（リネーム）も提案して承認も得ていた。
　それでも yefv9l 側でリネームしただけで、rfwmo8 に同期しなかった。**
**気づくことと、直しきることは別。**

### これから（3つとも守る）

#### ① 草案は **rfwmo8 に置く**

`reports/free/<当日>.md`。**yefv9l に置いても Routine は見ない。**
yefv9l で作ったら、**同じコミットで rfwmo8 にも入れる**こと。

```
git checkout claude/family-event-planning-rfwmo8
git checkout claude/line-message-resend-yefv9l -- reports/free/<当日>.md
git commit && git push
```

#### ② Routine は、**その日の号がすでにあれば書き直さない**

巡回の手順4（レポート作成）の前に、必ずこれを見る。

> **`reports/free/<当日>.md` がすでにあるか。**
> **あれば、それが正。**内容を書き換えず、**日付と、時間に依存する記述（天気・締切・会期）だけ**を確かめて、
> ずれていればそこだけ直す。**構成・推し・載せる/載せないの判断はやり直さない。**
> 無ければ、これまでどおり作る。

🔴 **「自分ならこう書く」で書き直さない。**草案は人と詰めた結果で、
**載せないと決めたもの（例: 涼しくなった時期のプール）まで復活してしまう。**

#### ③ 天気は、**取得先を決めて、そこだけ見る**

事故の芯は天気だった。`docs/sources.md` の「天気」を見て、**そこに書いてある先から取る。**
**予報は日ごとに変わる。**前日に取ったものを、当日そのまま使わない。**配信の朝に取り直す。**

### 送ってしまったあとに気づいたら

**取り消せない。**やることは1つだけ。

- **誤りが「読者の予定に影響するもの」なら訂正する**（天気・日付・料金・締切）。
  文体の好みや構成の違いでは送り直さない
- 送り方はオーナーが決める。**補足だけ** / **訂正版として全文**
- ファイル名は `<当日>-hosoku.md` `<当日>-teisei.md` にする。
  **`update-homepage-preview.mjs` の絞り込みが `YYYY-MM-DD.md` に限定されているので、
  ホームページのプレビューは本編のまま動かない**
