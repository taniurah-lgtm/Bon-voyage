## 6. 事故の記録（同じことを繰り返さないため）

### 事故1: 画像から転記したら36%間違えた

市報8/5号を**私がスクリーンショットで読んで起票**した E44〜E54 を、後日 公式PDFと突合したところ
**11件中4件が誤り**。うち **E47 は開催日を丸ごと8日ずらしていた**（防災週間の期間を開催日と誤読）。
E46 は曜日を誤り、**締切を落とした**。

→ **画像を読むのは最後の手段。** 順番は `docs/sources.md`「取り方の順番」を必ず守る。

### 事故2: 「入場無料が基本」と書いたが、過半が有料だった

田無アスタ2Fセンターコートについて私が書いた記述。**8月は800円/500円/300円と有料が過半**。
無料版レポートは「無料・格安を上位に」が方針なので、**読者が実際にお金を払う実害**になる。

→ **「無料」と書く前に、必ず費用を確認する。**

### 事故3: 「読めないサイト」と誤診し、2週間むだにした

田無アスタの月次スケジュールが画像だったので「Webに文字がない」と結論し、
スクリーンショット運用を設計文書にまで書き込んだ。**誤りだった。**
`asta.co.jp/event/` に**本文テキストがあった**。一覧しか見なかったのが原因。

→ **「読めない」と書く前に、個別ページ→PDF→別の一覧を全部試したか自問する。**

### 事故4: 巡回設定はあるのに毎月0件だったが、誰も気づかなかった

田無アスタは「毎回巡回」の設定なのに、**通信に一度も登場していなかった**。
谷裏さんが紙のチラシを送ってくれて初めて発覚。同種の障害として、
**イオンシネマ「げんきッズシアター」は制度自体が終了**していた（`CLAUDE.md` に固有名が
埋め込まれていた）。検索インデックスに旧ページが残るので、生きているように見える。

→ **0件だったソースを巡回レポートに1行残す。**（ルールは書いたが、**強制する仕組みはまだない**）

### 事故5: HTTP 200 なのに中身は「Access Denied」だった

`curl -w '%{http_code}'` が200を返すのに、本文はAkamaiの遮断ページ。
**ステータスコードだけでは判定できない。** さらに **curl と WebFetch で結果が割れる**
（巡回は WebFetch を使うので、**WebFetch側の可否が実運用の答え**）。

### 事故6: LINEのアクセストークンをスクリーンショットに写した

環境変数欄を撮った画像に平文で写り込んだ。**再発行済み。**
→ **あの欄はスクショに写さない。**
