# K. 事故の記録（同じことを繰り返さないため）

### 1. 画像から転記したら36%間違えた
市報8/5号のスクショ起票 E44〜E54 を公式PDFと突合 → **11件中4件が誤り**。
**E47は開催日を丸ごと8日ずらしていた。** E46は曜日を誤り**締切を落とした**。
→ **画像は最後の手段。** 個別ページ → PDF → 別の一覧 → 検索 → 画像 の順。

### 2. 「入場無料が基本」と書いたが、過半が有料だった
田無アスタ2Fセンターコート。**8月は800円/500円/300円と有料が過半**。
→ **「無料」と書く前に費用を確認する。**

### 3. 「読めないサイト」と誤診して2週間むだにした
アスタの月次表が画像だったので「Webに文字がない」と結論。**誤り。** `asta.co.jp/event/` に本文があった。
**一覧しか見なかったのが原因。**

### 4. 巡回設定はあるのに毎月0件だったが、誰も気づかなかった
アスタは「毎回巡回」なのに通信に一度も出ていなかった。**紙のチラシで初めて発覚。**
同種で **イオンシネマ「げんきッズシアター」は制度終了**（巡回指示に固有名が埋まっていた）。
→ **0件だったソースを巡回レポートに1行残す。**

### 5. HTTP 200 なのに中身は「Access Denied」だった
`curl` が200を返すのに本文はAkamaiの遮断ページ。さらに **curl と WebFetch で結果が割れる**。
→ 巡回は WebFetch を使うので **WebFetch側の可否が実運用の答え**。**ステータスコードだけで判定しない。**

### 6. LINEのトークンをスクショに写した
環境変数欄が平文で写り込んだ。**再発行済み。あの欄は撮らない。**

### 7. 「カレンダー登録代行」— 実装していないことを特典に書いていた
**ワンタップの自己登録**に訂正済み。→ **できていないことを書かない。**

### 8. 巡回が発火したのに、号が2回分 静かに飛んだ
8/5・8/12。**ファイルの実在だけが配信の証拠。**「動いているはず」を信じない。→ A章。

### 9. チラシの版下で、同じ要素を2つの版に入れていた
2度刷りになって線が太り濁る。分解したら**必ず「両方に出ていないか」を確認する**。
あわせて **CSSの `container-type` を付けた要素自身に `cqw` を使うとビューポート幅にフォールバック**する罠を踏んだ
（余白が画面幅で変わり、環境ごとに見切れた）。**コンテナ自身の寸法は % で書く。**

> **9件のうち7件は、人が気づいたから見つかった。** システムが自力で検出したものは1件もない。

# M. 大事な方針（ぶれると信頼を失う）

- **無料通信で売り込まない。** 身内・友人も読む。信頼が最大の資産
- **煽り表現を使わない**（「急いで」「損」「今だけ」）
- **できていないことを特典に書かない**
- **無料を薄くして有料に誘導しない。** 線引きは「量」でなく「役割」（無料＝**知る** / サポーター＝**決める・動く**）
- **地図リンクは無料版では「今週の一推し」1件だけ**
- **秘密情報はリポジトリに入れない**（LINEトークン・会員ページの合言葉）
- **IG用の写真は自前か商用ライセンスのみ**
- **詳細が未公表でも、締切に間に合ううちに存在を知らせるほうを優先する**
  （2026-08-19 オーナー判断。「未公表なので◯◯へ直接」と正直に書けば事実として正確。**出かけるきっかけの数を優先**）
