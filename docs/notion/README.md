# ぼんぼやーじゅ通信 — Notion 用

このセッションから Notion に直接書き込めなかったため、**インポートできる形**で置いてある。

## 1. タスク（データベースとして取り込む）

`tasks.csv` を Notion にインポートする。

1. Notion で取り込み先のページを開く
2. 左サイドバー下の **「インポート」** →「CSV」
3. `tasks.csv` を選ぶ → **データベースになる**

列: `タスク` / `分類` / `優先度` / `状態` / `期限` / `詳細` / `参照`

インポート後にやると使いやすくなる:
- **`期限` を Date 型**に変更（自動で日付として認識されないことがある）
- **`優先度`・`状態`・`分類` を Select 型**に変更
- **ビューを作る**: 「今週」（期限でフィルタ）／「分類別」（ボードビュー）

### 値の意味

| 列 | 値 |
|---|---|
| 分類 | 配信 / 台帳 / あすぴあ / 営業 / SNS / LINE / 有料転換 / 仕組み / 印刷物 |
| 優先度 | 最優先 / 高 / 中 / 低 / 保留 |
| 状態 | 未着手 / 進行中 / 常時 / 待ち / 保留 / 完了 |

`常時` は繰り返しの運用（毎日のSNS投稿など）。`待ち` は先方の返事待ち。

## 2. 背景・経緯（ページとして取り込む）

`context.md` を Notion にインポートすると**ページ**になる（同じ「インポート」から Markdown）。

タスクではないが、**知らないと事故る**もの:
- 過去に起きた事故7件と、その原因
- 「やらないと決めたこと」と却下の理由
- 環境・設定の現状

## 3. 更新のしかた

**リポジトリが正、Notion は写し**。
`docs/handoff.md` が全体の最新状態。タスクが増減したら `tasks.csv` を更新して再インポートする
（Notionは再インポートで既存行を更新しないので、**運用が回り始めたらNotion側を正にして、
このCSVは初期投入用と割り切る**のがよい）。
