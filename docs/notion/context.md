## 起きた事故と、その原因

### 1. 画像から転記したら36%間違えた
市報8/5号を、Claudeがスクリーンショットで読んで台帳に起票した11件を、後日 公式PDFと突合したところ
**4件が誤り**だった。**E47は開催日を丸ごと8日ずらしていた**（防災週間の期間を開催日と誤読）。
E46は曜日を誤り、**申込締切に間に合わず失注した**。

→ **画像を読むのは最後の手段。** 個別ページ → PDF → 別の一覧 → 検索 → 画像 の順で試す。

### 2. 「入場無料が基本」と書いたが、過半が有料だった
田無アスタ2Fセンターコートについての記述。**8月は800円/500円/300円と有料が過半**だった。
無料版は「無料・格安を上位に」が方針なので、**読者が実際にお金を払う実害**になる。

→ **「無料」と書く前に費用を確認する。**

### 3. 「読めないサイト」と誤診して2週間むだにした
田無アスタの月次スケジュールが画像だったので「Webに文字がない」と結論し、
スクリーンショット運用を設計文書にまで書き込んだ。**誤りだった。**
`asta.co.jp/event/` に本文テキストがあった。**一覧しか見なかったのが原因。**

### 4. 巡回設定はあるのに毎月0件だったが、誰も気づかなかった
田無アスタは「毎回巡回」の設定なのに、通信に一度も登場していなかった。
**紙のチラシをもらって初めて発覚。** 同種で **イオンシネマ「げんきッズシアター」は制度が終了**
していた（巡回指示に固有名が埋め込まれていた）。検索結果に旧ページが残るので生きて見える。

→ **0件だったソースを巡回レポートに1行残す。**（ルールは書いたが、**強制する仕組みはまだ無い**）

### 5. HTTP 200 なのに中身は「Access Denied」だった
`curl` が200を返すのに、本文はAkamaiの遮断ページ。さらに **curl と WebFetch で結果が割れる**。
巡回は WebFetch を使うので、**WebFetch側の可否が実運用の答え**。

### 6. LINEのアクセストークンをスクリーンショットに写した
環境変数欄を撮った画像に平文で写り込んだ。**再発行済み。あの欄は撮らない。**

### 7. 「カレンダー登録代行」— 実装していないことを特典に書いていた
ホームページ・オンボーディング・計画書の全部に書いてあった。
**ワンタップの自己登録**に訂正済み。

> **7件のうち5件は、人が気づいたから見つかった。** システムが自力で検出したものは1件もない。

## やらないと決めたこと（蒸し返さない）

| | 却下の理由 |
|---|---|
| **創刊サポーター枠** | 名簿・番号の管理が人数に比例して重い。「最初の20名」は**お金を求める側の都合が前面に出て品がない**。一度実装したが撤回した |
| **返金保証** | note に個別返金の導線がない。書くと事故1・7と同じ「実態との乖離」になる |
| **チラシに「有料への誘導は一切ありません」と刷る** | **虚偽**。QRの先に月300円の導線がある。Geminiが「役所を通すための言い訳」として提案してきたもの |
| **403の迂回にGeminiを使う** | 実行環境のREADMEが「迂回せず報告せよ」と明記。正しい対処は許可リストを広げること（実施済み） |
| **マイ広報紙（mykoho.jp）を巡回先にする** | Cloudflareのボット遮断。市報の正は**小平市公式のPDF** |
| **予約・チケットの見張り番** | 明示的に見送り |
| **Canva連携** | 検討したが導入していない |

## 大事な方針（ぶれると信頼を失う）

- **無料通信で売り込まない。** 身内・友人も読む。信頼が最大の資産
- **煽り表現を使わない**（「急いで」「損」「今だけ」）
- **できていないことを特典に書かない**
- **無料を薄くして有料に誘導しない。** 線引きは「量」でなく「役割」
  （無料＝**知る** / サポーター＝**決める・動く**）
- **地図リンクは無料版では「今週の一推し」1件だけ**（読みやすさ最優先）
- **秘密情報はリポジトリに入れない**（LINEトークン・会員ページの合言葉）
- **IG用の写真は自前か商用ライセンスのみ。** 公式サイトの画像は使わない

## いま効いている学び

**設置が通った2件は、どちらも「行きつけ」だった。**
飛び込み10軒より、行きつけ3軒のほうが早い。新規開拓の前に、自分たちの行きつけを棚卸しする。

**公共施設は「実績」を持って行くと通りやすい。**
個人店で「◯◯さんにも置いていただいています」を作ってから、児童館・公民館へ。
