## このリストの回し方（順番の決まり）

1. **S（今月）→ A → B → C。**1日に動くのは2〜3件まで
2. 🔴 **応援型は1業種1社。同じ業種に同時に声をかけない。**1番手の返事を待ってから2番手へ（`docs/sponsor-apo.md` §1 の順番）。2社から「はい」と言われて片方を断るのがいちばん気まずい
3. 🔴 **医療と園は「チラシが先」。**チラシを置いてもらえてから、次の補充のときに院長あてに資料を渡す。同じ日に両方を頼まない
4. お店・教室は、チラシのお願いの日に**決める人と話せたら、資料を1部だけ渡してよい**（説明は求められたら）
5. フランチャイズ・法人で「本部の決まりで出せない」と言われたら、**それ以上押さない**
6. 「最初の2件は無料」は**紙に書かない。**口頭で、合う先にだけ（掲載のあとのご感想と引き換え）。2件で終わり
7. 催しの主催者（マルシェ・夜市・キッズタウンなど）には協賛の営業をしない。催しは編集で無料で載せる

## 言わないこと

- 「広告」「宣伝」「今だけ」「急いで」「損」
- 効果の約束（「生徒が増えます」「お客さんが来ます」）
- 🔴 「協賛してくれたら載せます」「協賛がないと載せられません」（**編集と協賛を混ぜない**）
- ほかの協賛先の金額や条件
- 巡回の仕組み・使っている道具
- 口座番号（請求書にだけ）
- 読者の個人の情報
