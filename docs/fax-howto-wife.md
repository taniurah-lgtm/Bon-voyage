## 使うもの

- **`FAX用チラシ（2枚）.pdf`**（`docs/print/` にある。夫から LINE で受け取って、スマホに保存しておく）
  - 1枚目: 送信票（宛先「園長先生」・送信元・お礼の文。**園名・FAX番号・日付は入っていない**＝どの園にもそのまま送れる。日時は FAX の上の端に自動で入る）
  - 2枚目: いつものチラシ（**2026-11-05 から片面の新しいチラシ**。白黒版）
  - 作り直すとき: `node scripts/make-fax-generic.mjs <作業用.pdf> "docs/print/FAX用チラシ（2枚）.pdf"`
- **スマホでFAX45**（https://www.netfax.jp/smp ）: 会員登録なし・1枚45円（2枚で90円）・クレジットカード払い。送れなかったら決済は自動で取り消し。結果はメールで届く（2026-11-04 公式で確認）

## 送る文（夫から奥さまへ LINE で送る用。この下をそのまま貼る）

```
園にFAXを送る手順です（スマホだけ・5分・90円）

【はじめに1回だけ】
添付の「FAX用チラシ（2枚）.pdf」を開いて、「ファイルに保存」しておいてください。
1枚目が送信票（宛先は「園長先生」、園の名前と日付は入れていません）、2枚目がチラシです。

【電話で「FAXで」と言われたら】
「承知しました。FAX番号を伺ってもよろしいですか」
→ 番号を復唱してメモ
「いつごろお電話すればよろしいですか」
→ 日をメモ

【送り方】
1. https://www.netfax.jp/smp を開く（登録はいりません）
2. ファイルを選ぶ → 保存した「FAX用チラシ（2枚）.pdf」
3. 宛先のFAX番号を入れる。
   ⚠️ 電話番号ではなくFAX番号。送る前にメモと1字ずつ見比べる
4. FAXの上に文言を入れられる欄があれば「〇〇幼稚園 御中」
   送付状（+5円）はつけない（1枚目がこちらの送信票なので）
5. クレジットカードで支払う（2枚で90円）
6. 送れたかどうかは、あとでメールで届きます
   届かなかった場合は、お金は自動で取り消されます

【送ったら】
・Notionのアポリストのメモに「11/〇 FAX済み・〇日に電話」と書く
・約束の日に電話：「先日FAXでお送りした、ぼんぼやーじゅ通信のチラシの件でお電話しました」
・郵送OKなら、部数を聞いて夫に伝える（郵送は夫がやります。届くのはFAXと同じチラシのカラー版です）
・支払いのメールは夫に転送（経費にします）
```

## Claude（奥さまの有料版）でできること

- **FAX番号を聞きそびれたとき**: Claude に「小平市の〇〇幼稚園のFAX番号を、園の公式サイトで調べて。見たページのURLも」と頼む → **かならずそのURLを開いて、公式のページで番号を自分の目で確かめる**（AIの答えだけで送らない。違う番号に送ると、よその人にチラシが届く）
- 電話の前に、Notion の台本を Claude に貼って「この台本で、園の人の役をやって」と頼むと練習になる
- ⚠️ FAX の送信そのものは Claude ではできない（スマホでFAX45 で自分で送る）

## コンビニから送るとき（カードを使いたくないとき）

- PDF を印刷してから、マルチコピー機の「FAX」で送る（国内1枚50円・チラシは「高画質」）
- 家で刷れないときは、ネットプリントに PDF を登録して同じコンビニで印刷 → そのまま FAX
- 相手の画面には店の番号が出るが、送信票に会の名前とメールがあるので問題ない

## 夫（オーナー）がやること

- 最初に `FAX用チラシ（2枚）.pdf` と上の「送る文」を奥さまに LINE で送る
- 「郵送OK」の連絡が来たら、1週間以内に郵送（`docs/en-phone-script.md`「郵送するとき」）
- 園ごとの送信票（園名・FAX番号・日付入り）がほしいときは、いままでどおり `node scripts/make-fax.mjs`
