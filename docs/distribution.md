🚫 **いちばん下の「発行：…」の行より下には、何も置かない。**

家庭用プリンタもコンビニも紙のフチまで刷れず、「用紙に合わせる」で少し縮む。
297mm ぴったりに置いた文字は**実際に消える**（2026-09-05 オーナー報告。
問い合わせの行が、何度刷っても出なかった）。
**下端 8mm は安全帯として空けてある**（`.foot` の `padding-bottom:8mm`）。
情報を足すときは**発行の行より上**に入れること。現在の並びは
**「毎週みる街 → 問い合わせ → 発行」**。

最下段の文字から紙の下端までの距離は、これで測れる（**7mm以上を保つ**）:

```js
const t = document.querySelector('.trim').getBoundingClientRect();
const b = document.querySelector('.foot .b').getBoundingClientRect();
(t.bottom - b.bottom) / 794 * 210   // mm
```

⚠️ **版面は 297mm ぴったりで、余白がほとんど無い。**文言を足すと下が切れる
（2026-09-05 に実際に切れた）。足したら必ず刷る前に確認すること。はみ出しの測り方:

```js
document.querySelector('.trim').scrollHeight - document.querySelector('.trim').clientHeight
```

QRは300/150/100dpi で読み取り確認済み

### 🔁 市の配布サイクル（これに合わせて渡す）

**市の2課は、自分たちのタイミングで各館へ配りに行く。こちらの都合ではなく、この周期に乗せる。**

| 課 | 各館へ配りに行くタイミング | 渡す締切 |
|---|---|---|
| **市民協働・男女参画推進課**（地域センター20館＋元気村） | **毎月1日ごろ と 月の中旬** の2回 | その回に間に合う数日前まで |
| **こども若者みらい課**（児童館） | 同じ周期で合わせる | 同上 |

**今回渡した分 → 2026年9月中旬の便で配られる。**

> 📅 **次に渡すのは 2026年10月下旬。11月分として配ってもらう。**
> 10月下旬に渡す → 11月1日ごろの便に乗る、という読み。
> つまり**増刷は10月中旬までに済ませておく**必要がある。
>
> それ以降も同じリズムで回す:
> - 10月下旬に渡す → 11月分
> - 11月下旬に渡す → 12月分
> - 以降、**毎月下旬が「市に渡す月」**

**この周期の意味**: チラシは渡した瞬間ではなく、**翌月アタマに20館の棚に並ぶ**。
だから通信の内容が「その月に使える」ものである必要はなく、**マップ・カレンダー・LINE登録**という
時期に左右されない導線を前面に出しておくのが正解。日付入りのイベント告知をチラシに載せてはいけない。
