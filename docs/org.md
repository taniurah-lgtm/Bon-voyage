## 🔴 各部に渡さない仕事

**この6つは、各部にやらせない。オーナーの承認を経て、経営企画室が手でやる。**

1. **水曜9時の自動配信は続ける**（2026-09-18 オーナー判断）。
   ただし 🔴 **Routine のプロンプトに「今日の号がすでにあれば書き直さない」を入れる。**
   2026-09-16 に64人へ3通送った原因は、**合意ずみの草案があったのに Routine が上書きで
   自分の版を書いた**こと。手を止めるのではなく、**草案を尊重させる**ことで直す
2. **SNSへの投稿・返信の送信** — 読者との会話には人格と責任が要る
3. **先方への連絡**（電話・メール・訪問） — 相手は生身の人
4. **印刷の発注** — 刷り直しは実費
5. **ブランチの削除** — そもそもこの箱からはできない（プロキシが拒む）。オーナーがGitHubの画面で
6. **`reports/free/sent.log` への書き込み** — 送っていない号がホームページに出る

## ご提案の4分割から、2つ変えた理由

### ①「情報解析→裏取り」は、2つの別の仕事

2026-09-15 にオーナー自身が分けた線をそのまま使う。

- **広く浅く探す**（落とさないことが仕事） … ブランドマーケティング部と、火曜の Gemini
- **公式で裏を取る**（間違えないことが仕事） … 校閲部

**同じ担当にやらせると、探しながら「たぶん合ってる」で通してしまう。**
ブランドマーケティング部は「こういうものが出ていた」で止め、裏取りは校閲部が受ける。

### ②「総務が水曜配信の送り出しをする」は、送り出しだけ外す

台帳作りと号の組み立てまでは担当でよい。**送信だけは渡さない。**

🔴 2026-09-16 の3通配信が、まさに「自動で動くものが送った」事故だった。
前日に合意した草案があったのに、Routine が別のブランチで自分の版を書いて送り、
**降水確率90%の連休にプールを薦めた。**訂正と補足で計3通になった。

**送る前に人が紙面を読む。**これは例外を作らない。

## 呼ぶ／呼ばない の線引き

**呼ぶのは、扇状に広がる仕事だけ。**各部は毎回ゼロから始まるので、
呼ぶこと自体にコストがある。経営企画室の中でできることを外に出すと、かえって遅い。

| 呼ぶ | 呼ばない |
|---|---|
| 10件のイベントを並列に裏取り | 1件だけ確かめる |
| 協賛先を30軒洗い出す | 既にあるリードの次の一手を決める |
| 全チラシの版下を作り直す | 1文字直す |
| 大きな作業の前後の監査 | 日常のちょっとした確認 |

## 各部に共通の約束

1. **見ていないことを書かない**
2. **自分のブランチの最大値でIDを振らない。**全ブランチを `git fetch` して最大値+1
3. **commit と push はしない。**経営企画室がまとめてやる
   （ブランチが分かれた結果、9/16 の事故と E104〜E112 の全面衝突が起きた）
4. **判断に迷ったら、決めずに経営企画室へ返す**
5. 🔴 **先方に校閲をさせない**（2026-09-21・オーナー指示）

## 🔴 先方に校閲をさせない（2026-09-21・オーナー指示）

**「こう書きます」と原稿を見せるのは、確認をもらうため。検算をさせるためではない。**

2026-09-21、オーガニックフェスタで **3回続けて原稿を直された。**

| | こちらが書いたこと | 実際 |
|---|---|---|
| 1 | 子ども服の交換会・お箸づくりがある | **今年はやらない**（2024年の実績を写していた） |
| 2 | みんなの広場にゴザのスペース | **こどもワクワク広場**（みんなの広場は会場全体） |
| 3 | 14時のライブで楽器にさわれる | チラシは「ライブ＆体験」だけ。**先方が出演者に問い合わせて確かめてくれた** |

**3回とも、こちらが推測で書き、先方が調べ直した。**
**忙しい主催者の時間を、こちらの下調べに使わせたことになる。**

### やり方

| ❌ これまで | ⭕️ これから |
|---|---|
| 推測で原稿を書く → 送る → 直してもらう | **自分で裏を取る → 確実な文章にする → 「これでよろしいですか」** |

1. **公式サイト・チラシ・過去の告知で、書くこと全部の裏を取る**
2. **取れなかったものは、原稿から落とす**（推測で埋めない）
3. **落としたうえで、なお必要なものだけを質問にする。**
   **質問は「相手しか持っていない事実」に限る**
   （例: 当日申込の可否・臨時駐車場の有無 — 公開されていないもの）
4. **原稿は、確認をもらうために見せる。**「間違いがあれば直してください」と言わない

🔴 **「原稿を見せたから防げた」は、結果論。**
**防いだのは先方であって、こちらではない。**
**次の相手が同じように調べてくれるとは限らない。**
