# PR外注プラン（印刷・配布・自動化）

「多少お金をかけてでも、印刷・配布を外注して人海戦術で広めたい。できるだけ自動化したい」への調査と提案。
方針: **有料の面（印刷＋ポスティング）はオンライン完結のツール1つに寄せて自動化**し、**無料の人海戦術（掲示・転送・SNS・ジモティー）と併走**させる。

---

## 結論（おすすめ構成）

| 面 | ツール／依頼先 | 自動化度 | 目安コスト |
|---|---|---|---|
| **①印刷＋ポスティング（主力）** | **ラクスル ポスティング** | ★★★（入稿→エリア選択→決済まで全部オンライン） | A5・5,000部で 5〜8万円前後（印刷込み・配布単価約2.9円〜） |
| ②新聞折込（補助） | ラクスル 新聞折込 / 地域の折込会社 | ★★☆ | 折込料 3〜5円/枚＋印刷 |
| ③印刷だけ発注→自分/知人で配布 | ラクスル/プリントパック等のネット印刷 | ★★★（印刷）＋人手（配布） | A5・1,000部 数千円〜 |
| ④無料の人海戦術 | 児童館・図書館掲示、ママ友転送、インスタ、ジモティー地元情報 | ―（手間のみ） | 0円 |

**最初の一手のおすすめ**: ③のネット印刷で**A5チラシを少部数（500〜1,000部）刷って、児童館・支援センター・ママ友・ジモティーで手配り＆掲示**して反応を見る（＝低コストで検証）。手応えが出たら①**ラクスルのポスティングで子育て世帯セグメント配布**にお金を入れて一気に面を取る。

## ① ラクスル ポスティング（＝一番「自動化」に近い）

- URL: https://raksul.com/posting/
- **印刷から配布までオンラインで完結**：デザイン入稿 → 配布エリアを地図・市区町村で指定 → 部数決定 → 決済 → 入稿審査 → 印刷 → ポスティング、まで一括。請求書対応。
- **最少1,000部・7,898円〜**（印刷込み）。配布単価は約2.9円〜。
- **セグメント配布ができる**：ローラー配布（全ポスト投函・3〜5円/枚）に加え、**戸建て限定／集合住宅限定**などの指定が可能。**「1〜8歳の子どもがいる世帯」など属性を狙った配布**もできる＝子連れおでかけ通信と相性が良い。
- 若い子育て世帯は新聞購読率が低いので、**折込よりポスティングの方が届きやすい**。
- 配布エリアは花小金井・小平を中心に、西武新宿線沿い（田無・東久留米・久米川）まで広げられる。

**費用相場（一般値）**
- ポスティング配布単価: 3〜10円/枚（セグメントするほど高い）
- 印刷込み総額: 5〜13円/枚 → **1万枚なら5万〜13万円**
- 新聞折込: 折込料3〜5円/枚＋印刷

**シナリオ例**
- お試し: A5・3,000部・小平＋花小金井の戸建て中心 → **約2〜3万円**
- 本気: A5・10,000部・小平＋西東京＋東久留米の子育て世帯 → **7〜12万円**

## ② 新聞折込（補助的）

- ラクスルでも新聞折込を注文できる。地域の折込会社（読売・朝日系の販売所）に直接も可。
- メリット: 一度に広域。デメリット: 若い世帯は新聞未購読が多く**子育て層への到達はポスティング＜折込**。→ 主力にはしない。

## ③ 印刷だけ発注（＝安く始める・手配りと併用）

- ラクスル / プリントパック / グラフィック 等のネット印刷で**A5チラシだけ**を発注。
- A5・1,000部で数千円台。入稿は用意済みの `docs/homepage/assets/flyer-a5-print.pdf`（塗り足し3mm付き）をそのままアップするだけ。
- 刷った紙は **児童館・子育て支援センター・図書館の掲示板／自由配布ラック**、ママ友への手渡し、保育園・幼稚園まわり、地域の掲示板に置く（許可を取れる所から）。

## 「自動化」について（現実的な線引き）

- **完全自動（クリック1つで全国に勝手に撒く）は現実には不可**。入稿データの審査・エリア選定・決済は人の確認が要る（誤配布・費用の暴発を防ぐ意味でも、そのほうが安全）。
- **できる自動化＝「発注の手間を極小化」**：
  1. こちらで**入稿用PDF（塗り足し・トンボ付き／CMYK配慮）を用意** → ラクスルにアップするだけ。
  2. **配布エリア・部数・予算はテンプレ化**（例: 「小平＋花小金井の戸建て・3,000部・上限3万円」）。毎回同じ設定を使い回す。
  3. 反応測定用に**チラシのURL/合言葉を専用にして流入を計測**（例: ホームページに `?from=flyer` を付ける、専用の合言葉）。
- 定期出稿にするなら「毎月○部・○エリア」をルーチン化し、巡回と同じく決まった手順で回す。

**入稿PDFの作り直しコマンド**（文言を直したら再実行）:
```
cd docs/homepage
/opt/pw-browsers/chromium-1194/chrome-linux/chrome --headless=new --no-sandbox \
  --force-color-profile=srgb --disable-gpu --no-pdf-header-footer \

```

## ラクスル ポスティング 発注手順（オーナー用・約10分）

1. https://raksul.com/ で会員登録／ログイン（支払いはオーナーのカード）。
2. 「ポスティング」→ **A5チラシ**・部数を選ぶ（お試しは3,000部程度）。
3. **配布エリアを地図/市区町村で指定**。テンプレ↓。
4. **配布方法を選ぶ**：戸建て中心（セグメント）or 全戸ローラー。子育て世帯狙いなら戸建て＋集合を選択。
5. **入稿**：`flyer-a5-print.pdf` をアップロード → **無料データチェック**を通す。
6. 配布開始日を指定 → 決済 → 完了（あとは印刷・配布までラクスル側で進む）。

**エリア/部数/予算テンプレ（初回おすすめ）**
| 項目 | 設定 |
|---|---|
| エリア | 小平市（花小金井・小平・一橋学園まわり）＋西東京市（田無・ひばりヶ丘）の子育て世帯が多い住宅地 |
| 部数 | 3,000部（反応を見る規模） |
| 配布 | 戸建て中心のセグメント配布 |
| 予算上限 | 3万円めやす |
| 配布時期 | イベントの多い時期の**週の前半**（週末おでかけに間に合う） |

反応が出たら → 10,000部・小平＋西東京＋東久留米へ拡大（7〜12万円）。

## 流入計測（紙 → LINE/ホームページ）

静的サイト（GitHub Pages）は単体ではアクセスを記録できないため、**複数の軽い方法を併用**して「チラシがどれだけ効いたか」を測る。

1. **専用URL `bonvoya.nicomaru.tokyo/f`**（実装済み）… チラシにだけこのURLを印字。`/f/` は流入元を記録しLINEへ転送。**将来アクセス解析（GA4/Plausible等）を入れたら、このページのPVがそのままチラシ流入数**になる。
2. **LINE友だち数の増え方**… 配布日の前後で友だち追加のペースを比較（LINE公式アカウント管理画面で確認）。いちばん手軽な指標。
3. **アンケートAの「どこで知りましたか」設問**（`docs/surveys.md` / `scripts/create-forms.gs` に追加済み）… 回答者の流入元をチェックボックスで把握。
4. （任意）**チラシ合言葉**… 「LINEで『おでかけ』と送ると、今週のおすすめが届きます」等、紙にだけ書いた言葉で来訪者を識別。

> 本格計測をするなら、後日ホームページに軽量アクセス解析（GA4 か Plausible）を入れると `/f/` のPVで一発で分かる。導入もこちらで対応可能。
