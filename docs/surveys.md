# アンケート設計（ニーズ検証・機能の需要確認）

「作る前に聞く」。将来機能（カレンダー登録・出し分け・予約アラート・投稿マップ 等）の需要をアンケートで検証してから実装する。
静的サイトは回答を保存できないため、**Googleフォーム**で作成し、LINE/noteから誘導する。設問はそのままフォームにコピーして使える。

## 3つのアンケートの役割
| # | 対象 | 目的 | 配信 |
|---|---|---|---|
| A | 無料全会員 | 属性・困りごと・欲しい情報・**将来機能の需要**・価格感 | LINE無料ブロードキャスト → フォーム |
| B | 有料会員 | 満足度・継続理由・**機能の優先度**・改善点 | note メンバー限定掲示板 or LINE 1:1 → フォーム |
| C | 有料入会時 | カスタマイズ・ヒアリング（出し分けの素） | note参加後に掲示板/LINEから誘導（`docs/onboarding-form.md`） |

- トーン: 売り込まない・短い（5分以内）・匿名可。回答の冒頭に「よりお役に立つための任意アンケートです」。
- 回収率のコツ: 短く / スマホで完結 / 選択式中心 / 「回答者に◯◯（限定版ガイド等）」の軽いお礼（任意）/ 締切をゆるく設定。

## A. 無料会員アンケート（ニーズ発掘・機能検証）

**配信**: 無料LINEでブロードキャスト（下記テンプレ）→ Googleフォーム。月200通枠の1通を使う想定で、単発 or 水曜号に添える。

**設問（Googleフォーム／匿名可）**
1. お子さんの年齢層（複数可・チェック）: 0〜2歳 / 3〜6歳（未就学）/ 小学生 / その他
2. お住まいエリア（ラジオ）: 小平 / 西東京 / 東久留米 / 東村山 / 小金井 / その他（記述）
3. 主な移動手段（複数可）: 徒歩・自転車 / 電車 / 車
4. 通信は役に立っていますか（ラジオ）: とても / まあ / ふつう / あまり
5. 特に良かった回・スポットがあれば（記述・任意）
6. もっと欲しい情報（複数可）: お祭り / 花火 / 水あそび・プール / 屋内・雨の日 / 公園 / 動物 / 電車でおでかけ / キャンプ / 連休の旅行 / 味覚狩り / 映画・子連れ上映 / 習い事・イベント / その他
7. おでかけで一番困ること（複数可）: 行き先を決められない / 混雑・待ち時間 / 雨の日の行き先 / 予約の取り方・タイミング / 費用 / 移動・アクセス / その他
8. あったら使いたい機能（複数可・**将来機能の需要検証**）: 気になった予定をカレンダー登録 / 家族に合わせた出し分け / 人気予約の開始日アラート / みんなの投稿マップ / 過去号アーカイブ / その他
9. こうした“もっと便利な機能”に、月いくらまでなら払ってもいい？（ラジオ）: 0円（無料だけがいい）/ 100円 / 300円 / 500円 / それ以上
10. 自由記述（要望・応援）
11. （任意）続報や個別のご案内を受け取りたい方は、ニックネーム or 連絡手段をどうぞ

**分析の見どころ**: Q6/Q7で「刺さるジャンル・困りごと」、Q8/Q9で「有料機能の需要と価格感」。予約アラート・マップは Q8 の選択率で需要判定。

---

## B. 有料会員アンケート（満足度・優先度）

**配信**: note メンバー限定掲示板 or LINE 1:1 でフォームリンク。四半期に1回など。

**設問**
1. 満足度（5段階）
2. 特に役立っている特典（複数可）: 週2配信 / カレンダー登録（📅） / 家族に合わせた出し分け / 会員ページのカレンダー / その他
3. もっと強化してほしい（優先度・上位3つ選択）: 予約開始アラート / みんなの投稿マップ / 出し分けの精度 / 対象エリア拡大 / 過去号の充実 / その他
4. 「追跡してほしい予約・チケット」があれば（記述・**予約アラートの需要検証**）
5. 続けたい理由 / もしやめるとしたら理由（記述）
6. 自由記述

**分析の見どころ**: Q3/Q4で「次に作る機能の優先度」。Q4に具体的な予約名が集まれば「予約さきどり」を復活検討。

## C. 有料入会時アンケート（オンボーディング・カスタマイズ）

= `docs/onboarding-form.md`（家族構成・興味・範囲・頻度）を流用。**note参加のタイミングで必ず取る**。

**流れ**
1. note メンバーシップ参加 → **メンバー限定掲示板の「ご案内」に “カスタマイズ設問フォーム” のリンク**を置く（会員ページURL＋合言葉と一緒に）。
2. 新会員がフォーム回答（家族構成・興味ジャンル・対象エリア・配信頻度・自由要望）。
3. オーナーが回答を `profiles/<id>.md`（`plan: paid`）に転記 → 次の巡回から個別出し分け。
4. 細かい調整は LINE 1:1 で。

## 配信文テンプレ

### A 無料アンケート（LINE無料ブロードキャスト）
```
いつも「ぼんぼやーじゅ通信」をご覧いただきありがとうございます🎈
もっとお役に立てるよう、かんたんなアンケート（5分・任意）にご協力いただけたら嬉しいです。
お住まいのエリアや「こんな情報がほしい」を教えてください。今後の内容づくりに生かします。
▼アンケート（匿名でOK）
〔Googleフォームのリンク〕
よい週末を、ご家族で🌿
```

### B 有料アンケート（note掲示板 / LINE 1:1）
```
いつも応援ありがとうございます🎈
会員のみなさま向けに、満足度と「次に強化してほしいこと」を伺うアンケートです（5分・任意）。
いただいた声から優先して改善します。
▼アンケート
〔Googleフォームのリンク〕
```

### C 入会時（note掲示板ご案内に追記する1文）
```
▼よりあなたのご家庭に合わせるため、こちらのカスタマイズ設問にもご記入ください（任意・5分）
〔Googleフォームのリンク〕
```

## 運用メモ
- フォームは3つ別々に作る（回答が混ざらない）。回答はGoogleスプレッドシートに自動保存。
- 個人情報（連絡先）は宛先管理のみに使い、`profiles/` には書かない（プライバシー方針）。
- 集計結果は `docs/` にサマリを残し、機能の実装是非（予約アラート/マップ 等）の判断材料にする。
