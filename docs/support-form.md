# 応援（サポーター）申込フォーム — 質問一覧

ホームページ「応援する」ボタンの飛び先にするGoogleフォームの中身。
Googleフォームを新規作成し、以下をコピーして質問にする。作成後の「送信 → リンク」でURLを取得し、
Claudeに渡すと「応援する」ボタンに差し込む。

※連絡先・実名は配信/連絡にのみ使い、リポジトリには保存しない（プライバシー方針は profiles/README.md 準拠）。

## フォーム説明文（冒頭）
> 【ぼんぼやーじゅ通信 応援サポーター お申し込み】
> いつもお読みいただきありがとうございます。月々300円で通信を応援いただける方の受付フォームです。
> お礼として、週2配信・会員ページの「おでかけカレンダー」（ワンタップで自分のカレンダーに追加）・カスタマイズ等をご用意しています（一部は準備中）。
> 無料通信はこれからもずっと無料です。いつでも解約できます。

## 質問
1. **ニックネーム**（記述・必須）
2. **最寄駅**（記述・例: 花小金井）
3. **お住まいの市区町村**（記述・例: 小平市）
4. **お子さんの年齢**（記述・例: 6歳・4歳・2歳）
5. **興味のあるジャンル**（チェックボックス・複数可）：夏祭り / 花火 / プール・水あそび / キャンプ / 動物園・水族館 / 屋内あそび場 / 味覚狩り / 紅葉 / イルミネーション / 博物館・科学館 / 地域のお祭り / スポーツ観戦
6. **ほしい情報の範囲**（ラジオ）：近所だけ / 市内 / 多摩地域全体 / 多摩＋都心も / 車での遠出も
7. **平日のおでかけ**（ラジオ）：土日のみ / 平日も可
8. **受け取り方法と連絡先**（記述）：LINE（友だち追加のうえ表示名）/ メールアドレス
9. **お支払い方法の希望**（ラジオ）：〔※選んだ集金方法に合わせて記載。例〕 PayPay / 銀行振込 / クレジットカード
10. **確認事項への同意**（チェックボックス・必須）：
   - 月額300円（税込）であることに同意します
   - 特定商取引法に基づく表記・免責事項を確認しました（→ リンク）
   - 一部の特典（おでかけマップ等）は準備中であることを理解しました

- 実名・連絡先はプロフィールに書かず、フォーム回答シートで別管理。
