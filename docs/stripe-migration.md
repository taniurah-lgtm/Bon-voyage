# 有料サポーターの決済を note → Stripe に移す

> ⚠️ **このドキュメントは廃止・凍結された（2026-09-04）。**
> 月額制度は廃止し、読者獲得とスポンサー探し（BtoB）に切り替えた。
> 現行の方針は **`docs/strategy-2026-09.md`**。以下は判断の経緯として残している。

**判断（オーナー 2026-09-01）**: 読者が**アカウント登録なしで、リンクから即申し込める**ことを優先する。
特商法で住所・電話の開示請求が来た場合は**開示に応じる**方針で合意済み。

---

## 1. なぜ移すか

| | 読者の手間 | 手取り(月300円) | 個人情報 |
|---|---|---|---|
| note メンバーシップ | **noteの会員登録が必要** | 決済5%＋プラットフォーム10% → **約257円** | note社の情報を表示できる（Q18） |
| **Stripe** | **リンク→カードのみ。**Apple/Google Pay対応端末なら数タップ | 決済3.6%＋Billing0.7% → **約287円** | **請求されたら開示**（省略表示は可・Q15/Q17） |

> **note を選んでいた理由は「特商法をnoteに内包できる」ことだった**（`docs/paid-roadmap.md`）。
> しかしその後**合言葉ゲートの会員ページ**を作ったため、noteのメンバー限定投稿機能は使っていない。
> **必要なのは「決済」と「合言葉を渡すこと」だけ**なので、決済だけStripeでよΩい。

## 2. 特商法（確認済み・2026-09-01）

消費者庁「通信販売広告Q&A」で確認した:

- **Ｑ15（氏名）／Ｑ17（住所・電話番号）**: 消費者からの請求によって広告表示事項を記載した書面または
  電子メール等を**「遅滞なく」提供することを広告に表示し、実際に提供できる措置を講じている場合は、
  表示を省略できる**
- **Ｑ19**: 私書箱は不可。「現に活動している住所」であること
- **Ｑ18**: プラットフォーム事業者やバーチャルオフィスの住所を表示する方法もあるが、
  **プラットフォームの住所を使えるのは「取引がそのプラットフォーム上で行われる」場合**。
  → **Stripe直（自サイトで申込）では使えない。**noteを離れると、この道は閉じる

**`docs/homepage/tokushoho.html` の現状**

- ✅ 所在地・電話番号は「ご請求をいただいた場合、遅滞なくメールにて開示いたします」→ **要件を満たす。そのまま使える**
- ⚠️ 「遅滞なく」とは**申込みの意思決定に先立って十分な時間的余裕をもって**提供すること。
  → **請求メールに気づける状態を保つこと**（`tokyo.papa.home@gmail.com` を見落とさない）
- ⚠️ **販売事業者名が「ニコマル」（屋号）のみ。**消費者庁は「屋号のみの表示は認められない／個人事業者は
  戸籍上の氏名」としている。**運営統括責任者に実名（谷裏 愛）があるため実質は満たしていると読めるが、
  気になるなら「販売事業者名」欄も実名にするか、氏名も省略方式に統一する**

## 3. 書き換えが必要な箇所（tokushoho.html の4か所）

| 欄 | 現在 | Stripe移行後 |
|---|---|---|
| 販売価格 | 「note の仕様上、ご参加中のプランの月額はあとから変更されません」 | note言及を削除 |
| お支払い方法 | 「クレジットカード／PayPay」「note株式会社が提供する…」 | 「クレジットカード（Stripe）」。使える国際ブランドを記載 |
| お支払い時期 | 「note のマイページ『購入・支払い履歴』で確認」 | 「Stripeから届く領収書メール、またはカスタマーポータルで確認」 |
| 解約について | 「note の管理画面からいつでも解約」 | **「Stripeのカスタマーポータルからいつでも解約」** |
| 動作環境 | 「LINE／メール／Webブラウザ」 | 変更不要 |

> 🔴 **順番を間違えない。**Stripeが動く前に tokushoho.html を書き換えると、
> **実際と違う支払方法を掲示する**ことになる。**Stripeの決済リンクが完成した日に、同時に切り替える。**

## 4. 手順（オーナー作業）

1. **Stripeアカウントを作る**（stripe.com・無料）。本人確認と入金口座の登録
2. **商品を作る**: 「ぼんぼやーじゅ通信 応援サポーター」／**月額300円（税込）**／継続
3. **Payment Link を発行**（ノーコード）。これが申込URLになる
4. ⚠️ **カスタマーポータルを有効にする**（設定 → 請求 → カスタマーポータル）。
   **これを入れないと読者が自分で解約できない。**「いつでも解約できます」と書いている以上、必須
5. **決済後のリダイレクト先**を、Payment Link の設定で
   **「お申し込みありがとうございます」ページ**に向ける（下記5）
6. 完了したら連絡 → こちらで tokushoho.html とホームページのボタンを差し替える

## 5. 合言葉の渡し方（要設計）

いまは「note のメンバー限定投稿で合言葉を知らせる」方式。Stripeにはその場が無い。

**案A（推奨・手動）**: 決済完了ページに「合言葉はメールでお送りします」と表示し、
Stripeの通知を見て**1:1で送る**。人数が少ないうちはこれで十分。確実
**案B（自動）**: 決済完了ページ自体に合言葉を書く。手間ゼロだがURLを知られると漏れる
**案C（将来）**: Stripe Webhook で自動送信。人数が増えてから

> **合言葉はリポジトリに保存しない**（既存ルール）。

## 6. 今やらない判断もある

有料会員は現在**0人**。手数料差は10人で月300円程度。
**「摩擦を減らす」効果が出るのは、申し込む人が実際に現れてから。**
9/23のサポーター案内の前にStripeを用意できるなら意味があるが、
**間に合わないなら note のまま案内を出し、あとで移す**のでもよい（読者にはURLが変わるだけ）。
