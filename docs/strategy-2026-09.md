### なぜこの形が筋が通っているか

読者59人の段階で個人課金を始めると、**一番効く資産（信頼と読者数）を、一番安い値段で削る**ことになる。
月300円 × 現実的な転換率1〜2% ＝ **月200〜400円**。その額のために、通信とホームページの一番目立つ場所を
「お金の話」に使い、身内・友人が読むという前提のトーンを崩す。割に合わない。

一方スポンサーは**1社で桁が変わる**。ただし、いま出せる数字（到達59）では売り物にならない。
**だから読者獲得が先**という順番になる。この決定は「収益をあきらめる」ではなく、**順番を直した**ということ。

## 3. 読者獲得に全振り、の中身

「全振り」は**通信の中身を変えない**という意味でもある。読者が増えるのは、
役に立つ号が毎週きちんと届いたときだけ。以下は**やらないこと**の確認でもある。

### 通信・ホームページのトーン（変更なし・むしろ徹底）

- 通信に**お金の話を一切入れない**。フッターはホームページ導線のみ
- ホームページに価格を置かない。**「応援」という言葉も当面は出さない**
- 「急いで」「損」「ママ目線で厳選」は引き続き使わない

### いま効いている獲得経路（続けるもの）

| 経路 | 状態 |
|---|---|
| 地域センター20館・児童館3館へのチラシ | 稼働中。**次は10月下旬に市へ渡す（11月分）** |
| LINEオープンチャット（花小金井・田無） | 告知済み |
| あすぴあ 登録団体（第254号） | 登録済み。掲示・団体紹介の枠を使える |
| 多摩六都科学館 | プレスリリース送付の合意あり。**掲載時は指定の一文を必ず添える** |
| ホームページ（bonvoya.nicomaru.tokyo） | 稼働中。検索流入はこれから |

### 次に手を付ける価値がある経路

- **計測を入れる**（`analytics.js` の `SITE` が空のまま）。どこから来ているか分からないまま
  獲得に全振りしても、何が効いたか永久に分からない。**獲得に全振りするなら、これが最優先**
- **チラシのQRを設置場所ごとに分ける**（`/f/jidokan` など）。増刷は**10月中旬まで**なので、それに間に合わせる
- 幼稚園・保育園・小学校の**PTA / おたよりへの掲載**（1件決まると桁が違う）
- Threads・Instagram の地域アカウントへの声かけ（@suzu_kids.navi に打診済み・返信待ち）

## 4. BtoB（スポンサー探し）

### いまの正直な立ち位置

到達59人。**この数字で広告枠は売れない。** 数字で売ろうとすると足元を見られるか、断られる。
売れるのは数字ではなく、**「この地域の子育て家庭に、毎週きちんと読まれている紙とLINEがある」という事実**と、
**市の20館＋児童館3館に置かれているという流通**のほう。

### したがって、最初の1社は「金額」より「実績」を取りに行く

1. **1社目は無償または実費で載せる。** 掲載実績・掲載面の見本・先方の声を作る
2. 2社目以降に、その見本を持って金額の話をする
3. 金額を先に決めない。**相場の調査は、見本ができてから**（いま相場から入ると、
   到達59という数字だけで値付けされる）

### 声をかける先の候補（地元・子育て導線が重なるところ）

- 習い事（スイミング・体操・英語・音楽・学習塾）
- 小児歯科・矯正歯科・整骨院・産後ケア
- 写真スタジオ（七五三・入園入学の季節性が通信と噛み合う）
- 工務店・不動産（**ダイワ住友・そのだ不動産に打診済み、返信待ち**）
- 地域の商店会・イベント主催者

### 渡せるもの（枠の候補）

| 枠 | 中身 |
|---|---|
| 通信内 | 号のいちばん下に1枠。**記事と混ぜない**（混ぜると通信の信用が落ちる） |
| ホームページ | 協賛としてロゴ・1行紹介 |
| チラシ | 裏面に「協賛」欄。20館＋児童館3館に置かれる紙に載る |
| おでかけマップ | 施設・店舗としての掲載（有料広告ではなく、地域の情報として） |

> ⚠️ **通信の記事欄は売らない。** 協賛と記事を混ぜた瞬間に、この通信の値打ちが無くなる。
> 枠は必ず「協賛」と明示して分ける。

## 6. この決定のいちばん大きな帰結 — 配信コスト

**課金をやめた以上、LINEの月5,000円を払う理由が無くなった。**

| | 費用 | 上限 |
|---|---|---|
| LINE フリー | ¥0 | **月200通** → 週1配信で**読者50人が限界** |
| LINE ライト | **月5,000円** | 月5,000通 → 週1で読者1,250人 |
| メール（Brevo 無料） | **¥0** | **購読者無制限・月9,000通・1日300通** |

いまの到達59人では、**LINEフリーでは週1配信すら回らない**（59×4＝236通 > 200通）。
読者獲得に全振りするなら読者は増える。増えるほどLINEの費用は上がり、**収益はゼロのまま**。

→ **メール配信への移行を、いま真剣に検討する段階に入った。**
手順と受け皿は `docs/mail-plan.md` に用意済み（ホームページの受け皿は
`BV_MAIL_FORM_URL` を入れるだけで表示される）。

**当面の選択肢は3つ:**

| 案 | 中身 | 向き |
|---|---|---|
| A | LINE ライトに課金（月5,000円の持ち出し） | 読者の使い勝手は最良。**スポンサーが決まるまでの持ち出しを許容できるなら** |
| B | LINE を隔週にしてフリーのまま | 費用ゼロ。**ただし読者獲得に全振りする方針と矛盾する**（接触が半分になる） |
| C | メールへ移行（Brevo 無料） | 費用ゼロで無制限に増やせる。**移行の手間と、開封率の低下を飲む** |

> 読者獲得に全振りするなら **A か C**。B は方針と合わない。
> **決めるのはオーナー。** 決まりしだいこのファイルに追記する。
