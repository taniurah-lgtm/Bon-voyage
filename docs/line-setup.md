# LINE連携のセットアップ手順(初回のみ・所要15分)

イベントレポートを家族のLINEに届けるために、無料のLINE公式アカウント(Messaging API)を1つ作り、アクセストークンをClaude Codeの環境変数に登録します。

## 1. LINE公式アカウント(Messaging APIチャネル)を作る

1. https://developers.line.biz/ja/ を開き、普段のLINEアカウントでログイン。
2. 「プロバイダー」を新規作成(名前は例: `家族イベント`)。
3. プロバイダー内で「新規チャネル作成」→「Messaging API」を選択。
   - ※2024年以降は先に https://entry.line.biz/ でLINE公式アカウントを作成し、
     LINE Official Account Manager(https://manager.line.biz/)の
     「設定 → Messaging API」から有効化する導線の場合があります。画面の案内に従ってください。
   - チャネル名: 例 `ぼんぼやーじゅ通信`(家族に表示される名前)
   - 業種: 個人 / その他 でOK
4. 作成できたら LINE Developers コンソールでチャネルを開く。

## 2. チャネルアクセストークンを発行する

1. チャネルの「Messaging API設定」タブを開く。
2. 一番下の「チャネルアクセストークン(長期)」の「発行」を押す。
3. 表示された長い文字列をコピーする(これが `LINE_CHANNEL_ACCESS_TOKEN`)。
   ⚠️ このトークンは秘密情報。リポジトリやチャットに貼らないでください。

## 3. 応答設定(2026-09-01 に全面的に変更・設定済み)

LINE Official Account Manager(manager.line.biz)→ 設定 → 応答設定

| 項目 | 設定 | 理由 |
|---|---|---|
| **チャット** | **オン** | 読者からのメッセージが管理画面に届く。**地図に載せる運用の前提** |
| **あいさつメッセージ** | **オン** | 友だち追加時にカレンダー・マップを案内し、**「送ってください」と誘う** |
| **Webhook** | **オフ** | ⚠️ **オンにしない。**転送先のサーバーが無い。オンにすると受信の行き先が
変わり、チャットと応答メッセージが動かなくなる。**配信(送信)にWebhookは不要** |
| **応答メッセージ** | **オン** | メッセージをくれた人へ自動でお礼と案内を返す |
| チャットの応答方法 → 応答時間内 | **手動チャット＋応答メッセージ** | これにしないと**日中のメッセージに自動返信が出ない**(時間外だけ出る) |
| 応答時間 | **実質24時間** | ⚠️ **通知は応答時間と連動する。**時間外はチャットの通知が飛ばない |

> 💡 **あいさつメッセージと応答メッセージは、メッセージ通数にカウントされない(無制限)。**
> 無料枠200通を消費せずに使える唯一の配信路。**枠が苦しいときほどここを使う。**

### 受信に気づくための仕組み(必須)

- **スマホアプリ「LINE公式アカウント」を入れて通知をオンにする。**
  ブラウザ版(manager.line.biz)は**チャット画面を開いている間しか通知が来ない**
- スマホ本体側でもこのアプリの通知を許可する
- 保険として**メール通知**もオンにしておく(機種変更やOS更新で通知が切れることがある)

> ⚠️ **読む責任が発生している。**応答メッセージで
> 「おすすめの場所はマップに加えさせていただきます」と**約束している**。
> 気づかず放置すると、返信が無いより印象が悪い。**自動返信と通知は1セット。**

### あいさつメッセージの中身(2026-09-01 差し替え)

- **おでかけガイドの案内をやめた**(導線から外したページだった)
- **おでかけカレンダーとみんなのおでかけマップ**を案内
- **「おすすめの場所があれば、このトークに送ってください」**を明記
  → これが無いと、マップがあることも送ってよいことも伝わらない
- 「はじめて友だち追加されたときにのみ送信」に**チェックを入れる**(ブロック解除での再送を防ぐ)

## 4. Claude Code の環境変数にトークンを登録する

1. https://claude.ai/code (またはClaudeアプリ)で、このセッションが動いている
   **環境(Environment)の設定**を開く。
2. 環境変数に以下を追加:
   - 名前: `LINE_CHANNEL_ACCESS_TOKEN`
   - 値: 手順2でコピーしたトークン
3. 保存。次回セッション起動(次の巡回)から有効になります。

## 5. 家族が友だち追加する

1. LINE Developers の「Messaging API設定」タブ(またはOfficial Account Manager)に
   QRコードがあるので、家族全員のLINEで友だち追加。
2. レポートは「ブロードキャスト送信」なので、友だち追加した人全員に届きます。

## 6. 動作確認

Claudeに「LINEテスト送信して」と伝えると、`scripts/line_report.sh` でテスト
メッセージを送ります。家族のLINEに届けば完了です。

## 備考

- 無料プランの送信上限は月200通(受信者ごとに1通カウント)。
  週2回 × 家族分でも十分収まりますが、家族5人×週2なら月約45通です。
- トークンを再発行した場合は環境変数を更新してください。
- LINE側からの返信はこの仕組みでは受信できません。イベントの承認
  (カレンダー登録)はClaudeへの返信で行います。

## 📏 1通に収める文字数（★2026-09-20 決着）

🔴 **9/16の訂正版が2通に分割され、「バル�」「�ンなど」と文字化けした。**
**原因は `scripts/line_report.sh` が bash の `${text:offset:max}` を使っていたこと。**
**この箱は LANG が未設定で、bash は文字列をバイトとして数える。**
2,034文字（1通で余裕）の号が **5,035バイト**と数えられて分割され、
**切れ目がマルチバイト文字の途中に入った。**

→ ✅ **修正済み。**分割は python3 に任せ、**文字単位＋行の切れ目**で割るようにした。

### 数字

| | |
|---|---|
| **LINEの上限** | **1通 5,000文字**（textメッセージ） |
| **スクリプトが分割する値** | **4,500文字**（`line_report.sh` の `MAX`） |
| 🔴 **原稿の安全上限** | **4,000文字。**ここを超えなければ**絶対に2通にならない**<br>訂正のおわび文（約200字）を頭に足しても余る |
| **実際の号** | **1,700〜2,100文字**（2026年8〜9月の実測） |

### 🔴 いちばん大事なこと — 上限を「バイト」で数えない

**台帳に「全体4,400字の上限」と書いてあったが、そんな上限は存在しない。**
**`wc -c`（バイト数）を字数と読んでいた。**日本語はUTF-8で**1文字3バイト**なので、
**実際の2.5倍ほど厳しい上限を自分に課して、内容を削っていた。**

**数えるときは必ず文字で数える。**

```bash
# ⭕️ 文字数（これが正）
python3 -c "print(len(open('reports/free/2026-09-23.md',encoding='utf-8').read()))"

# ❌ wc -c はバイト数。日本語では約2.5倍に出る
```

### 🔴 結論 — 上限は「9/2便」。1,468文字 / 42行（2026-09-20 オーナー決定）

**4,000文字は「2通に割れない」ための技術上限で、読みやすさの上限ではない。**
**読みづらいという指摘を受けて、実際の号で上限を決めた。**

| 号 | 文字 | 行 | |
|---|---|---|---|
| 8/26 | 1,749 | 47 | |
| 🔴 **9/2** | **1,468** | **42** | **← これを上限にする** |
| 9/9 | 1,525 | 49 | |
| 9/16 | 1,780 | 57 | **長すぎた** |

🔴 **効いてくるのは文字数ではなく行数。**
**1行あたり34〜37文字で書いているので、行が先に尽きる。**

### 1号の予算

| | 文字 | 行 |
|---|---|---|
| 上限 | **1,468** | **42** |
| ヘッダー＋天気 | −135 | −4 |
| フッター（※〜AI案内〜HP導線） | −178 | −5 |
| 🔴 **本文に使える** | **1,155** | **33** |

**本文の1本は 240〜340文字 / 8〜10行。**つまり**入るのは3本まで。**
**4本目からは「イベント先取り情報」に2行で落とす。**

- **一推し**（10行・📍地図つき。地図は一推しだけ）
- **本文 2本**（各8〜9行）
- **先取り**（1件2行。2〜3件）

**4本目を本文で入れたくなったら、どれかを先取りへ落とすか、次号へ送る。**
**号をふくらませない。**

### 数え方

```bash
# ⭕️ 文字数（これが正）
python3 -c "import re;s=re.sub(r'<!--.*?-->','',open('reports/free/2026-09-23.md',encoding='utf-8').read(),flags=re.S).strip();print(len(s), len([l for l in s.split(chr(10)) if l.strip()]))"

# ❌ wc -c はバイト数。日本語では約2.5倍に出る
```

**訂正版を出すときも、おわび文を足して2通に割れないか、送る前に数える**（技術上限は4,000文字）。
