## 書体
埋め込み済み: Mochiy Pop One／Zen Kurenaido／Zen Maru Gothic／Zen Kaku Gothic New／DejaVu Sans（◎✕などの記号の一部）。IPAゴシックは混ざっていない。

## 白黒
preview/spread-4-5-mono.png で確認。種類は色に加え、形（四角・家形・丸・ひし形・六角）と文字（本・児・こ・出・ひ）、枠線（実線・太線・破線・点線・二重線）でも分かる。
