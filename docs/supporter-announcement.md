## ⚠️ 9月は水曜が5回ある(9/2・9/9・9/16・9/23・9/30)

無料枠は**月200通**。ブロードキャストは**1回につき到達人数ぶん**を消費する。

| 到達人数 | 5回配信の消費 | 200通に収まるか |
|---|---|---|
| 40人 | 200通 | ぎりぎり(余白ゼロ) |
| **47人(現在)** | **235通** | ❌ **35通オーバー** |
| 50人 | 250通 | ❌ 50通オーバー |

**つまり「50人超え」を待たなくても、9月は今の人数のままで無料枠を超える。**
これは人数の問題ではなく**9月のカレンダー(水曜5回)の問題**。

**9月の選択肢:**
1. **ライトプラン(月5,000円/15,000通)に切り替える** … 通信を減らさない。サポーター案内の前提と一致
2. **9月だけ4回に減らす**(どこか1回スキップ) … 200通ちょうどで余白ゼロ。増員で即破綻
3. 何もしない … 5回目が送信エラーになる(**過去4回の「配信が落ちる」事故と同じ形**)

→ **1を推奨。**そのうえで「50人超えの次の配信」でサポーター案内を1回出す。
   もし9/2時点でまだ50人以下なら、**切り替えだけ先に行い、案内は50人超えまで待つ**(オーナー承認どおり)。

## 文面(そのまま貼る。◯◯は送信時の実数に置き換える)

```
■ おしらせ

LINEの無料枠は月200通までで、1回お届けするごとに人数ぶんを使います。

今月から有料の配信プラン(月5,000円)に切り替えます。

通信はこれまでどおり、毎週水曜に無料でお届けします。ここは変えません。
もし「続いてほしい」と思っていただけたら、
月300円のサポーターとして支えていただけると、とても助かります。
→ https://bonvoya.nicomaru.tokyo/
```

### 文面のチェック(トーン規約 CLAUDE.md「フリーミアム運用」に照らす)

- ✅ 急かす語(「急いで」「損」「今だけ」「残り◯名」)を使っていない
- ✅ 「無料でお届けします。ここは変えません」で**不安を先に消している**
- ✅ 金額を1回だけ・事実として書き、**申込を迫っていない**(リンクを置くだけ)
- ✅ 身内・友人が読んでも気まずくならない長さ(9行)
- ⚠️ 「今月から」は**送信月に合わせて**「来月から」に直すこと(切替時期による)

## 送信時の手順

1. `insight/followers` で **targetedReaches** を確認し、**50を超えていること**を確かめる
   ```bash
   curl -sS -H "Authorization: Bearer $LINE_CHANNEL_ACCESS_TOKEN" \
     "https://api.line.me/v2/bot/insight/followers?date=$(date -d yesterday +%Y%m%d)"
   ```
2. 文面の `◯◯人` をその実数に置き換える(フォロワー数ではなく**到達可能数**を書く)
3. **その号だけ**、末尾のホームページ導線フッターの直前にこのブロックを入れる
4. 配信後、この文書に「**送信済み: YYYY-MM-DD**」と追記する。**2回目は出さない**
5. 翌週の号でブロックを外したことを確認する
