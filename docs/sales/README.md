# 売れる方法論 — 地域で、小さなお店・教室に頼むコツ（非公開・2026-11-23〜）

オーナー「私もあなたも、営業のコツ・人の心を読むところが下手。地域密着の営業のコツ、人がお金を出してもいいと思うコツを、本・ブログ・YouTube から集めて、方法論を蓄えるのが先」→ 進め方を了承（2026-11-24）。

## 学ぶことは3つ

1. **小さなお店・教室は、何にならお金を出すのか**（生徒が来る／地域で知られる／手間がかからない のうち、相手がいちばん困っていること）
2. **地域の小さな媒体は、どう広告を売ってきたか**（ホットペッパー・タウン誌・地域のフリーペーパー）
3. **初めての相手に信頼されて、断られにくい頼み方**（人の心の動き・聞き方・頼み方）

## 実地で聞くこと — 「ゆるっとお仕事ひろば」リアル会（東久留米・清瀬周辺の事業者のオープンチャット・91人）

**聞き方: こちらの商品の感想ではなく、相手が実際にしたことを聞く**（「あったら使いますか？」は「いいですね」で終わる）。

① 教室・お店の人に
- いちばん最近来たお客さん（生徒さん）は、最初どこで知って来た？
- 宣伝にお金を払ったことは？ 何に、いくら？ 続けている？ やめたのはなぜ？
- 効いたと感じた宣伝は？（Instagram・チラシ・口コミ・掲載サイト）
- 新しいお客さんが、どの宣伝で来たか、どうやって分かる？
- 「載せませんか」と声をかけられたとき、聞くか断るかは何で決める？
- 子育て中の家庭に知ってほしいとき、いま何を使っている？

② 主催の方に
- 91人まで増えたきっかけは？
- 「ゆるっと案内所」（メンバーの一覧）に通信を登録してよいか
- メンバーの子ども向けのワークショップ・イベントを、通信で紹介してよいか（公式の告知があるものを、無料で）

③ その場で探す
- 子ども向けの教室・習い事をしている人（→ ①を中心に聞く。スクールガイドは聞かれたら）
- 東久留米・清瀬の子育て家庭がよく見ている情報

自己紹介（30秒）: 「小平・花小金井で、子育て中の家庭向けに、週末のおでかけ情報を無料のLINEで毎週お届けしています。いま230家庭くらいです。東久留米や清瀬のお子さん向けのワークショップやイベントがあれば、通信で無料でご紹介できるので、ぜひ教えてください」

気をつけること: その場で売り込まない（会の決まり「具体的なお仕事のやり取りは当事者同士で」）。値段は聞かれたときだけ。連絡先は渡されたときだけ。

### ミニ講座（住宅の営業の方・「営業力強化」）— 聞き取るところ

講座の告知の画像: 「売るのではなく、困りごとを解決する」「なぜ家を欲しがるのかを考える」「体感させる」「ゴールから逆算」「顧客理解 → 課題整理 → 体験設計 → 価値提案 → 契約」。

| 講座の言葉 | 私たちなら |
|---|---|
| なぜ家を欲しがるのか | **なぜ教室は載りたいのか**（生徒を増やす／体験会を埋める／春の入会に向けて知られる）。お手紙を「先生の困りごと」から書き始める |
| 体感させる | その教室のカードの案を添える（いまのやり方）＋実際の週の号のページでどう見えるかまで見せる |
| ゴールから逆算 | 教室のゴール＝春の入会。「3月末まで無料」はここから逆算した形 |
| ヒアリング・ニーズ発掘 | 頼む前に聞く（上の質問リスト） |

講師の方に聞けそうなこと:
- 「なぜ家が欲しいのか」を聞き出すとき、最初の5分でどんな質問をするか
- 体感させる提案で、いちばん反応がよかったものは
- 断られたあと、紹介につなげるには

🔵 **住まいパック（ニコマル・`docs/b2b/README.md`）の勉強にもなる**: 住宅の営業の人は、物件のまわりの子育て環境シートがいちばん役立つ相手。**その場では売り込まない**。聞くなら「土地や周りの環境（公園・学校・子育て施設）は、お客様にいまどう見せていますか？何を使っていますか？」（いましていることを聞く）。興味があれば名刺だけいただき、あとで見本を送る
