### 🔴 #1 を最優先にした理由（Notion では「高」だったが、もう「最優先」）

Notion の行は **47人**で計算していた。いまは **64人**。

- LINE 無料枠（コミュニケーションプラン）＝ **月200通**。broadcast は**受信者ごとに1通**
- 64人 × 週1 = **月256通**（水曜が5回ある月は **320通**）
- 9月の水曜は 9/2・9/9・9/16・9/23・9/30 の**5回**
  → 累計 9/2=64 / 9/9=128 / **9/16=192** / **9/23=256 ← ここで枠を超える**
- 無料プランは**超えたぶんを送れない**（追加購入ができない）。
  **9/23 か 9/30 の号が、何も言わずに届かなくなる。**

→ **ライトプラン（月5,000円 / 5,000通）**に上げるか、その月だけ配信を間引くかを**9/23 までに決める**。
　読者はこれからも増える前提なので、実質は「いつ上げるか」だけの問題。
　`docs/freemium-plan.md` の「50人まで無料」という記述も、**64人の現実に合わせて直す**。
