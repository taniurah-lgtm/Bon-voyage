# Instagram リール作成のための引継書

**この1枚を別の会話に丸ごと貼れば、リールの構成づくりを任せられる。**
オーナーは、撮ってきた写真・動画と「今週これを出したい」を渡すだけでよい。

- 作成日: **2026-09-13**
- 前提となる方針: `CLAUDE.md` / `docs/strategy-2026-09.md`（読者獲得に全振り）
- 姉妹の引継書: Threadsの返信は `docs/threads-reply-kit.md`

---

## 0. 🔴 先に、リールを作る前に知っておくべき制約2つ

### 制約① 素材がほぼ無い

`social/photos/` に入っているのは **`_default/park-hero.jpg` の1枚だけ**。
`social/photos/README.md` にカテゴリ（park / water / festival / indoor / museum …）の
受け皿は用意してあるが、**中身が空。**

**つまり、いまリールを作るなら「まず撮りに行く」から始まる。**
構成だけ先に作っても、映すものがない。

### 制約② 公共施設の館内は、たいてい撮れない

いちばんの持ちネタ（おひさまひろば・児童館・中央図書館）は**屋内の公共施設**で、
**館内撮影は原則できない**と考えるべき（他の利用者の子どもが写る）。

→ **撮れるのは「外観・道のり・看板・手元・後ろ姿」。**
→ **実写がなくてもリールは成立する。**文字＋写真のスライド型で組む。

## 1. 何のために作るのか

| | |
|---|---|
| 目的 | **LINEの友だちを増やす。**それ以外の指標（再生数・いいね）は途中経過にすぎない |
| いまの読者 | **LINE 64人**（2026-09-06時点）。上限1,000人 |
| 宛先 | **小平市の未就学児・小学生のいる家庭** |
| 載せる範囲 | **花小金井からだいたい30分で行ける場所。**市境はまたぐ |
| 書き手 | 花小金井に住む、3人の子どもがいる親（個人） |

### 🔴 Instagramは本文のリンクが押せない

キャプションにURLを書いても押せない。**プロフィールのリンク（bonvoya.nicomaru.tokyo）へ誘導するしかない。**
→ リールの最後に「プロフィールのリンクから」の一言が要る。
→ 押し売りにしない。`CLAUDE.md`「お金・申込を前面に出して急かさない」。

### リールに時間を使う根拠（と、その限界）

2026-09-10、花小金井のネイルサロンが自力集客2ヶ月の実数を公開していた:
**Instagram 5人 / Google検索 5人 / Threads 1人。**
→ **InstagramはThreadsの5倍。**リールに投資する根拠はある。
→ ただし**1軒の事例**で、業種も目的も違う（客を取る／読者を取る）。断定はできない。
→ そして**リール1本の制作時間は、Threadsの返信10件分**くらいかかる。**本数を追わない。**

## 3. 🔒 リールに絶対に出さないもの

`CLAUDE.md`「公開物に書かないこと」がそのまま効く。**リールは公開物。**

- **巡回の仕組み・頻度・自動化の有無・使っている道具や技術の名前**
- **巡回先の一覧そのもの**（`docs/sources.md` の構造・優先度）
- **台帳・スクリプト・ファイル名・内部の判定理由**
- **計測の仕組み**（`/f/xxx` の配布先コード、解析の設定）
- **読者数を実際より多く言う**（64人。盛らない）

⭕️ **書いてよいのは結果と根拠だけ。**
「市や施設の公式ページで一件ずつ確かめています」「まとめサイトからの転載はしません」
「各項目に公式サイトのURLを付けています」

## 4. 🔴 言ってはいけないこと・言ってよいこと

| | |
|---|---|
| ❌ | **「自分の足で確かめて」「実際に行って」**（イベント情報は現地確認していない。嘘になる） |
| ⭕️ | **実際に行った場所については「行ってよかった」と書いてよい**（おでかけマップ枠。地元の家庭の持ち寄りなので事実） |
| ❌ | 「急いで」「損」「ママ目線で厳選」 |
| ❌ | 施設の案内に書いていない子連れ情報を断定する。**「(要確認)」を付ける** |
| ❌ | 効果の約束、掲載時期の確約 |

**リールは映像なので、この線がはっきり出る。**
**行っていない場所の映像は撮れない**＝リールにできるのは、**実際に行った場所だけ**。
これは制約であると同時に、この媒体でいちばん強い部分でもある。

## 5. 🔴 法務（映像だからこそ効く）

### 著作権
- **他人の写真・動画は使えない。**公式サイトやSNSから拾うのは侵害
- 使えるのは**自分で撮ったもの**か、**商用利用OKのライセンス素材**（Unsplash / Pexels / 写真AC など。規約を都度確認）
- チラシ・ポスターを画面に大きく映すのも、デザインの複製にあたりうる。**日付や名称の情報として読み取って、自分の文字で書く**

### 音源
- ⚠️ **Instagramの音源ライブラリは、アカウント種別によって使える曲が変わる**（ビジネス設定だと選べる曲が減ることがある）。
  **リールを作る前に、実際のアカウントで選択肢を確認すること。**ここは推測で書かない

### 肖像
- **子どもの顔が特定できる映像は避ける**（`social/photos/README.md` の既存方針）。
  風景・後ろ姿・手元が安心
- **他人の子どもは絶対に映さない。**公園や祭りの引きの絵でも、顔が判別できるなら使わない

### ステマ規制（景品表示法・2023年10月〜）
- **お金をもらった掲載は「協賛」と明記する。**方針ではなく法律
- いまのところ協賛は1件もない（`docs/sponsor-plan.md`）。**発生したらこの節を必ず読み直す**

### 薬機法・医療広告
- 健康・美容の効果を**こちらの言葉で書かない**。相手のキャッチをそのまま転記しない
- 接骨院・クリニック・産科などは**屋号のみ**。診療科目や効果に触れない

### 施設との約束
- **多摩六都科学館**と**小金井公園（園内の江戸東京たてもの園を含む）**は、
  掲載時に「**※最新の情報は◯◯の公式サイトでご確認ください**」を添える約束をしている。
  **リールでも守る。**キャプションか画面内に必ず入れる

## 7. リールの型（4つ）

どれも **15〜30秒**。長くしない。

### 型A「道のり」★いちばん作りやすい
駅の改札 → 歩く → 着く、を早回しで。文字で「徒歩◯分」「無料」「予約なし」。
**車のない家庭にいちばん刺さる。**素材が外だけで済む。

### 型B「開いてる日・閉まってる日」
🔴 **この通信のいちばんの持ち味。**
「金曜は図書館が休み」「日・月・祝はおひさまひろばが休み → 児童館は開いてる」
**行って閉まっていた、を防ぐ。**文字主体で作れる。

### 型C「知っていると助かる」
「11時15分から手遊びの時間がある＝その間、親が相手をしなくていい」
「11時半からお昼を食べる場所が開く＝おにぎり持参で午前中まるごといられる」
**施設の案内には書いていない読み方**を出す。⚠️「損」は使わない。

### 型D「今週末の3つ」
台帳から3件。日付・時間・料金・年齢の目安（👶🧒🎒）。
**フィードカードと内容が重なるので、作りすぎない。**

## 8. キャプションの型

```
（1行目＝リールの中身を一言で。ここしか一覧に出ない）

・場所（駅から◯分）
・日時
・料金
・予約の要否
・子連れメモ（ベビーカー可否・おむつ替え・何歳から）

※最新の情報は◯◯の公式サイトでご確認ください（← 約束のある施設のときは必須）

小平まわりの週末おでかけ情報を、毎週水曜の朝にお届けしています。
プロフィールのリンクから見ていただけます。

#小平市 #花小金井 #小平子育て #東京多摩 #子連れおでかけ
```

- **URLはキャプションに書かない**（押せない）。プロフィールへ
- 「登録してください」と書かない。**「見ていただけます」まで**
- ハッシュタグは**地名を必ず入れる**。フォロワー数より、**フォロワーの住所**が要件

## 10. オーナーへ

**リールは「作れる本数」ではなく「撮れた素材」で決まる。**
まず `social/photos/` のカテゴリに、**自分で撮った写真を数枚ずつ**入れるところから。
それだけで、既存のフィードカードの絵面も良くなる（同じ素材を共用している）。

**数えるのは、再生数ではなくLINEの友だち数。**
