## 3. 絞った結果

### やる
1. **B（本命）名入れの原稿・住まいパック** — 読者数にも LINE にも左右されない。原稿は台帳から作れるので、手間は営業と毎月の目通しだけ
   - **住まいの会社向けパック（月8,000円）**: 毎月の「来月の子連れおでかけ」原稿（お客さま向けのニュースレター・LINE用、名入れ）＋**物件の住所ごとの「子育て環境シート」**（近くの公園・児童館・図書館・今月の催し）＋季節の名入れガイド（年2回）
   - **教室・小児歯科・賃貸管理・民間学童向けの原稿（月4,000円）**: 月1回のA4（掲示・おたより用）とLINE用の文。1業種×1駅圏で1社
   - 標準は**通信の名前とQRを入れる**（待合室や、引っ越してきた家庭から読者が増える）。名前を出さない形は割増
   - 相場: 工務店のニュースレターのひな形 月9,800円（https://s-kkk.com/nl/ ）／医院だよりの作成代行 月4,400〜18,700円・半径5kmで1院だけ（https://www.medicalcontents.com/price/ ）
   - 守ること: **公式に公開された催しだけ**を使う。団体から「通信への掲載」として許しをもらった催しと、PRの催しは入れない。距離は「直線距離の目安」と書き、「子育てしやすい」のような評価の言葉は書かない（不動産の表示のきまり）。**作り方は書かない**
   - 応援型の不動産がいれば、その駅の周辺では先にそこへ声をかける（同じお店の予算を取り合わない）
2. **A 協賛を作り直す** — 利益の柱ではないが、12月末の判定の線（§9）を越えるのに要り、Bへの入口にもなる。料金は据え置き、**載るのが Web と紙だけになったことは正直に伝える**
3. **C 求人ページ（試すだけ）** — 1〜3月に3件だけ、初回5,000円で試す。保育園には、チラシのお願いとは別の日に
4. **D 西武信用金庫** — お金は当てにしない。**紹介元として一度だけ会う**（3〜5時間）

### やめる（理由）
- **E 紙のマップ**: Bと営業の時間を取り合う。営利の紙は公共の棚にも園にも置けない。15枠のうち5枠しか売れなければ年3.5万円にしかならない。**2027年10月に見直し**、Bのお客さまで枠の半分が埋まるなら2028年3月号を作る
- **F PRの枠を増やす**: 「1号1件」の約束を崩す。Threads は読者を増やす主な入口なので、広告で薄めない
- **I 制作代行**: 紙面で扱う店の原稿を書くことになり、利益相反になる
- **H 集客代行・共催**: 週末の時間を取られ、保険も要る。無料の編集掲載とも矛盾する
- **G 読者調査**: いまの読者数では少なすぎる。1,000人に届くまで保留
- **L 助成金**: 利益を出す活動に、福祉の助成を重ねない
- **J・K のれん分け・受託**: 立ち上げが重く、市との無償の関係も変わってしまう

## 4. 確かめたこと（評価役・出典つき）

- **求人と職業安定法**: 事業者に頼まれた求人を続けて載せると「募集情報等提供事業」になる。**届出が要るのは、求職者の情報を集めて使う「特定」の場合だけ**。メールアドレスを集めず、応募は先方へ直接なら届出は要らない。それでも、内容を正確・最新に保ち時点を書く、苦情の窓口を示す、料金を事前に示す（2025年4月から）。
  **LINE では配らない**（規約の第三者の広告に当たり、求人メルマガにも近い）。**採用1人ごとの成果報酬は職業紹介（許可制）に寄るので取らない。固定額で、こちらは選ばず、応募も約束しない**
  （https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/boshuujouhouteikyou.html ・ https://www.mhlw.go.jp/content/001250191.pdf ）
- **西武信用金庫**: こども家庭庁の「こどもまんなかリーディングバンク」第1回採択（2026-07-15、14件）は事実。7月に「はぐくみサポート室」を新設。
  ただし補助は**信金が取引先の子育て支援を伴走支援する費用**で、**広告費の区分が無い＝協賛のお金にはならない**。会って得られるのは取引先の紹介のほう。動くなら補助事業の年度末（2027年3月）まで
  （https://www.shinkin.co.jp/seibu/information/new/2026/NEWS_RELEASE_35.pdf ・ https://www.cfa.go.jp/procurement/477d1b9c ）
- **あすぴあとニコマル**: あすぴあの登録の要件は「営利を目的としない市民活動団体」。非営利とは構成員に収益を分けないこと（内閣府）。
  協賛が実費を超えた分がニコマル（会の役員の家族の個人事業）に残ると、**会の活動の利益が家計に入る**と読める。8/15に登録が認められたのは月300円の応援制度を前提にした判断。
  **断定はできないので、あすぴあに確かめる**（11/4以降の小川パレットへの棚の相談のついでに）:
  ①協賛が実費を超えた分がニコマルに残ってよいか　②ニコマルが事業者向けの原稿を通信とは別に売ることは登録に響くか　③協賛の入った紙に、あすぴあの印刷機やラックを使ってよいか
  - ※評価役によると、`docs/asupia-registration.md` の「収支について…配分は行っていません」の一文は**提出していない下書き**だった（チラシの提出で足りたため）。要件そのものは変わらない
  - 事業開発の整理: Bは**ニコマルの事業**として通信と分け、「台帳と仕組みはニコマルのもので、会は無償で使っている」と書面に残し、帳簿も分ける。**月5万円は、通信の外で作るほうが筋が通る**

## 7. 評価役が指摘した、3人の数字の甘いところ

- **3人とも、協賛を LINE に載せる前提**で組んでいた（§0）
- **AI の利用料**を実費に入れるなら、目標は実質月6.5〜8万円になる
- マーケター: 4月に5つの品を同時に立ち上げる時間が無い（立ち上げだけで38時間＋毎月10時間）。協賛0件の媒体が初めて売るにはマップ15枠は多すぎる。園は営利の紙を置かない前提でチラシを受けてくれている
- 営業マン: 信金の「2〜3割で年36万円」は1割未満が妥当（補助金に広告費の区分が無い・本部の決裁・LINE に名前を出せない）。「求人サイトなら28.5万円、ここは1.5万円」は採用1人の費用と掲載1回の料金を比べている。業種の筆頭ごとの料金（年74万円）は §15 のたたき台の7倍
- 事業開発: 3件に1件の成約は、実績の無い新しい品には高すぎる（6〜10件に1件が妥当。8件に1件なら4月の売上は見込みの4割）。時間の見積もりが表と道筋で食い違う（1社3時間で数えると営業だけで約110時間）。解約と初月無料が数字に入っていない
