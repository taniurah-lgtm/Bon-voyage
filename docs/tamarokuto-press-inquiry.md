## この文面の狙い

| 書いたこと | なぜ |
|---|---|
| 冒頭で**訪問と案内の事実**に触れる | 飛び込みではなく、先方の案内に応じた連絡だと最初に分かる |
| **読者47世帯**と正直に書く | 盛ると信用を落とす。小ささは断る理由にならない |
| **圏域5市のうち4市**と明示 | 無関係な外部媒体ではなく、圏域内の団体だと一言で伝わる |
| **あすぴあ登録番号**を入れる | 公的な裏づけ。実在確認の手間を省く |
| **天体観望会を例に挙げる** | 「締切がある・圏域限定」＝取りこぼすと読者が損をする具体例。抽象論にしない |
| **割引や優待をうたわない**と明記 | 商業的な利用を疑われる余地を先に消す |
| お願いを**1つに絞る** | 検討事項が増えるほど返事が遅れる |
