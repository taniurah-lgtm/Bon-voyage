## 意見ごとの考え（Claude・2026-11-26）

1. **「無料だから市役所に置けるだけ。信用ではない」**: 半分は当たり。市の棚は「無料の市民活動」だから置ける。ただ**読者からお金を取ると、その棚を失う**（市・あすぴあ・幼稚園協会の流れがすべて「無料」に乗っている）。
   信用は「お金を払う人がいるか」より「**載せた先に人が動いたか**」で示せる（ミュウテック: Threads から7回・申込0）。読者は無料のまま、**お金は事業者から（ニコマル）**、の分け方は崩さないほうがよい
2. **プレミアム**: 有料版は休止中（11/23）。読者が払うなら「時間が浮く」もの（人気講座の申込開始・抽選の締切を自分の子の年齢で知らせる）か「**地元の特典**」（下の4）。応援会員（年3,000円）の中身にできる
3. **売り先・ハウスメーカー**: 住まいパック（月8,000円・`docs/b2b/README.md`）の方向と合っている。まず1社に見本を見せる
4. **成果報酬（入会したら紹介料1万円）＋ぼんぼや経由の特典**: いちばん筋がよい案だと思う。
   - 教室の側: 入会1人の価値は月謝×通う年数（例: 月8,000円×2年＝約19万円）。1万円は安い。**入会しなければ払わない**ので頼みやすい
   - 読者の側: 「通信を見た」で入会金無料・体験の優先 → コドモブースターに無い理由ができる。合言葉か会員の印で数えられる（ミュウテックで分からなかった「本当に通信から来たか」が分かる）
   - 気をつけること: 紹介料をもらう教室は**PR**（ステマ規制）。紹介料の多い教室をひいきしない（並びは五十音のまま）。**LINE本文には出さない**（規約）。入会の数は教室の申告に頼る（合言葉で数えやすくする）
   - 形の案: 年の掲載料は小さく（0〜5,000円）＋入会1人ごとに1万円、など
5. **自分で価値を下げていないか**: 年5,000円・3月末まで無料は、始めやすさのため。ただ「安い＝自信がない」と読まれる面はある。**定価は1万円と書き、最初の教室は特別に〜、の見せ方**もある
6. **あっせん融資**: 市が金融機関に紹介し、利子の一部を市が持つ形の融資（要件は市のページで確かめる）。**借りて何に使うか**（チラシを大きく刷る・機材など）と、返すお金の見込みが先。いまは急がない

## コドモブースターと同じ土俵に乗らない案（広げるだけ・まだ決めない）

- **「いつ」がある習い事**: 体験会・季節講座・春の入会キャンペーン・発表会を、**毎週の号のカレンダーに日付つきで**。静かな一覧にはできない（通信の強み）
- **個人・小さな教室**（自宅の教室・先生1人）: 大きなサイトに出ていない／掲載料を出しにくい → 成果報酬なら入りやすい
- **子連れの条件だけ**（カフェと同じやり方）: 曜日と時間・送迎・きょうだいの同伴・ベビーカー・駐車場・雨の日。公式と教室から聞いた事実だけ
- **年齢別**（0〜2歳／3〜6歳／小学生）: 号の年齢別ページと同じ分け方。探す親の頭の中と同じ
- **口コミは集めない（集めるなら、ごほうびなしで）**: 「公式で確かめた事実」が通信の売り。口コミは「通っている家庭から教えてもらいました」の形で、事実だけ
- **駅・自転車で**: 花小金井・小川・鷹の台・一橋学園。町丁目より親の動き方に近い

## 月10万円に届くか（2026-11-26 オーナー「スクールガイド全てで掲載料と紹介料が取れたら、月10万も夢じゃない？」）

Claude の試算（仮定つき）:

| | いまの読者（約230家庭） | 月10万に届く形 |
|---|---|---|
| 掲載料 | 年5,000円 × 20教室（§16 の1年目のめど）＝ **月8,300円** | 年1万円 × 50教室 ＝ 月4.2万円 |
| 紹介料（入会1人5,000円） | 月1〜2人 ＝ **月5,000〜1万円** | 月10〜12人 ＝ 月5〜6万円 |
| 合計 | **月1.3〜1.8万円** | **月9〜10万円** |

- 仮定: 小平の数える教室は94（調べた分）。声をかけた教室のうち載るのは1〜2割。読者の家庭が新しい習い事を始めるのは年に1つほどで、そのうち通信を見て決めるのは1割ほど
- 94教室が全部 年5,000円を払っても月3.9万円。**掲載料だけでは月10万に届かない。**届くかどうかは**紹介料＝読者の数**で決まる
- → 月10万は「夢じゃない」が、**読者1,000家庭（いまの4倍強）と50教室**が先。順番は「通信で読者を増やす → 習い事のページが見られる → 教室に紹介料の話ができる」

## リッチメニューの案（2026-11-26 オーナー「4つにして、ホームページをやめて、カフェとスクールガイド（準備中）に」）

- 4つにするには「大」のテンプレート（2500×1686・画面の半分ほど）が要る。「小」は3つまで（`scripts/build-richmenu.mjs`）
- 🔴 **スクールガイドはページ全体が掲載料をいただいた教室**。リッチメニューから直接つなぐと、10/28 の決定「LINE本文・リッチメニューには、お金を受け取った名前と催しを入れない」（規約 第18条(6)・`docs/revenue-ideas.md` §0）に当たる。止まると読者を移す手段が無い
- 代わりの案: ボタンは**「習い事」**にして、**編集のページ**（日付のある体験会・季節の講座・会員以外も参加できる催しを、公式で確かめて無料で載せる）へ。スクールガイド（PR）はそのページの下からつなぐ。カフェのページ・カレンダー・マップと同じ「編集が主、PRは1件ずつ」の形になる
- 「準備中」のボタンは、押しても何も無いと信用を下げる。**ページができてから**ボタンを足す
- ホームページを外す前に、**LINE の管理画面でリッチメニューのボタンごとのタップ数**を見る。外すなら、プロフィールのボタンにホームページを残す（応援会員の入口がホームページにある）
- 当面の案: 「小」のまま **カレンダー／おでかけマップ／子連れカフェ**（ホームページ→カフェに差し替え）。習い事のページができたら「大」で4つに

## ほかのサービスの壁打ち（2026-11-26 オーナー「託児できる人と託児したい人を繋げる、お出かけ一緒に行きたい人を繋げる（オプチャ作る）など、サービス展開はまだありそう」）

### 託児をつなぐ
- 🔴 **人と人を直接つなぐ（マッチング）は、いちばん重い**: 子どもの命と安全。国の「子どもの預かりサービスのマッチングサイトに係るガイドライン」（2015年・2021年改訂）が、仲介する側にも、預かる人の確認・事故のときの対応などを求めている。お金をとって預かる個人には児童福祉法の届出があり、届出しないと過料。通信の会（市民活動）や ニコマルが背負える責任ではない
- **すでに公のしくみがある**: ファミリー・サポート・センター（地域の人どうしの預け合い。研修・保険つき）・一時保育・東京都の補助を使うベビーシッター（近くの市では1時間2,500円まで補助などの例）。小平市の中身（料金・補助の有無）は**まだ確かめていない**
- → **案: つなぐのではなく「預けたいときの道案内」ページ**（公式で確かめた事実だけ: どこに・いくら・何日前に・登録のしかた）。通信のやり方そのままで、危なさが無い。読者の困りごと（「美容院・通院・きょうだいの行事のとき」）に直接こたえる

### おでかけ仲間をつなぐ（オープンチャット）
- 良いところ: 読者どうしがつながると、通信をやめにくくなる・口コミで広がる・「何に困っているか」が見える
- 重いところ: **見張りの手間**（勧誘・保険・マルチ・スピリチュアルの投稿は必ず来る。Muse のさがしでも毎日出る種類）／**知らない人と子連れで会う安全**／個人情報（顔・住所・子の名前）／荒れたときに通信の名前が傷つく／オーナーの時間（仕事と家族があって、通信の運営もある）
- LINE の公式アカウントとオープンチャットは決まりが別（協賛の扱いも別。`docs/myutec-outreach.md` 11/11）
- → **案: 小さく始める**: ①オーナー一家が行く公の催しで「通信の読者で行く人、現地で会いましょう」（月1・昼間・公園など人の多い所・集まるのは自由）→ ②人が来るようなら、そのとき催しごとの短いオープンチャット（終わったら閉じる）→ ③続くなら常設。**ゆるっと（91人のオープンチャット）の本部に、決まりと見張りのやり方を 12/2 に聞く**のが近道
