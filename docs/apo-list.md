## 🗺 マイマップ（ピンで進捗を見る）

**ステータスを色で見分ける。** 設置済=**青** / 交渉中=**黄** / 断られた=**赤** / 候補=**白**

### 使い方

1. `data/apo-spots.json` の `status` を書き換える（`設置済` `交渉中` `断られた` `候補` のどれか）
2. `node scripts/build-apo-map.mjs` → `data/apo-map.kml` と `data/apo-map.csv` ができる
3. https://www.google.com/mymaps → 「新しい地図を作成」→ **インポート** → `apo-map.kml` を選ぶ
   → **ピンの色が最初から付いた状態で載る**（KMLにスタイルを埋めてあるため）

> CSVのほうは、表で編集したいとき用。CSVで読み込んだ場合は
> マイマップの「**個別スタイル → 均等スタイル → ステータスでグループ化**」で色を割り当てる。

### 更新するとき

マイマップは**再インポートで上書きされない**（レイヤーが増える）。
状況が変わったら、**古いレイヤーを削除してから読み込み直す**か、
ピンが少ないうちはマイマップ上で直接ピンの色を変えるほうが早い。

### 住所が未確認のもの

## 0. 「営利性の壁」— 半分は消えた（2026-09-04）

**公共施設（公民館・図書館・児童館・あすぴあ）の掲示・配架は、たいてい「営利目的でないこと」が条件になる。**

### ✅ 壁の半分は消えた（2026-09-04 の方針転換）

**月300円のサポーター制度を廃止した。**ホームページから価格・特典・比較表・申込導線を全部消し、
特商法の表記ページも「免責事項・個人情報の取り扱い」に変えた（`docs/strategy-2026-09.md`）。

**読者からお金を取る導線は、もう1本も無い。**ここが以前といちばん違う。

| | いま |
|---|---|
| 読者の費用負担 | **無い**（無料配信のみ・会員制も無い） |
| 読者向けの有料プラン | **無い**（廃止済み） |

### 🔴 だから「広告は入れていません」と言い切らない

協賛は**絶賛探し中**で、決まれば紙面に名前が載る。
いま「広告は一切ありません」と言うと、**決まった瞬間に前言を翻すことになる。**
置かせてもらっている先に対して、それがいちばん効く。

**先に言っておけば、あとで何も起きない。**次の一文は、協賛が付いても**そのまま使える**。

### 窓口でそのまま言ってよい文（協賛が決まっても言い直さなくて済む形）

> 「**読者の方に費用の負担はありません。**無料でお配りしていて、会員制でもありません。
> 　小平市民活動支援センターあすぴあの登録団体（第254号）です。
> 　（聞かれたら）**運営費は、地元の事業者さんに協賛という形でご協力いただく形を考えています。**
> 　いまのところ協賛はまだ無く、紙面は**市や施設の公式ページで一件ずつ確かめた催しの情報だけ**です。」

**言い方の要点は3つ。**

1. **主語を「読者」にする。**窓口が気にしているのは「棚に置いた紙で、来館者がお金を取られないか」。
   そこに答えれば足りる。「非営利です」と団体の性格の話にすり替えない（**個人事業なので嘘になる**）
2. **協賛は、聞かれたら言う。**こちらから長々と説明しない。ただし**聞かれて濁さない**
3. **「広告」ではなく「協賛」と言う。**紙面の性格が変わるわけではない、と伝わる

### ⚠️ 協賛が実際に決まったときにやること

1. **この節の文から「いまのところ協賛はまだ無く」を消す**（消し忘れるとその日から嘘になる）
2. **すでに置かせてもらっている先に、こちらから先に伝える。**
   「次の号から協賛が入ります」の一言。**黙って中身が変わるのが、いちばん信用を落とす**
3. 掲示・配架を断られる先が出たら、それは受け入れる。**隠して置き続けるより安い**

### これを踏まえた方針

| | 判断 |
|---|---|
| **公共施設を、後回しにしない** | 読者からお金を取る導線が消えたので**いま行ける**。公民館・児童館・図書館は読者層が丸ごといる |
| **民間の個人店** | 店長判断で即決できる。引き続き強い。**効いたのは「行きつけ」だった** |
| **掲示物に価格を書かない** | カード・ポスターは**HP誘導のみで価格の記載なし**。維持する |
| **チェーン店は後回し** | 本部一括のポリシーで個店では断られやすい |

### ❌ それでも刷ってはいけない一文（Gemini提案・2026-08-08 却下）

Geminiは、役所を通すための対策として、チラシに次の一文を刷ることを勧めてきた。

> 「本通信は地域の子育て支援を目的とした**完全無料のボランティア配信**です。
> **有料サービスへの誘導や営利目的の配信は一切ありません**」

**却下した理由の半分（月300円への導線があった）は消えた。それでもこの文は使わない。**

- 「**ボランティア**」が事実でない。運営しているのは**個人事業のニコマル**であって、ボランティア団体ではない
- 「**営利目的の配信は一切ありません**」は、**協賛を探している方針と正面から矛盾する。**
  **刷った紙は何か月も棚に残る。**協賛が決まった日から、その紙が嘘をつき続けることになる
- そもそもGemini自身がこれを「担当者が上に説明を通すための言い訳（根拠）」と説明していた。
  **窓口に言い訳を持たせるための文は、目的からして通すべきでない**

過去に「カレンダー登録代行」で実態と乖離した記載をして直した経緯がある（`docs/paid-conversion.md`）。
**できていないこと・事実でないことを書かない**という方針は、相手が役所でも同じ。
→ 言うのは上の「窓口でそのまま言ってよい文」だけでよい。**短いほうが、事実だから強い。**
