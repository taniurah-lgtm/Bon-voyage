## 0. 先に押さえるべき「営利性の壁」

**公共施設（公民館・図書館・児童館・あすぴあ）の掲示・配架は、たいてい「営利目的でないこと」が条件になる。**

ニコマルは**個人事業**で、ホームページには**月300円のサポーター制度**がある。
通信そのものは無料でも、この一点で「営利」と判断されて断られる可能性がある。

### これを踏まえた方針

| | 判断 |
|---|---|
| **民間の個人店から回る** | 店長判断で即決できる。**ここが本命。** |
| **公共施設は並行して申請** | 時間がかかる前提。通れば信用の裏づけになる |
| **掲示物に価格を書かない** | 現状のカード・ポスターは**HP誘導のみで価格の記載なし**。これは有利に働く |
| **チェーン店は後回し** | 本部一括のポリシーで個店では断られやすい |

**あすぴあ（市民活動支援センター）の団体登録には「5人以上の会員名簿」と「会則・定款」が要る**
（[出典](https://kodaira-shiminkatsudo-ctr.jp/tebolo/tetuduki)）。個人事業では満たせない。
ただし**チラシラックの利用に団体登録が必須かは未確認**。ここは電話1本で分かる。→ 最優先の確認事項
