# おでかけマップを Googleマップにする — 鍵（APIキー）の作り方（2026-11-18）

> 「やはりGooglemapの埋め込みというか切り替えをできませんか？ いまの地図、正直見づらいです」→「1で」（オーナー・2026-11-18）
> 作業はオーナー（Google と GitHub の画面）。所要 15分ほど。終わったら Claude に「入れた」と伝える。

## しくみ（Claude 側はできている）

- マップのピン・まとめ表示・しぼり込み・ふきだし・PRのピンは、これまでのまま。**下地の地図だけ Googleマップ**になる
- 鍵は **GitHub の Variables（`GMAPS_KEY`）** に入れる。リポジトリのファイルには書かない
  （地図用の鍵はページに載る前提のもの。そのかわり「このホームページからしか使えない」制限をかける）
- 鍵が無い・鍵のエラー・読み込めないときは、**自動でいまの地図（OpenStreetMap）に戻る**（真っ白にならない）
- 料金: 地図の表示は **月1万回まで無料**（Dynamic Maps・2025年3月からの料金体系。2026-11-28 に Google の料金ページで再確認: 1万回を超えると1,000回あたり 7ドル）。下の 6 で「1日300回まで」に止めておけば、無料の範囲を超えない。**おでかけマップとスクールガイドの地図で、この上限を分け合う**

## 手順

### 1. プロジェクトを作る
1. https://console.cloud.google.com/ に、ふだんの Google アカウントでログイン
2. 上の「プロジェクトを選択」→「新しいプロジェクト」→ 名前は `bonvoya-map` など →「作成」

### 2. お支払い情報を登録する（カード）
1. 左のメニュー「お支払い」→「請求先アカウントを管理」→ 作る（カードを登録）
2. いま作ったプロジェクトに、その請求先アカウントをつなぐ
   - 無料トライアルのクレジットの案内が出たら、そのまま進んでよい

### 3. 地図の機能を有効にする
1. 左のメニュー「APIとサービス」→「ライブラリ」
2. 「**Maps JavaScript API**」を検索 →「有効にする」

### 4. 鍵（APIキー）を作る
1. 「APIとサービス」→「認証情報」→「認証情報を作成」→「APIキー」
2. できた鍵（`AIza…` で始まる文字列）をコピーしておく

### 5. 鍵に制限をかける（🔴 必ず）
「認証情報」の一覧で、いま作った鍵の名前を押して編集する。

- **アプリケーションの制限**: 「ウェブサイト」を選び、次の2つを追加
  - `https://bonvoya.nicomaru.tokyo/*`
  - `http://bonvoya.nicomaru.tokyo/*`
- **API の制限**: 「キーを制限」→「**Maps JavaScript API**」だけにチェック
- 「保存」

### 6. 使いすぎ止め（おすすめ）
1. 「APIとサービス」→「有効なAPIとサービス」→「Maps JavaScript API」→「割り当てとシステム上限」
2. 「Map loads per day」（1日の地図の読み込み）を **300** に下げる（300×31日＝9,300回＝無料の1万回の内側）
3. あわせて「お支払い」→「予算とアラート」で、月 **100円** を超えたらメールが来るようにしておくと安心

### 7. GitHub に鍵を入れる
1. GitHub のリポジトリ（Bon-voyage）→「Settings」→「Secrets and variables」→「Actions」
2. 「**Variables**」のタブ（Secrets ではない）→「New repository variable」
3. Name: `GMAPS_KEY` ／ Value: 4 でコピーした鍵 →「Add variable」

### 8. Claude に「入れた」と伝える
Claude がホームページの組み直しを動かして、Googleマップになったかを確かめる。

## うまくいかないとき

| 見え方 | 原因と直し方 |
|---|---|
| いままでの地図のまま | 鍵がまだ入っていない／7 の名前が `GMAPS_KEY` になっていない／Variables ではなく Secrets に入れた |
| 一瞬 Googleマップが出て、いままでの地図に戻る | 5 の制限のアドレスが違う／3 の「有効にする」をしていない／2 のお支払いがつながっていない |
| 「このページでは Google マップが正しく読み込まれませんでした」 | 2 のお支払いがつながっていない |

## 決めたこと

- 下地を Googleマップにするだけ。Google のお店の口コミや経路案内は使わない（料金が別に掛かる）
- お店・飲食店の Google のアイコンは消している（通信のピンと見分けにくいため）。公園・学校・駅は出る
- 会員ページ（`/m/…`）の地図は、いまのまま（OpenStreetMap）
- 🆕 スクールガイドの「地図で見る」（2026-11-27）も同じ鍵で Googleマップになる（公開するときに、組み直しの段へ `GMAPS_KEY` を渡す。`docs/school-guide-launch.md`）
