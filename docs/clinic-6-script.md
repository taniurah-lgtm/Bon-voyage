# B. 当日の台本（持っていくとき）

**持ち物**: チラシ **10部**（「まず2〜3部」と言ったが、**置けると言われたら10部渡せる**ようにしておく）
／ A5ポスター1枚（掲示できるか聞く用）／ 名刺か、連絡先を書いたメモ

**服装**: 普段着でよい。**子どもを連れて行ってよい**（このほうが早く伝わる）

## B-1. 受付の方に渡すだけのとき（いちばん多い）

```
先日お電話しました、ぼんぼやーじゅ通信です。
チラシをお持ちしました。まず10部ほど置かせてください。

なくなりそうでしたら、ご連絡いただければすぐお持ちします。
こちらに連絡先を書いてあります。

ありがとうございます。失礼いたします。
```

**🔴 長くしない。**受付は仕事の最中。**渡して、礼を言って、出る。**

## B-2. 院長・事務長など、決められる方に会えたとき（本番）

**ここでだけ、将来の話をする。**

```
ありがとうございます。置かせていただけて助かります。

小平の子育て家庭に、週末のおでかけ情報を毎週お届けしています。
市や施設の公式ページで一件ずつ確かめて載せていて、
まとめサイトからの転載はしていません。

いまは、とにかく読者を増やしている時期です。
児童館や公民館、多摩六都科学館さんにも置かせていただいていて、
11月からは市内20館と児童館3館にも並ぶ予定です。

読める人が増えたら、
将来は地元の事業者さんに協賛という形でご協力いただけたらと考えています。
いまは協賛はまだいただいていません。
そのときに、こちらにも声をかけさせていただけたら嬉しいです。

まずは、置かせていただくところからお願いできればと思っています。
```

### なぜこの順番か

1. **先に礼。**もう置いてもらえることになっている
2. **何をしているか → どう確かめているか。**信用の根拠を先に置く
3. 🔴 **「いまは読者を増やしている時期です」。**
   **これが枕になって、協賛の話が「いまのお願い」ではなくなる**
4. **置かせてもらっている先を並べる。**
   **相手が判断に使うのは、ここ**（自分だけが特別に頼まれたのではない、と分かる）
5. **協賛は「将来」「そのときに声をかけさせて」。****いま決めてもらわない**
6. **最後にもう一度「まずは置かせていただくところから」。**
   **今日の用事はこれだけ、と閉じる**
