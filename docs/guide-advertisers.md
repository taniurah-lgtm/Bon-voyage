## ⏭ これをどう使うか

1. 🔴 **チラシの置き先として、まず動く。**
   **すでに「この層に届けたい」とお金を払っている。**棚を貸す話は、それよりはるかに軽い。
   → **医療の18件のうち、`distribution.md` の小児科リストと重なる6件から。**
   **「子育てガイドにも出されていますよね」と言えるのが強い**（相手の関心がはっきりしている）
2. **協賛は、そのあと。**`docs/sponsor-plan.md` の「営業10件やって0なら〜」の10件を、
   **この中から選ぶ。**推測ではなく**出稿の実績**で選べる
3. **裏表紙全面の中野産婦人科医院が、いちばん予算を持っている。**ただし**最後に回す。**
   小さく始めて実績を作ってから
4. ⚠️ **サイネックスに広告を買いに行かない。**うちは**媒体を持っている側**であって、
   他媒体に出稿する話ではない（`docs/sponsor-plan.md` の方針）
