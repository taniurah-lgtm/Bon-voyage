# 有料（月300円）に「入りたい」と思ってもらうための設計

無料通信は動き出した。次は「応援サポーター（月300円）」への転換をどう作るか。
値付けを触る前に、**人が少額課金する時の心理**を押さえ、そこから施策を逆算する。

---

## 0. 最初に正直な前提：いまの数字だと「0人が正常」

- 無料の友だちは十数人。一般的なフリーミアムの転換率（1〜3%）なら **0.1〜0.5人**。
- つまり**今ページを磨いても、それ単体では課金は生まれにくい**。
- ただし例外がある：**知人・近しい人の転換率は桁違いに高い**（応援目的なので10〜20%も珍しくない）。
  → **いまの局面は「不特定多数への最適化」ではなく「近しい数人が“応援として”入りやすい形」を作るのが正解。**
- 並行して**母数を増やす**（掲示・名刺・SNS）のが、遠回りに見えて一番効く。

---

## 1. いま課金が起きない構造的な理由（診断）

| # | 障壁 | 何が起きているか |
|---|---|---|
| 1 | **母数** | 分母が小さく、確率的にまだ出ない |
| 2 | **摩擦 > 金額** | 障壁は300円ではなく「note登録・カード入力」の手間。**心理的コストが金額を上回っている** |
| 3 | **特典が「量」** | 「週2になる」は"同じものが増える"だけ。人は量にはお金を払いにくい（質の飛躍が要る） |
| 4 | **無料が充実しすぎ** | 無料版が「読むだけで十分」に仕上がっている。自分でカニバリを起こしている |
| 5 | **社会的証明ゼロ** | 「誰も入っていない」状態は、それ自体が入会のブレーキ |
| 6 | **"今"払う理由がない** | 締切・限定・季節性がなく、「そのうち」で終わる |
| 7 | **払った後が想像できない** | 入会後に何が起きるかの絵が無い（初日の体験が描けていない） |

---

## 2. 人が「月300円」を払うときの6つの心理ドライバー

少額課金は**経済的判断ではなく感情的・自己像の判断**で決まる。効く順に：

1. **手間の代行（時間を買う）** … 「自分で調べなくていい」。金額より"面倒がなくなる"が刺さる。
2. **損失回避・FOMO** … 「知らずに逃した」を避けたい。人は得より損に約2倍反応する。
3. **自分ゴト化** … 「うちの子（2歳・ベビーカー・車なし）に合っている」。汎用情報は無料で足りる。
4. **応援・所属** … 「この人を支えたい」「仲間でいたい」。地域・個人発の媒体はここが主戦場。
5. **社会的証明** … 「◯人が応援中」「同じ園のママも入っている」。
6. **リスクの低さ** … 「いつでもやめられる」「先にたくさんもらった（返報性）」。

---

## 3. 改良案（詳細）

### 案1. 価格の「再フレーミング」＝時間の値段に置き換える
- **効く心理**: 手間の代行 / アンカリング
- **やること**: 応援セクションの見せ方を「300円」から**「毎週の“どこ行こう”を調べる2〜3時間を、週75円で肩代わり」**へ。
  - 表現例：「調べるのに毎週2時間。**1回あたり75円**で、その2時間を家族と過ごす時間に。」
- **なぜ効く**: 300円という絶対額ではなく、**"何と比べるか"**で価値判断が変わる（コーヒー1杯より安い、等の常套句より"自分の時間"の方が強い）。
- **工数**: 小（文言のみ）／**効果**: 中

### 案2. 入会の摩擦を最小化する（最重要・即効）
- **効く心理**: 認知的負荷の削減（障壁は金額でなく手間）
- **やること**:
  1. **入会導線を「3タップ」に**：LINEのリッチメニュー →（HPの応援セクション）→ note。**途中の説明を削る**。
  2. **noteアカウントを持っていない人向けの説明を1行**：「noteの登録が要ります（1〜2分）」と**先に言う**。不意打ちの手間が一番の離脱要因。
  3. **決済手段の再検討**：note は手軽だが"note登録"が壁。**Stripe決済リンク / BASE / PayPay** など、カード入力だけで完結する手段の比較検討（特商法表記は必要）。
- **工数**: 小〜中／**効果**: 大

### 案3. 「うちの子仕様」オンボーディング（入会直後の体験設計）
- **効く心理**: 自分ゴト化 / 関係性 / 一貫性（自分で答えた設定は使い続けたくなる）
- **やること**:
  - 入会したら**その日のうちに1:1で「カスタマイズ設問」**（既に `docs/onboarding-form.md` にある）。
  - **次の号の冒頭に「◯◯さんちは2歳と5歳・自転車圏なので、今週はここ」**と、名指しで書く。
  - 会員ページに**「あなたの設定」**を表示（エリア・年齢・興味）。
- **なぜ効く**: 「払ったのに何も変わらない」を潰す。**初回体験で"個別化"を体感**させると継続率が跳ね上がる。
- **工数**: 中（人数が少ないうちは手動で十分）／**効果**: 大

### 案4. 会員限定「予約・チケットの見張り番」（FOMOの本命・工数を絞る設計）
- **効く心理**: 損失回避（最強）
- **経緯**: 以前「巡回のハードルが高い」として一度ボツにした。**全部を見張るのは無理**という判断は正しい。
- **作り直し方**: **会員が指定したものだけ**を見張る**ウォッチリスト方式**にする。
  - 会員が「これを見ていて」と3つまで登録（例：ディズニー、ピューロランド、C&C山中湖、映画の子連れ上映）。
  - 巡回時に**その3つだけ**を確認 → 解禁日・発売日が判明したら**個別に通知**。
  - **上限を設ける**（1人3件・全体で◯件まで）ことで工数が破綻しない。
- **なぜ効く**: 「取り逃した」の痛みは大きく、**300円が保険のように見える**。
- **工数**: 中／**効果**: 大（ただし需要はアンケートで先に検証）

### 案5. 土曜の「直前チェック」を主役に置く
- **効く心理**: 手間の代行 / 損失回避
- **やること**: 有料の目玉を「週2配信」ではなく**「土曜朝の“今日どうする？”便」**として売る。
  - 中止・順延の確認、当日の天気、混雑、雨なら代替案。
  - **無料には絶対に無い**（無料は水曜のみ）ので、線引きが明確。
- **なぜ効く**: 「週2」は量、「**土曜の朝に判断を助けてくれる**」は体験。**人は体験に払う**。
- **工数**: 中（土曜巡回の復活）／**効果**: 大

### 案6. 「創刊サポーター」枠（限定性＋社会的証明の起動）**← 見送り（2026-08 に実装したが撤回）**

> **却下の理由**: ①掲載名簿・番号の管理が人数に比例して増え、運用が重い。②「番号を配る」「最初の20名」は**お金がほしい側の都合が前面に出て品がない**。この通信は身内・友人も読む前提で、そこを崩すと信頼という最大の資産が減る。
> 代わりに、**参加型の投稿マップ**（無料は閲覧中心／サポーターは投稿と全体閲覧）で「入ったほうが楽しい」を作る方向に切り替えた。
- **効く心理**: 限定性 / 所属 / 社会的証明の初期ブート
- **やること**:
  - **最初の10〜20名を「創刊サポーター」**として募集。**入会順に番号**（No.1〜）。
  - 特典：**ずっと同じ価格**（将来値上げしても据え置き）、会員ページに**お名前orニックネーム掲載**（希望者のみ）。
  - 「あと◯名」ではなく「**◯名の方に支えていただいています**」と**淡々と**書く（急かさない方針を守る）。
- **なぜ効く**: 0人問題の突破口。**最初の3人**が出れば、以降は「みんな入っている」が効き始める。
- **工数**: 小／**効果**: 中〜大
- **実装メモ**:
  - ホームページ応援セクションに「創刊サポーター」ブロック（`.founding`）。**あと◯名は書かない**。「あわてて決める必要はない」と明記して煽らない方針を守る。
  - 価格据え置きは**約束ではなく note の仕様**。[note ヘルプ](https://www.help-note.com/hc/ja/articles/900000164086)いわく**一度決めた会費は変更できず、変えるにはプランの作り直しが必要**。よって値上げ時は新プランを作ることになり、既存の300円プランはそのまま残る。こちらが旧プランを削除しない限り据え置きが成立する（＝守れる約束）。
  - 会員ページの掲載は `scripts/build-members.mjs` の `FOUNDING`（掲載希望者のみ）と `FOUNDING_TOTAL`（実人数）。**`FOUNDING_TOTAL = 0` の間はセクションごと出さない**（空欄が「誰もいない」を可視化するのを避ける）。
  - 参加者が出たら: `FOUNDING_TOTAL` を増やし、掲載OKの方だけ `FOUNDING` に `[番号, ニックネーム, ひとこと]` を追加 → `MEMBER_PASS=… node scripts/build-members.mjs` で再ビルド。

### 案7. 無料 / 有料の線引きを「量」から「種類」へ
- **効く心理**: 価値の非対称性
- **現状**: 無料＝週1・汎用、有料＝週2・個別。**"同じものの増量"**に見える。
- **変更案**:

  | | 無料 | 有料（サポーター） |
  |---|---|---|
  | 役割 | **知る**（今週のおすすめを1つ決めてくれる） | **決める・動く**（うちの家族の予定になる） |
  | 中身 | 汎用の一推し＋先取り | **土曜の直前チェック** / **うちの子仕様の出し分け** / **カレンダーに追加** / **見張り番** |
- **ポイント**: **無料を薄くしない**（トーン方針・信頼を守る）。**有料を"別の仕事"にする**。
- **工数**: 小（設計）／**効果**: 中

### 案8. 「働きぶり」の可視化（払い続ける理由を作る）
- **効く心理**: 損失回避（やめると失う）／ 進捗の実感
- **やること**: 会員ページに月次で
  - 「今月は**◯件**を調べて、**◯件**をあなた向けに選びました」
  - 「あなたがカレンダーに追加した予定：◯件」
  - 「先取りでお伝えした締切：◯件」
- **なぜ効く**: 無形サービスは**成果が見えないと解約される**。可視化は継続率に直結。
- **工数**: 中／**効果**: 中（継続に効く）

### 案9. リスクを消す一文（コンバージョンの底上げ）
- **効く心理**: リスク低減 / 返報性
- **やること**: 応援セクションに**短く**：
  - 「**いつでも解約できます**（次回請求は止まります）」
  - 「**合わなければ最初の1か月ぶんはお返しします**」（返金保証。少額なので実損は小さく、効果は大きい）
  - 「無料通信は**これからもずっと無料**です」（既にあり・維持）
- **工数**: 小／**効果**: 中

### 案10. 「今」入る理由をつくる（季節のフック）
- **効く心理**: タイミング / 損失回避
- **やること**: 常時の煽りではなく、**年に数回の自然な区切り**で案内する。
  - 例：**大型連休の1〜2か月前**（予約が要る時期）、**夏休み前**、**冬のイルミ前**。
  - 「連休の計画、うちの家族向けに一緒に立てませんか」という**用件ベース**の案内。
- **工数**: 小／**効果**: 中

## 4. 価格そのものの再考（要検証）

- **300円は「安すぎて価値を疑われる」水準になりうる**（安さは品質のシグナルにもなる）。
- 一方、**少額であるほど"応援"として払いやすい**という逆の力も働く。
- → **アンケート（`docs/surveys.md` Q9：0/100/300/500/1000円）で実測してから**判断する。
- 有力な選択肢：**300円は据え置き、価値を厚くして"お得に見せる"**（値上げより安全）。

## 6. 注意（やらない方がいいこと）

- **無料版で売り込まない**（`CLAUDE.md` の方針を維持）。信頼が最大の資産で、それを削ると母数が減る。
- **煽り表現を使わない**（「急いで」「損」）。地域・知人相手では逆効果。
- **工数が青天井の特典を約束しない**（1:1相談・見張り番は**上限つき**で）。人数が増えた瞬間に破綻する。
- **できていないことを特典に書かない**（過去に「カレンダー登録代行」で実態と乖離した。実装済みのことだけ書く）。
