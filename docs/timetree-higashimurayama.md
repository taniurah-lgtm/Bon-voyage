# 東村山周辺イベント（TimeTree 公開カレンダー）への入力

**2026-10-08 始め。**東村山 子育て情報交換オプチャ（475人）の管理人やっぴーさんが作った
TimeTree の公開カレンダー「東村山周辺イベント」（https://timetr.ee/p/higashimurayama_event ）に、
こちらの台帳から**東村山から行きやすい催し**を入れる。やっぴーさんから「どんどん入力してもらえたら」と依頼あり。

## 分担

| | だれ | |
|---|---|---|
| 入力 | **オーナー**（TimeTree のアプリで） | Claude は TimeTree を操作できない（外から予定を入れる入口が無い） |
| 候補の一覧づくり | **Claude** | このファイルの「入れる候補」を、オーナーに頼まれたとき・号を作るときに更新する |
| 編集の権限 | オーナーが**ノートのコメント欄で入力ボランティアに名乗り出る** | 先方の決まり（「コメント欄に書き込みお願いします」） |

## 入れるもの・入れないもの

- ⭕️ **東村山市内**、または**東村山から電車1本・30分くらい**の催し
  （小平の北側＝小川・萩山・小平駅・鷹の台／所沢／東大和／清瀬／東久留米）
- ⭕️ **だれでも行ける**もの（市外の人も参加できる）
- ❌ **小平市民限定**（市内在住・在学）のもの。東村山の人は申し込めない
- ❌ 日付や料金の**裏が取れていない**もの・台帳で**保留**のもの
- ❌ メモに**こちらのホームページやLINEのリンクを入れない。**公式のURLだけ。
  人のカレンダーで宣伝すると、せっかくの関係を損なう
- ❌ 主催者個人の連絡先（携帯・メール）を書かない（`CLAUDE.md`「個人の連絡先を機械可読で撒かない」）
- 入れる前に、**同じ催しがもう入っていないか**カレンダーで見る（先方とほかのボランティアも入れている）

## 入れ方（1件ずつ）

- タイトル: 催しの名前
- 日時: 時刻が分かれば時刻、分からなければ終日。2日以上は日をまたいで1件にする
- 場所: 会場名（市名を括弧で）
- メモ: 「入場無料」「要チケット」など1行 ＋ 公式URL
