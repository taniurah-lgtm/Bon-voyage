# 名入れの原稿・住まいパック — 売り方と、使ってもらい方（オーナー向けの説明・2026-11-02）

> オーナー「どう売り込んで、どう運用してもらうのかが分かっていない」への答え。内部用・非公開。
> 決まりごとは `docs/b2b/README.md`。ここは**流れの説明**。

## 1. ひとことで

**「子育て中のお客さまに配れる『来月の子連れおでかけ』を、お店の名前入りで毎月お届けします」**

お店は、お客さまと月1回つながる**ネタ**を、手間なしで手に入れる。
こちらは、毎週集めている催しの情報（市や施設の公式で確かめたもの）を、**お店の名前で使える形**に組み直して渡す。

## 2. だれに売るか（買う理由がある順）

| 相手 | 商品 | お店にとっての使い道 |
|---|---|---|
| **不動産**（賃貸・売買の仲介、管理会社） | **住まいパック 月8,000円** | 子育て世帯の来店客に、物件資料と一緒に「**この物件のまわりの子育て施設と、今月の催し**」を渡す（他の店との違いになる）／入居者・オーナーへの月1のおたより／お店のLINEの配信ネタ |
| **教室**（習い事・学習塾・英会話・スイミング・工作）・**小児歯科／小児科**・**民間学童**・キッズカットの美容室 | **原稿プラン 月4,000円** | 待合・受付に置く、掲示する、保護者へのおたよりに入れる、お店のLINEで月1回送る |
| 工務店・保険の代理店など、子育て世帯に**月1のニュースレター**を出している会社 | 原稿プラン | ニュースレターの1ページ分にそのまま使う |

- **1業種×1駅圏で1社だけ**。これがいちばんの売り（「花小金井の不動産では、お宅だけです」）
- 相場: 工務店向けのニュースレターのひな形 月9,800円／医院だよりの作成代行 月4,400〜18,700円（`docs/revenue-ideas.md` §3）

## 3. お店はどう使うか（毎月の流れ）

| いつ | だれが | 何を |
|---|---|---|
| 毎月15日ごろ | Claude | 翌月の催しを台帳から選び、A4とLINE用の文を作る（`node scripts/make-b2b.mjs <月>`） |
| 〃 | オーナー | 目を通す（10分） |
| **毎月20日ごろ** | オーナー | お店に**メールで送る**（PDF＋LINE用の文）。請求書（ニコマル名義・前払い）も |
| 受け取ったら | お店 | **印刷して置く・貼る・物件資料に挟む・LINEに文を貼って送る**。お店の作業は印刷と貼り付けだけ |
| 住まいパックだけ | お店 → オーナー | 物件の住所をメールで送る → **3営業日ほど**で物件シートのPDFを返す（**月5件まで**） |

- お店が中身を確かめる必要はない（公式に出ている催しだけ。紙に「〇年〇月〇日時点」と出る）
- 契約は**3か月から**、そのあとは1か月ごと。やめるときは**前の月の10日まで**に連絡
- お支払いは**前払い**。毎月、請求書（ニコマル名義）を送る。消費税の上乗せなし（インボイス未登録）

## 4. 売り込み方（1件 30分）

1. **候補を選ぶ**: 花小金井・小平駅のまわりから。協賛のアポリスト（Notion）と重なる店は、先に協賛の話をしたかを見る（同じお店の予算を取り合わない）
2. **相手の店名を入れた見本を作る**（Claude に「〇〇不動産の見本」と頼めば、名前を入れた PDF をすぐ作る）
3. **店頭に持って行く**（電話より、紙を見せたほうが早い）。話す順:
   - 「子育て中のお客さまは多いですか？」
   - 「毎月、来月の子連れのおでかけ情報を、お店のお名前入りでお届けしています。印刷して置いていただくか、LINEで送っていただくだけです」
   - 「中身は、市や施設の公式に出ている催しだけで、毎月こちらで確かめています」
   - 「このあたりの〇〇屋さんでは、1社だけにしています」
   - 「月4,000円（不動産は物件シートつきで8,000円）、3か月からです」
4. 興味があれば**申込書**（ニコマル名義）を置いてくる。翌月分から
5. 返事は1週間後に1回だけ聞く。だめなら理由を1行メモ

## 5. 守ること（これだけは崩さない）

- **通信の会とは分ける**: ニコマル名義・ニコマルの請求書。名入れの紙に**あすぴあの登録番号を書かない**／あすぴあのラックや印刷機を使わない
- **買ってくれたお店を、通信の紙面でひいきしない**（通信での紹介は、協賛の「PR」か、ふつうの編集だけ）
- 不動産: **料金は固定額だけ**（成約ごとの報酬はとらない＝宅建業法）。**「子育てしやすい」などの評価の言葉は書かない**、距離は「直線距離の目安」（不動産の表示のきまり）
- お店のLINE用の文に、**通信の宣伝（友だち追加のお願い）を入れない**（お店のLINE公式アカウントの規約）。出典として名前だけ
- 主催者の許しが「通信への掲載」までの催し・PRの催しは入れない（スクリプトが止める）

## 6. お金の目安

- 原稿プラン 10社 × 4,000円 ＝ 月4万円
- 住まいパック 3社 × 8,000円 ＝ 月2.4万円
- 毎月の手間: Claude が作る → オーナーの目通し10分 → メール送信。営業は1件30分
