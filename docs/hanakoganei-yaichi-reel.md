## 3. 台本（約22秒）— 作り直し版

### 🔴 冒頭1.5秒の設計意図

**引きの会場写真（写真③）は、小さい画面の1.5秒では何も伝わらない。**そこで役割を分けた。
**画は「光っている手元」（写真②）で指を止め、「どこの話か」は画ではなく文字で伝える。**
型が求める「1.5秒で場所を見せる」は、文字（「花小金井駅前」）で満たす。
引きの会場写真は、名前を明かす9〜13秒に回した——ここまで見た人には「どこの続きか」がもう伝わる状態。

| 秒 | 画 | 画面の文字（15字以内） |
|---|---|---|
| 0〜1.5 | 写真② 光るミニライト（暗闇のなか、手元アップ） | **花小金井駅前** |
| 1.5〜5 | 写真① パーツを選ぶ手元（机いっぱいの仕切りケース） | **好きなパーツを選んで** |
| 5〜9 | 動画 息子が完成したライトを見せる | **自分で作りました** |
| 9〜13 | 写真③ 会場の引き（高架下・テント・電球の連なり） | 1行目: **花小金井夜市**<br>2行目: **駅を出てすぐ** |
| 13〜17 | 写真③ 別クロップ（テントと電球に寄る） | **入場は無料** |
| 17〜22 | 写真② 再び、少し引きで（光る手元・余韻） | **暗くなってからが本番** |

### 🔴 先に確かめること — 写真②は、どこで撮ったか

**0〜1.5秒に「花小金井駅前」と出す設計だが、写真②は会場で撮ったものに見えない。**
写っているのは暗がりの手元と、左に**サンダル**、下に**木か土間のような段**。
**会場（高架下・テント・電球）の要素が1つも写っていない。**帰宅後の玄関の可能性がある。

- **会場で撮ったものなら**、このままでよい
- **家で撮ったものなら**、その画に「花小金井駅前」と重ねるのは**場所の偽り**になる。
  `docs/handoff-reel.md` §2-③「行ってきましたと書いてよいのは、実際に撮った場所だけ」に触れる

**家だった場合の直し方**（構成は崩さない）:

| 秒 | 直し方 |
|---|---|
| 0〜1.5 | 文字を **「これ、作ってきました」**（9字）に替える。**場所を主張しない**。画はそのまま |
| 9〜13 | ここで初めて **「花小金井夜市」「駅を出てすぐ」** が出るので、**場所は結局伝わる** |

もう1つの手は、**動画のうち会場で撮れているカット**を0〜1.5秒に持ってくること。
**会場で光らせている画があるなら、それがいちばん強い**（場所と光が1枚で両立する）。

**編集メモ**: 写真②・写真③はそれぞれ2回使うが、**クロップ（寄り/引き）を変える**ことで
同じ静止画の使い回しに見えないようにする（Edits の拡大・パン機能で足りる）。

### この並びの考え方（問い1〜3への回答）

1. **指が止まるのは光（写真②・動画）。**場所は文字が引き受ける。画と文字の役割を分けたので両立できる
2. **1行目「花小金井駅前」は6字。**1.5秒でも読み切れる長さにした。2行目以降も各行15字以内・2行までを守っている
3. **最後まで見る理由は「これは何？」の引っ張り。**冒頭は光っているだけで説明が無い→
   パーツを選ぶ画（1.5〜5秒）→完成を見せる動画（5〜9秒）で種明かしが完成する。
   さらに**最後（17〜22秒）で冒頭と同じ「光る手元」に戻る**ことで、動画が一周してループ再生しても
   違和感がない作りにした（Reelsはループ再生されるため、切れ目が滑らかだと再生され続けやすい）。
   実用情報（入場無料・駅を出てすぐ）は9〜17秒に固めたが、**そこに来る前に「見る理由」は
   もう作れている**ので、後半だけに情報を積んでも離脱しにくい設計にした。
