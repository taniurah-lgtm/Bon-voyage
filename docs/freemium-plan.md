# フリーミアム運用計画(花小金井エリア)

「無料で間口を広く → もっと詳しく/自分に合った情報がほしい人は有料」の設計。
コスト構造(無料=全員同報で追加コストほぼゼロ / 有料=個別生成で人数分コスト)と、
無料・有料の線引きを一致させる。

## 無料 / 有料の線引き

| | 無料(ブロードキャスト) | 有料(300円/月・個別) |
|---|---|---|
| 配信 | 花小金井エリア共通の同報1本 | プロフィール別に出し分け |
| 頻度 | **週1(水のみ)** | **週2(水・土)** |
| エリア | 花小金井〜小平中心の近場 | 多摩＋都心まで(coverage指定) |
| 内容 | 汎用おすすめ数件＋2歳連れひとこと | 興味ジャンル・平日候補・無料重視で絞り込み |
| カレンダー登録 | なし(公式URL案内のみ) | 「E3を登録」でGoogleカレンダーへ代行 |
| キャンプ | 触りだけ | 空き枠の先読み・予約タイミング |
| 直前確認 | なし | 土曜巡回で中止・天気の直前確認 |

**原則**: 無料は「読むだけ」、有料は「自分向けに動いてくれる」。

## なぜ無料を週1にするか(LINE無料枠)

LINE公式アカウント無料プランは月200通、broadcastは受信者ごとにカウント。
- 週1(水のみ)= 約4通/人・月 → **約50人**まで無料枠内
- 週2 = 約8通/人・月 → 約25人で頭打ち

無料は週1に抑えて50人まで無料運用。人数が増えたらライトプラン(月5,000円/5,000通)へ。
**このLINE費が「無料ファネルの原価」**で、有料転換で回収する。
無料プロフィールは既存の `frequency: 1x_week` 相当(水のみ配信)で表現する。

## 運用フロー(無料→有料)

1. **共通調査(1回)**: 既存の巡回どおり全 `active` プロフィールの和集合で `events/` を更新。
2. **無料通信(水)**: `profiles/free-hanakoganei.md` を使い、エリア共通版を `reports/free/YYYY-MM-DD.md` に生成 → `scripts/line_report.sh` で**無料アカウントにブロードキャスト**。末尾に有料CTA(下記)を必ず付ける。
3. **有料通信(水・土)**: `active: true` かつ `plan: paid` のプロフィールごとに `reports/<id>/YYYY-MM-DD.md` を生成 → 個別に配信。
4. **転換**: 無料通信のCTA→フォーム(`docs/onboarding-form.md`)で有料申込 → `profiles/<id>.md`(`plan: paid`)を1枚作成 → 次の巡回から個別対象。
