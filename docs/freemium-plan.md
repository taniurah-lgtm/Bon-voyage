# フリーミアム運用計画(花小金井エリア)

「無料で間口を広く → もっと詳しく/自分に合った情報がほしい人はホームページへ → その中で有料」の3層設計。
コスト構造(無料=全員同報で追加コストほぼゼロ / 有料=個別生成で人数分コスト)と、無料・有料の線引きを一致させる。

**トーンの大原則(最重要)**: 身内・友人も使う前提。**お金や申込を前面に出して急かさない**。
無料通信はあくまで「役に立つ情報」だけを届け、収益化の導線は**ホームページに預ける**。
LINE末尾は「もっと詳しく知りたい方はホームページへ」の**やわらかい一言だけ**。価格・「有料」「急いで」等の煽り表現は無料通信に書かない。

## 3層の導線

1. **無料LINE(ぼんぼやーじゅ通信)** … 誰でも友だち追加で受け取れる。役立つ情報のみ。末尾でホームページへ静かに案内。
2. **ホームページ** … 過去の通信・詳しい行き方・エリア紹介などを掲載。ここで初めて「ご家庭に合わせた出し分け」「カレンダー登録」を使いたい方向けに有料プランを案内する。
3. **有料プラン(月300円)** … ホームページから申込。個別出し分け・週2・カレンダー登録代行など。

## 無料 / 有料の線引き

| | 無料(ブロードキャスト) | 有料(300円/月・個別) |
|---|---|---|
| 配信 | 花小金井エリア共通の同報1本 | プロフィール別に出し分け |
| 頻度 | **週1(水のみ)** | **週2(水・土)** |
| エリア | 花小金井〜小平中心の近場 | 多摩＋都心まで(coverage指定) |
| 宛先 | 未就学児・小学生のいる家庭ぜんぱん | 申込者ごと |
| 内容 | 汎用おすすめ＋年齢3カテゴリの目安 | 興味ジャンル・平日候補・無料重視で絞り込み |
| カレンダー登録 | なし | 「E3を登録」でGoogleカレンダーへ代行 |
| キャンプ | 触りだけ | 空き枠の先読み・予約タイミング |
| 直前確認 | なし | 土曜巡回で中止・天気の直前確認 |
| 収益導線 | ホームページへ静かに案内するだけ | ホームページから申込 |

**原則**: 無料は「読むだけで役に立つ」、有料は「自分向けに動いてくれる」。無料通信で売り込まない。

## 宛先とトーン(無料通信)

- **宛先を特定の子の年齢に寄せない**。「未就学児・小学生のいるご家庭へ」と広く書く(身内・友人・不特定の読者が対象)。
- 「ママ目線で厳選」等の性別・押し付け表現は使わない。中立でやわらかい言い回しにする。
- **各イベントに年齢3カテゴリの目安**を添える: `👶あかちゃん(0-2) / 🧒未就学(3-6) / 🎒小学生` を ◎ぴったり ○だいじょうぶ △ひと工夫 で。

## なぜ無料を週1にするか(LINE無料枠)

LINE公式アカウント無料プランは月200通、broadcastは受信者ごとにカウント。
- 週1(水のみ)= 約4通/人・月 → **約50人**まで無料枠内
- 週2 = 約8通/人・月 → 約25人で頭打ち

無料は週1に抑えて50人まで無料運用。人数が増えたらライトプラン(月5,000円/5,000通)へ。
**このLINE費が「無料ファネルの原価」**で、有料転換で回収する。
無料プロフィールは既存の `frequency: 1x_week` 相当(水のみ配信)で表現する。

## 運用フロー(無料→有料)

1. **共通調査(1回)**: 既存の巡回どおり全 `active` プロフィールの和集合で `events/` を更新。
2. **無料通信(水)**: `profiles/free-hanakoganei.md` を使い、エリア共通版を `reports/free/YYYY-MM-DD.md` に生成 → `scripts/line_report.sh` で**無料アカウントにブロードキャスト**。末尾は下記の**やわらかいホームページ導線フッター**のみ(価格・煽りは書かない)。
3. **有料通信(水・土)**: `active: true` かつ `plan: paid` のプロフィールごとに `reports/<id>/YYYY-MM-DD.md` を生成 → 個別に配信。
4. **転換**: 無料LINE → ホームページ → ホームページ上で有料プランを知って申込(フォーム `docs/onboarding-form.md`) → `profiles/<id>.md`(`plan: paid`)を1枚作成 → 次の巡回から個別対象。

## 通信末尾テンプレ(無料版フッター)

無料通信の末尾に付ける。**免責＋ホームページへのやわらかい案内のみ。価格や「有料」「急いで」は書かない。**

```
━━━━━━━━━━━━━
※日程・料金は変わることがあります。おでかけ前に公式サイトで最終確認を。
ぼんぼやーじゅ通信(無料・週1)でした。

もっと詳しい行き方や過去のおすすめ、ご家庭に合わせた情報を知りたい方は、ホームページものぞいてみてください → https://bonvoya.nicomaru.tokyo/
お友だちにも役立ちそうなら、この画面をそのままシェアしてもらえたら嬉しいです。
```

「イベント先取り情報」欄は、締切・発売日などを**淡々と事実で**書く(「急いで」「損」等の煽り表現は使わない)。

## 有料版フッター

有料通信の末尾は従来どおり(カレンダー登録の案内)。

```
━━━━━━━━━━━━━
気になるイベントは「E5を登録」「E5とE22を登録」と返信でGoogleカレンダーに登録します(前日リマインダー付き)。
「花火だけ」「キャンプもっと詳しく」等の相談もどうぞ。
```

## 特定商取引法・免責(有料化前に用意)

- 有料課金を始める前に、特商法に基づく表記(販売者・連絡先・支払方法・解約条件)を1枚用意する。
- 免責: 「掲載情報は変更の可能性があり、正確性を保証しない。最終確認は各公式で」。
- 個人情報: フォームで用途・おためし運用である旨を明記し同意を得る。連絡先はリポジトリに入れない(`profiles/README.md` のプライバシー方針を踏襲)。
