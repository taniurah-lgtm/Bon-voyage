# 特定商取引法に基づく表記 — ひな型（記入用）

「応援＝お礼(特典)がある」ため法的には通信販売にあたり、この表記が必要。
**〔　〕はあなたが記入する項目。** 記入前に「住所公開の回避」を必ず読むこと。

## ⚠️ 住所・氏名の公開について（先に読む）
- 原則、**販売者の氏名・住所・電話番号の記載（公開）が必要**。
- 自宅住所を公開したくない場合の選択肢:
  1. **決済プラットフォームを使う**（note メンバーシップ / Stripe / BASE 等）。プラットフォームの枠組みで表記でき、自宅住所の公開を避けやすい（最推奨）。
  2. **バーチャルオフィス / 私書箱**の住所を使う。
  3. 「請求があれば遅滞なく開示」方式は、条件が限られ自サイト直販では原則不可。安易に採用しない（必要なら消費者庁の案内・専門家に確認）。
- この表記は公開ページになるため、**載せてよい情報かを必ず自分で判断**すること。Claudeは実名・住所を代筆・推測しない。

## 記載項目（ひな型）
| 項目 | 記入 |
|---|---|
| 販売事業者名 | 〔氏名 または 屋号〕 |
| 運営統括責任者 | 〔氏名〕 |
| 所在地 | 〔住所／またはプラットフォーム・私書箱等〕 |
| 電話番号 | 〔電話番号／請求に応じ開示等〕 |
| メールアドレス | 〔連絡先メール〕 |
| 販売価格 | 月額 300円（税込） |
| 商品代金以外の必要料金 | なし（通信料等はお客様負担） |
| 支払方法 | 〔PayPay／銀行振込／クレジットカード 等〕 |
| 支払時期 | 〔申込時／毎月◯日 等〕 |
| サービス提供時期 | お申し込み・入金確認後、次回の配信日から |
| 解約・返品 | デジタルサービスのため、提供後の返金不可。解約はいつでも可能（次回請求分から停止） |
| 動作環境 | LINE（無料版）／メール等 |
