## ⚠️ 住所・氏名の公開について（先に読む）
- 原則、**販売者の氏名・住所・電話番号の記載（公開）が必要**。
- ただし消費者庁の通信販売広告Q&Aによれば、**「住所」と「電話番号」に限り省略できる**。条件は2つ:
  1. サイト上に「**請求があれば遅滞なく開示する**」旨と、その**開示の方法（連絡先）を明記**すること。
  2. 実際に請求が来たら**遅滞なく開示できる体制**があること（請求を拒むと違法）。
  - **氏名・名称／販売価格／支払方法／解約条件などは省略できない。**
- 自宅住所を公開したくない場合の選択肢:
  1. **請求時開示方式**（上記）。自宅兼事務所の個人事業では最も現実的。**本リポジトリはこれを採用**（`docs/homepage/tokushoho.html`）。
  2. **バーチャルオフィス / 私書箱**の住所を使う（月額の固定費が発生）。
  3. 決済プラットフォーム（note / Stripe / BASE 等）を使っても、**販売主体はクリエイター自身**。プラットフォームを使えば表記が不要になるわけではない。
- この表記は公開ページになるため、**載せてよい情報かを必ず自分で判断**すること。Claudeは実名・住所を代筆・推測しない。
- 出典: [消費者庁 通信販売広告Q&A](https://www.no-trouble.caa.go.jp/qa/advertising.html) / [noteヘルプ 特商法の表示について](https://www.help-note.com/hc/ja/articles/360008947533)

### note の請求日について（2026-08-03 に仕様変更）
- **8/2まで**: 入会日にかかわらず**毎月1日**が請求日。
- **8/3以降の入会**: **入会日**が毎月の請求日（例: 8/10入会 → 次回 9/10）。
- ただし**8/2までに開設されたメンバーシップ**は、クリエイターの設定により従来どおり毎月1日になる場合がある、と note が告知している。
  本メンバーシップは8/2以前の開設のため**どちらかは管理画面で要確認**。
- そのため表記ページの「お支払い時期」は、**どちらでも正確な書き方**（初回は参加時／以降は毎月自動更新／次回請求日は note のマイページで確認／**日割りなし**）にしてある。
  管理画面で確定したら、具体的な請求日を書き足してよい。
