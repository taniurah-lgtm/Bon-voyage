いまの形（`scripts/build-lessons.mjs`・見本 https://claude.ai/artifact/7ShrKzruWRahhzbU8zCRzm ）:
- 白いページに固定（端末が暗い設定でも白）。見出しは「スクールガイド　掲載数〇〇教室」だけ
- 上に「さがす」の枠: **年齢**（すべて／0〜2歳／年少〜年長／小学生）・**習い事**（絵のついた10のボタン。選ぶと色で塗る）・**駅**（4列×2段・件数つき）・無料体験だけ。組み合わせると数が変わり、選んだ条件は「×」で1つずつ外せる。「〇教室を見る」で一覧へ
- 無料の欄は1教室4段（名前／年齢／場所／体験）。体験が書いていなければ「体験の記載なし」。駅が書いていない教室は「仲町（小平駅エリア）」（町の中心から近い駅。小川町は小川・新小平の両方。町名で決まらない教室は駅の「そのほか」）
- PRカードは「PR」の札だけ（ステマの運用基準は「PR」の文言で足りる。掲載料の一文は、いちばん下の小さな説明にだけ）。名前 → 空き → 写真（3枚まで）→ 教室のひとこと → 曜日・費用・体験・申込み → 「通信を見た方へ」の特典 → 「体験を申し込む」
- 口コミ・星・ランキングは載せない。並びは習い事ごとの五十音（PRも混ぜる）
- 改行は、助詞（の・を・で…）のあとだけ（Node の Intl.Segmenter で <wbr>）。かっこ書きと数字＋単位は途中で折らない
- 駅はいくつでも選べる。年齢の書いていない教室は、どの年齢でしぼっても出す（行に「年齢の記載なし」）
- 年齢でしぼったときだけ、行の頭に「4歳から」「小1から」の札（案内の年齢の言い直し。**園児・応相談など、もっと小さい子の受け入れが書いてある行には付けない**＝「小1から」と出すと年少の親が「うちは無理」と読む）
- 駅エリアは場所の名前と「／」で分ける（「小川町（レンタルスタジオ／小川駅・新小平駅エリア）」）
- PRカードの「曜日・時間」はクラスごとに2行（クラス名／曜日と時刻）。「体験の日」は文字で。押せる所はすべて44px以上
- いちばん下は「載せ方について」（並び順／PR／PRのない教室（確認日）／駅エリア／申し込む前に）。「PR」の札の ⓘ とさがす枠の下のリンクから行ける

### 地図で見る（2026-11-27 オーナー「〇教室を見るの下に、一覧になる前にスクールだけのマップを」）

- さがす枠のすぐ下・一覧の前。**町ごとの教室の数を丸で出す**（教室ごとのピンは立てない。無料の欄は町名まで＝自宅の教室が多いため）
- 丸を押すと、その町の教室だけになる（条件の札に「花小金井（地図）×」、地図の下に「花小金井の教室 17／一覧を見る／町を外す」）。もう一度押すと外れる。年齢・習い事・駅・無料体験でしぼると、丸の数も変わる
- 重なる丸は「まとめた数」で出し、押すと寄る（おでかけマップと同じ考え方。まとめた丸はどこか1つの町を指さない）
