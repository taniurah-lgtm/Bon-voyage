# メール配信（メルマガ）への移行計画 — 受け皿を先に作っておく

**いまはLINEのまま。ただし、いつでも移れる状態にしておく。**このファイルはその手順と、移る条件。

---

## なぜ、いつかはメールなのか

**LINEは読者が増えるほど高くなる課金。メールは増えても変わらない。**

| | 無料で送れる上限（週1配信） | 有料 |
|---|---|---|
| **LINE公式アカウント** | **50人**（200通/月 ÷ 4回） | ライト ¥5,000/月・5,000通 → 1,250人まで |
| **メール（Brevo無料枠）** | **購読者数は無制限**／月9,000通・**1日300通** | 〜 |

2026-09-04 時点で到達59人。**LINEの無料枠はすでに構造的に足りない。**
読者200〜300人を超えると、LINEは**恒久的に月¥5,000**になる。メールならゼロのまま。

## それでも、いま乗り換えない理由

1. **59人の読者を失う。**LINEで登録した人にメールアドレスを打ち直してもらう必要がある
2. **獲得動線がLINE型。**チラシのQR→LINEは**1タップ**。メールは「フォームを開く→入力→確認」の**3段階**。
   11月に20館へ200枚配るのに、いちばん効く部分が弱くなる
3. **開封率。**日本ではLINEのほうが読まれる

> 🔑 **だから「受け皿だけ先に作って、貯めておく」。**
> 移るときに、ゼロから集め直さなくて済む。

## 移行の分岐点

**読者200〜300人。** ここを超えたら主軸をメールに移す。理由は2つ。

- LINEが恒久的に¥5,000になる
- **Brevo無料枠の「1日300通」に近づく**（1回の配信で300人を超えると、その日に送り切れない）

300人を超えて配信するなら、Brevoの有料か、購読者上限で課金する別サービスを比較し直すこと。

---

## いまやること（受け皿の設置）

### ステップ1: フォームを作る（Googleフォームでよい）

**Brevoのアカウントはまだ要らない。**送らないので。集めるだけなら Googleフォームで足りるし、
**同意した日時が自動で記録に残る**ぶん、むしろ都合がいい（下記の法律の話）。

フォームの項目はこれだけ:

| 項目 | 種類 | 必須 |
|---|---|---|
| メールアドレス | 短文回答（メール形式の検証をON） | ✅ |
| お住まいの地域（任意） | 短文回答 | — |
| **「ぼんぼやーじゅ通信をメールで受け取ることに同意します」** | チェックボックス | ✅ |

フォームの説明欄に、次の3行を入れる。

```
ぼんぼやーじゅ通信のメール版は、まだ配信を始めていません。
ご登録いただいた方には、始まったときに最初の号をお送りします。
配信の停止は、いつでも1クリックでできます。
```

### ステップ2: ホームページに貼る

`docs/homepage/index.html` の `BV_MAIL_FORM_URL` に、フォームのURLを入れるだけ。

```js
var BV_MAIL_FORM_URL = 'https://forms.gle/xxxxxxxx';
```

**空のあいだはブロックごと表示されない**ので、URLを入れるまでは何も起きない。
場所は「まずは、無料で受け取ってみませんか」セクションの中、QRコードの下。
**LINEより下・小さめに置いてある**（LINEが主導線であることは変えない）。

---

## ⚠️ 実際に送りはじめるときに、増える義務

**メールを送る段階になったら、LINEには無かった義務がつく。**受け皿の段階では発生しない。

### 特定電子メール法 第4条「表示義務」

| 項目 | 書く場所 |
|---|---|
| 送信者の氏名・名称 | **メール本文** |
| 受信拒否の通知先（アドレスまたはURL） | **メール本文** |
| 受信拒否ができる旨 | 通知先の**直前または直後** |
| **送信者の住所** | 任意の場所 |
| 苦情・問合せ先（電話/アドレス/URL） | 任意の場所 |

> ⚠️ **「任意の場所」は「書かなくてよい」ではない。「どこに書いてもよい」という意味。**
> **住所の表示そのものは義務。**リンク先のページでの表示で足りるかは、条文からは読み取れない。
> **送信を始める前に確認すること。**
>
> LINEでは特商法の「請求があれば遅滞なく開示」で済んでいた。
> **メールは「毎号どこかに表示」になる。**重さが違うので、自宅住所を使う判断は取り直す。

### 同意の記録の保存

オプトイン方式なので、**同意を証する記録を保存する義務**がある。
Googleフォームなら**回答日時が自動で残る**ので、スプレッドシートをそのまま保管すればよい。
（LINEの友だち追加は同意そのものなので、この点はLINEのほうが軽い。）

### 個人情報の取り扱い

メールアドレスは個人情報。**リポジトリに絶対にコミットしない。**
スプレッドシートは非公開のまま、オーナーのGoogleアカウント内に置く。

---

## 移行するときの順番（そのときに読む）

1. Brevo（または比較して選んだサービス）にアカウントを作る
2. Googleフォームで集めた住所をインポートする（**同意記録も一緒に残す**）
3. 1通目は「LINEで読んでくださっていた方へ」ではなく、**メールで登録した人への初回**として書く
4. LINEは**やめない**。獲得動線として残し、配信頻度を落とす（隔週なら無料枠で100人まで）
5. ホームページの導線を、LINE単独から「LINE / メール」の2択に変える

> **LINEを閉じない。**チラシのQRは1タップで効く。
> 「入口はLINE、配信はメール」という形も取れる。
