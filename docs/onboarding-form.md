# オンボーディング用 Googleフォーム(友人向け)

友人に配る「設定フォーム」の質問一覧。回答を `profiles/<id>.md` に転記して使う。
Googleフォームを新規作成し、以下をそのままコピーして質問にする。

## フォーム説明文(冒頭)
> 【子連れおでかけ情報 おためし版】お住まいや興味に合わせて、週末の夏祭り・花火・プール・キャンプなどの情報を選んでお届けします(無料・おためし)。ご家族に合わせてチューニングするための設定です。
> ※個人が特定される情報(実名・連絡先)は配信の宛先にのみ使い、第三者には共有しません。おためし運用のため予告なく終了する場合があります。

## 質問

1. **ニックネーム**(記述式・必須)
2. **最寄駅**(記述式・例: 花小金井、武蔵小金井)
3. **お住まいの市区町村**(記述式・例: 小平市)
4. **主な移動手段**(チェックボックス): 徒歩 / 自転車 / 電車 / 車
5. **どこまでの範囲の情報がほしい?**(ラジオ):
   近所(徒歩・自転車圏)だけ / 市内 / 多摩地域全体 / 多摩＋都心も / 車での遠出(キャンプ等)も含めて
6. **興味のあるジャンル**(チェックボックス・複数可):
   夏祭り・盆踊り / 花火大会 / プール・水遊び / キャンプ・アウトドア / 動物園・水族館・牧場 / 屋内遊び場(雨の日) / 味覚狩り・農業体験 / 紅葉・自然 / イルミネーション・クリスマス / 博物館・科学館 / 地域のお祭り・マルシェ / スポーツ観戦
7. **お子さんの年齢**(記述式・例: 6歳・4歳・2歳)
8. **ベビーカー利用や、オムツ替え/水遊びパンツの配慮が必要ですか?**(ラジオ): はい / いいえ
9. **平日のおでかけは可能?**(ラジオ): 土日のみ / 平日も都合をつけられる
10. **予算感**(ラジオ): 無料・格安中心がいい / 有料イベントもOK
11. **受け取り頻度**(ラジオ): 週2回(水・土) / 週1回
12. **受け取り方法と連絡先**(記述式): LINE(友だち追加のうえ表示名)/ メールアドレス

## 転記のしかた(回答→プロフィール)
- 5 → `coverage`(近所=neighborhood / 市内=city / 多摩=tama / 多摩＋都心=tama_plus_tokyo / 遠出=kanto_drive)
- 6 → `categories`(README のタグに変換)。「キャンプ」を選んだら `camp_ok: true`
- 8 → `stroller_needed` / `diaper_care`
- 9 → `weekday_ok`、10 → `budget`、11 → `frequency`、12 → `delivery`(**連絡先はプロフィールに書かず、宛先はフォーム回答シートで別管理**)
- 回答が来たら `profiles/<なまえ>.md` を1枚作成 → 次の巡回から自動で対象になる。
- Claudeに作成を頼む場合は、**実名・連絡先を除いた項目(1のニックネーム＋4〜11)だけ**を渡せばよい。

## 手動配信(パイロット)の流れ
1. 巡回セッションが `active: true` の全員ぶんの個別レポートを `reports/<id>/YYYY-MM-DD.md` に生成。
2. `delivery: manual` の人のぶんは、オーナーがLINE/メールでその本文を手渡し。
3. 反応が良ければ `delivery: line`＋LINE自動配信(docs/line-setup.md, 将来はWebhook)へ移行。
