# 9月30日の週、小平・花小金井の子連れおでかけ｜2026年

---- ここから下を note に貼る ----

小平で、未就学の子や小学生と行ける場所を探している方へ。
2026年10月の最初の週末（10/3・4）を中心に、花小金井から30分ほどで行ける催しをまとめました。
まとめサイトからの転載はせず、市や施設の公式ページで一件ずつ確かめています。

## 🚃 10月最初の週末、多摩六都科学館は電車の企画

多摩六都科学館（西東京市芝久保町5-10-64）で、10月3日（土）と4日（日）に「科学館で学ぶ電車のひみつ」があります。各日 10:30〜12:30 と 13:30〜15:30 の2部です。申込や予約は要らず、開催時間中にイベントホールへ行けば参加できます。料金は入館料のみ（大人520円 / 4歳〜高校生210円 / 4歳未満は無料）で、イベントの追加料金はありません。

鉄道模型の運転体験、モーターの工作、人力発電でNゲージを走らせる展示、カーブを曲がれる車輪の形、レールのカットモデルなどが並び、キッズコーナーもあります。

小平に住んでいると、少し身近に読める企画だと思います。白梅学園清修中高一貫部の鉄道模型デザイン班による「小平市中央エリアの未来のジオラマ」（1/150）が展示され、小平市内の駅や鉄道路線の資料展示と、解説チラシの配布もあります。小平市のマスコット「ぶるべー」も訪ねてくるそうです。

同じ日・同じ会場で「電気で走る鉄道模型を運転しよう！」も開かれます。こちらは対象が小学生で、各回14人。予約はできず、当日に参加券が先着で配られます（午前の枠は開館時の9:30から、午後の枠は12:45から、イベントホール前で配布）。同伴者は体験できないので、未就学のお子さんと行くなら、上の「電車のひみつ」のほうを見るのが確実です。

最新の情報は科学館のウェブサイトでご確認ください。
https://www.tamarokuto.or.jp/blog/press/2026/09/17/event_railway/

## 新小平駅の駅前で、10月3日（土）

新小平マーケットが、JR武蔵野線 新小平駅の駅前ロータリーで 10:00〜16:00。入場無料です。JR関連の体験コーナーに、子ども駅長の制服体験、非常ボタン体験、顔出しパネル、グッズ販売。白梅学園大学の企画でバルーンアートと輪投げもあります。地元の洋菓子・和菓子の店も出ます。荒天のときは中止です。

駅前ロータリーなので屋外です。ベビーカーで入れるか、おむつ替えや授乳の場所があるかは、案内に書かれていないため分かりません（要確認）。

https://kodaira-tourism.com/event/22948/

## 10月1日（木）は都民の日

都立の動物園・植物園・庭園・博物館などの入園料・入館料が無料になる一日です。子ども連れで効くのは大人のぶんで、子どもはふだんから無料のところが多くあります。

花小金井から近いのは、小金井公園のなかにある江戸東京たてもの園（小金井市桜町3-7-1）。自転車・バス圏で、一般400円がこの日は無料になります。中学生以下はふだんから無料です。10月の開園は 9:30〜16:30（入園は16:00まで）。月曜が休園日なので、木曜は開いています。

バス・電車で30分ほどの井の頭自然文化園も入園無料になります。9:30〜17:00（入園は16:00まで）で、こちらも月曜休みなので木曜は開いています。一般400円、小学生以下はいつも無料です。

都の広報に「混雑時、入場時間調整あり」と添えられています。

## この週末に動けなかったときの、屋内の手札

多摩六都科学館の2階図書コーナーで、10月1日（木）から11月8日（日）まで「たまろくとしょかん ブックセレクション」が開かれます。テーマは「鉄道の本」。小平・東村山・清瀬・東久留米・西東京の5市の図書館と、科学館のおすすめ本が並びます。2階なので入館券が必要で、入館料のみで見られます（追加料金はありません）。休館日（10/5〜9・13・19・26、11/2）は開いていません。

1か月以上あるので、10月3日・4日に行けなくても大丈夫です。

申込に締切のあるものでは、「ちびっこ集まれ 親子でヨーイドン」が10月5日（月）まで。そのあとは10月16日（金）締切のものが何件か続きます。
