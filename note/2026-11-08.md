# 【2026年】小平・花小金井まわりの児童館・こども広場 21か所まとめ（無料）

---- ここから下を note に貼る ----

小平市で、赤ちゃんや未就学の子、小学生を連れて「今日はどこへ行こう」と思ったときに。市内には、無料で使える児童館とこども広場が21か所あります。雨の日も、外が暑い日・寒い日も、お金をかけずに子どもを遊ばせられる場所です。

数が多いので、種類ごとにまとめました。住所と開館時間は、市や施設の公式ページで一件ずつ確かめています。まとめサイトからの転載はしません。

## 児童館（3館）

乳幼児から高校生年代まで、無料で使える市の施設です。おもちゃやボードゲームがいつでも使えて、ふれあい遊び・体操・誕生会・読み聞かせなどの行事もあります。申込は不要ですが、初めて使うときは登録が必要です。

- **花小金井南児童館** … 花小金井南町3-3-17 コミュニティセンター2階／☎042-461-9988
- **小川町二丁目児童館** … 小川町2-1154／☎042-345-6454
- **小川町一丁目児童館** … 小川町1-3045／☎042-347-2428

開館は平日が9:00〜19:00、土・日・祝は9:00〜18:00。**休館は第1・第3火曜**（祝日ならその翌日）と12/28〜1/4です。

3館とも年齢の目安は 👶◎ 🧒◎ 🎒◎。きょうだいの年齢が離れていても、同じ場所で過ごせます。ボルダリングやドッヂビーのような小学生向けの行事も不定期にありますが、行事の日時と対象学年は館のおたよりでないと分かりません。各館のおたよりでご確認ください。
https://kodaji.ashita-ba.co.jp/

## 児童館のなかのこども広場（3か所・午前中）

上の3館には、乳幼児と保護者・小中学生向けのスペースが、別の時間帯で開いています。専門スタッフが子育ての相談や保護者同士の交流、遊びのサポートをしています。

時間は月〜日曜の9:00〜14:00。児童館そのものの開館時間とは別なので、午前に行くならこちらです。場所と電話番号は上の3館と同じ。年齢の目安は 👶◎ 🧒◎ 🎒○。

## 出張こども広場（9か所・曜日が決まっています）

地域センターで開かれる出張版です。無料。ふれあいタイムや工作など、少人数でゆっくり過ごせます。決まった曜日だけなので、出かける前に日にちを確かめてください。時間はいずれも10:00〜18:00。

- 月曜 … **美園**（美園町1-19-2）／**学園西町**（学園西町2-12-22）
- 水曜 … **鈴木**（鈴木町1-400）／**小川西町中宿**（小川西町2-30-1・水曜と第1日曜）
- 木曜 … **小川東第二**（小川東町5-9-1）／**喜平**（喜平町1-10-9）／**学園東町**（学園東町2-16-11・木曜と第2日曜）
- 金曜 … **御幸**（御幸町58・金曜と第3日曜）／**小川西町**（小川西町5-4-17）

日曜に開く日があるのは、小川西町中宿（第1日曜）・学園東町（第2日曜）・御幸（第3日曜）の3か所です。年齢の目安は 👶◎ 🧒◎ 🎒△。

トイレやおむつ替えの場所、授乳室、駐車場、ベビーカーで入れるかどうかは施設ごとに違います。そこまでは確かめられていないので、気になることは各施設へ電話でご確認ください。
