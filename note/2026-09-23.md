# 9月23日の週、小平・花小金井の子連れおでかけ｜2026年

---- ここから下を note に貼る ----

小平市とそのまわりで、未就学児・小学生を連れて行ける場所を探している方へ。9月23日(水)からの一週間、小平・花小金井から30分ほどの範囲で開かれる催しをまとめました。日程は市や施設の公式ページで一件ずつ確かめています。まとめサイトからの転載はしません。

## 🚃 9月26日(土)｜たけのこ公園（花小金井）

**たけのこ公園ビアガーデン！2026** — 9月26日(土) 10:00〜20:00、小平市立たけのこ公園（小平市花小金井7-9-10／西武新宿線 花小金井駅・小平駅）。入場無料で、出店と飲食は実費です。

キッチンカーが10台以上出るほか、こども縁日としてスーパーボールすくい、車にラクガキコーナーが並びます。竹林と原っぱの公園で、横を西武新宿線が走ります。昼は子ども向け、夜はビアガーデン寄りの構成なので、未就学児と行くなら明るいうちが向いています。

トイレ・授乳室・おむつ替え・ベビーカーの可否は公式に記載がないため、要確認です。雨のときの扱いも2026年の告知には書かれていないので、当日の朝に主催の告知をご確認ください。問合せはこだいら観光まちづくり協会 042-312-3954。
https://kodaira-tourism.com/event/22825/

## 9月27日(日)は3つ重なります

**熊野宮 神幸祭**（小平市仲町・一橋学園駅圏）。9月26日(土)の宵宮が13:00〜20:00、27日(日)が神幸祭で、渡御は9:30に一橋学園ロータリーを出発します。無料（模擬店は実費）。宵宮では子供みこしを参道で数回かつぎ、参加した子にお土産があります。子供ゲーム（ストラックアウト・輪投げ・ボッチャ・水鉄砲）も。日曜は大道芸と回太鼓で、大太鼓は子どもがひけます。駐車場はなく、駐輪場も数に限りがあります。
https://kumanogu.com/shinkousai/

**太陽福祉センターまつり** — 9月27日(日) 10:00〜15:00、小平市立たいよう福祉センター 館内外（小川町）。入場無料（模擬店は実費）。工作コーナー、スタンプラリー、アートバルーン、人形劇のほか、ボッチャ・手話・点字の体験も。駐車場はなく、自転車は小川駅西駐輪場へ。042-344-1217。
https://www.syakaifukushi.kodaira.tokyo.jp/service/news/taisyo/20260722.html

**小平マルシェ vol.25** — 9月27日(日) 10:30〜15:30、village green（小平市天神町3-7-1）。入場無料と、主催の方からご回答をいただいています。陶芸、苔テラリウム、ビーズブレスレットなど、子どもと一緒に作れるワークショップが複数出ます。料金は出店ごとに違います。

熊野宮は一橋学園、たいよう福祉センターは小川。どちらも自転車圏ですが、はしごは現実的ではありません。
