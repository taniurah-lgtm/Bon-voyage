# 【2026年】小平・花小金井まわりの「雨・猛暑の日の屋内（毎週使える）」8か所まとめ

---- ここから下を note に貼る ----

小平で、雨の日や暑すぎる日に、子どもと行ける屋内の場所を探している方へ。
花小金井から行ける屋内のおでかけ先を8か所まとめました。
季節かぎりのイベントではなく、一年を通して使えるところを選んでいます。
まとめサイトからの転載はせず、市や施設の公式ページで一件ずつ確かめています。

## ☔ 花小金井の近くで、思い立った日に

多摩六都科学館（西東京）は、世界最大級のプラネタリウムがある施設です。
0歳から入れる回もあるので、下の子を連れていても組み立てやすいと思います。
実験イベントもあります。年齢の目安は、あかちゃん ○ / 未就学 ◎ / 小学生 ◎。
https://www.tamarokuto.or.jp/

イオンモール東久留米は、車で行きやすいところです。室内あそび場・授乳室・おむつ替えがそろっていて、
専門店街の3階には屋内の遊び場「ちきゅうのにわ 東久留米店」があります。
あかちゃん ◎ / 未就学 ◎ / 小学生 ○。
https://www.aeon.jp/sc/higashikurume/

田無アスタは、西武新宿線・田無駅の北口すぐの専門店街です。
2階のセンターコートで、縁日やワークショップなど季節のイベントが開かれます。
電車で行けるので、車が使えない日にも動きやすいところだと思います。
あかちゃん ◎ / 未就学 ◎ / 小学生 ○。
https://www.asta.co.jp/

スパジアムジャポン（スパジャポ・東久留米）は、天然温泉と岩盤浴の大型スパです。
授乳室・おむつ替え・粉ミルク用のお湯・フードコートがそろっています。
田無駅と東久留米駅から無料のシャトルバスが出ています。
あかちゃん ○ / 未就学 ◎ / 小学生 ◎。
https://www.spajapo.com/

## 📖 お金をかけずに、短く過ごす

小平市立図書館のおはなし会は、絵本の読み聞かせや手あそびの時間です。
花小金井図書館ほか、市内の各図書館で開かれています。無料・申込不要のことが多い会です。
回ごとに対象年齢が分かれているので、はじめての絵本の時間にも向いています。
あかちゃん ◎ / 未就学 ◎ / 小学生 ○。開催日は市立図書館の「おはなし会」のページに出ます。
https://library.kodaira.ed.jp/viewer/info.html?id=74

雨の予報が出てから行き先を決めたい日に、いちばん当てにしやすいのがここだと思います。

あかちゃん △ / 未就学 ○ / 小学生 ◎ なので、下の子がまだ小さいうちは、
上の子と過ごす日に向くかもしれません。
https://mangapark.jp/

## 料金・時間・持ちものは、公式で

この記事では、料金や開いている時間、持ちものには触れていません。
施設によって案内の出し方が違いますし、変わることもあるためです。
授乳室やおむつ替えについても、施設の案内に出ていたものだけを書いています。
書いていない施設は、あるともないとも言えないので、そちらも公式サイトでご確認ください。

確かめられたことだけを書くようにしています。ここに無いことは、おでかけの前に各公式でお願いします。
