# 【2026年】小平・花小金井まわりの「電車でおでかけ（西武新宿線ぞい）」6か所まとめ

---- ここから下を note に貼る ----

小平で、車を使わずに子どもと出かけたい方へ。
花小金井は西武新宿線の駅なので、電車に乗ればそのまま行ける場所がいくつもあります。
この記事では、線ぞいで子どもと行けるところを6つまとめました。

日程や料金は変わることがあるので、それぞれの公式サイトへのリンクを付けています。
まとめサイトからの転載はせず、市や施設の公式ページで一件ずつ確かめています。

## 🚃 乗り換えなしで行ける — 東伏見アイスアリーナ

西武新宿線の東伏見駅すぐにあるスケートリンクです。通年で滑れるので、夏は涼しく、冬は室内で快適に過ごせます。
ファミリー向けの時間帯もあるので、はじめてのスケートにも向いています。

年齢の目安は、あかちゃん △ / 未就学 ○ / 小学生 ◎。
あかちゃん連れのときは、上の子が滑るのを見て過ごす時間が長くなりそうです。

- 公式サイト: https://www.seibu-leisure.co.jp/icearena/index.html

## 乗り換えて、東村山・所沢へ

ここから先は乗り換えが必要ですが、そのぶん一日かけて遊べる場所です。

**八国山緑地・北山公園（東村山）** は、トトロに出てくるような雑木林をおさんぽできるところです。
東村山駅・西武園駅から歩けます。となりの北山公園とは約400mで隣どうしなので、続けて回れます。
北山公園は初夏、6月ごろの菖蒲が有名なので、その時期をねらうのもいいと思います。
https://www.tokyo-park.or.jp/park/format/index084.html

**西武園ゆうえんち（東村山・所沢）** は、電車で行ける遊園地です。
小さい子向けのエリアがあり、乗り物デビューにちょうどいい規模感です。
https://www.seibuen-amusement-park.jp/

**所沢航空記念公園（所沢）** は、広々とした芝生と大型遊具があり、航空発祥記念館も併設されています。
所沢航空記念公園駅すぐなので、一日たっぷり遊べます。
https://www.parks.or.jp/tokorozawa/

3か所とも年齢の目安は、あかちゃん ○ / 未就学 ◎ / 小学生 ◎ です。

## 雨の日と、都心に出る日

**ところざわサクラタウン** は、角川武蔵野ミュージアムのある複合施設です。
屋内なので雨の日にも向いています。東所沢駅から歩きます。
年齢の目安は、あかちゃん ○ / 未就学 ◎ / 小学生 ◎。
https://tokorozawa-sakuratown.com/

もうひとつ、西武新宿線は高田馬場・西武新宿まで乗り換えなしで出られます。
天気が崩れた日は、都心の屋内施設に切り替えるという手もあります。
年齢の目安は、あかちゃん ○ / 未就学 ○ / 小学生 ○。
https://www.seiburailway.jp/railways/
