# 【2026年】多摩六都科学館（西東京）は子連れでどう？ 料金・駐車場・おべんとう

---- ここから下を note に貼る ----

小平市で、未就学児や小学生を連れて行ける屋内の場所を探している方へ。花小金井から自転車・バスで行ける多摩六都科学館（西東京市）の料金・開館時間・駐車場・館内の設備を、公式ページで確かめた内容だけまとめました。天気に左右されない行き先を、ひとつ手札に持っておきたいときに。

## 🔭 多摩六都科学館はこんなところ

西東京市芝久保町5-10-64。プラネタリウムのドーム（サイエンスエッグ）と展示室がある科学館です。

開館は9:30〜17:00。**発券は16:00まで**なので、夕方に着くと入れないことがあります。休館は月曜（祝日・振替休日は開館し、その翌日が休館）、祝日の翌日、年末年始、機器整備日。連休のあとは開館日がずれるので、出かける前にカレンダーを見ておくと確実です。

公式サイト: https://www.tamarokuto.or.jp/

## 料金と駐車場

- 展示室のみ … 大人520円／小人（4歳〜高校生）210円
- 展示室＋プラネタリウム（または大型映像） … 大人1,040円／小人420円
- **4歳未満は無料**。ただし窓口で4歳未満用の券が渡されるので、入館の手続きは必要です

駐車場は普通車170台、9:15〜17:15。入庫後30分までは無料で、以降は30分ごとに100円、1日の上限が700円。**支払いは現金のみ**なので、小銭を用意しておくと入口で慌てません。

## 小さい子と連れて行くときに

休憩室が全部で154席あり、**お弁当など持ち込んでの食事ができます**。水飲み場と自動販売機、授乳室も。多目的トイレには介助用のパブリックシートがあります。

プラネタリウムには小さい子向けの回があります。キッズプラネタリウムは**土日祝の10:30〜11:05**。現在は「ペガロク きまぐれ宇宙旅行！ぐるぐる月旅行編」を12月27日（日）まで投影していて、上映は約35分、定員220人、対象は「どなたでも」ですが、**小学2年生以下は保護者と一緒の観覧**になります。チケットは当日、開館時からインフォメーションで先着順の販売で、予約はできません。投影の時刻は日によって変わるので、行く日のぶんをカレンダーで確かめてください。

さらに**「0歳からのプラネタリウム」**という回もあり、次は10月2日（金）の10:30〜11:00と11:30〜12:00（各30分）。対象は0歳から3歳くらいのお子さんとご家族で、館が「泣いてもOK」と書いています。**ドームにベビーカーは持ち込めず、お子さんは着席かお膝の上**での観覧です。この回は年に数回で、次は12月24日（木）と2027年1月8日（金）です。

※最新の情報は多摩六都科学館ウェブサイトでご確認ください。

## 申込のいらない催しと、近くでもう1か所

入館料だけで参加できて、申込のいらない催しが続きます。

- **科学館で学ぶ電車のひみつ** … 10月3日（土）・4日（日）の10:30〜12:30と13:30〜15:30。イベントホールへ直接行けばよい自由参加で、追加料金はかかりません。鉄道模型の運転体験やモーターの工作のほか、**白梅学園清修中高一貫部の鉄道模型デザイン班がつくった「小平市中央エリアの未来のジオラマ」**の展示と、小平市内の駅や鉄道路線の資料展示があります。小平市のマスコット「ぶるべー」も訪れます。
- **ザクロ石を観察しよう** … 10月10日（土）〜12日（月）、17日（土）、18日（日）、11月3日（火）、7日（土）、8日（日）、14日（土）、15日（日）。各日11:00／12:00／14:00／15:00 からの45分で、随時入れ替えなので途中で抜けられます。申込不要・入館料のみ・定員なし（混雑時は待機あり）です。

※最新の情報は多摩六都科学館ウェブサイトでご確認ください。

同じ方面には、小平市立図書館の**「絵本のへや」**（0〜3歳の子と保護者向けの、絵本の読みきかせや手遊び、わらべうた。4歳から小学生には別に「おはなし会」があります。開催日は館ごとに決まっています）や、**さわやか館のこども広場**（乳幼児と保護者・小中学生向けの無料スペース。子育てコンシェルジュに相談ができます）もあります。
