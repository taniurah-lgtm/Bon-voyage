# 【2026年】小平・花小金井まわりの「無料で水あそび（夏）」2か所まとめ

---- ここから下を note に貼る ----

小平で、小さい子や小学生と、お金をかけずに水あそびができる場所を探している方へ。
花小金井から歩いて行けるところと、自転車や車で10分ほどのところを2か所まとめました。
どちらも無料です。期間や時間は変わることがあるので、公式サイトへのリンクを付けています。
まとめサイトからの転載はせず、市や施設の公式ページで一件ずつ確かめています。

## 💧 歩いて行ける — 花小金井ひょうたん池公園

花小金井駅の南口から徒歩約9分、小平市花小金井南町3-3-13にある公園です。
大きなじゃぶじゃぶ池があり、浅めなので、はじめての水あそびにも向いています。利用は無料です。

年齢の目安は、あかちゃん ◎ / 未就学 ◎ / 小学生 ○。
歩きはじめたばかりの子でも入りやすい水あそびの場所で、駅から歩ける距離にあるのが助かるところです。

ひとつ知っておきたいのは、この公園には遊具とトイレがないことです。
長く居座る場所というより、水あそびだけを目的に短く区切って行くほうが、組み立てやすいと思います。
着替えのことも含めて、出かける前に済ませておくほうが安心です。

小平市内では、ほかに天神じゃぶじゃぶ公園や中央公園（鷹の台）にも水遊びの場所があります。
その年にどこが開いているかは、市のページに一覧が出ます。
なお、たけのこ公園には水遊びの施設はありません。

- 公式（小平市）: https://www.city.kodaira.tokyo.jp/kurashi/113/113055.html
- 地図: https://www.google.com/maps/search/?api=1&query=花小金井ひょうたん池公園

## 自転車や車で10分 — 西東京いこいの森公園の噴水広場

西東京市緑町にある公園で、噴水型の水あそび場があります。花小金井からは車や自転車で約10分。こちらも無料です。

噴水型なので、オムツの子でも遊べます。年齢の目安は、あかちゃん ◎ / 未就学 ◎ / 小学生 ○。
下の子がまだ小さいうちから連れて行きやすいのが、この場所の良いところだと思います。

動いている時間は10時30分から15時15分まで。45分動いて15分休む、というくり返しです。
気温が25度を下回る日と、天気の悪い日はお休みになります。毎月第2火曜日は点検日です。
2026年は10月12日（月）までとなっています。

- 公式（西東京市）: https://www.city.nishitokyo.lg.jp/kurasi/koen/kouenmizuasobi.html
- 地図: https://www.google.com/maps/search/?api=1&query=%E8%A5%BF%E6%9D%B1%E4%BA%AC%E3%81%84%E3%81%93%E3%81%84%E3%81%AE%E6%A3%AE%E5%85%AC%E5%9C%92

## 9月の水あそびは、期間を先に確かめてから

この2か所は、開いている期間の長さがずいぶん違います。

小平市の公園の水遊び施設は、例年7月上旬から9月上旬まで、10時から17時の開設です。
2026年の正式な期間は市のページでご確認ください。9月の半ばになると、
その年の開設がもう終わっていることがあります。

いっぽう、西東京いこいの森公園の噴水は10月12日まで。
9月に入ってから水あそびに行くなら、こちらのほうが空振りになりにくいと思います。
ただし気温25度を下回ると止まるので、涼しい日は動いていないことも出てきます。

持ちもの、着替えのできる場所、水遊び用オムツの決まりについては、
この記事では触れていません。施設によって案内の出し方が違うので、公式サイトでご確認ください。
確かめられたことだけを書くようにしているので、ここに書いていないことは公式でお願いします。
