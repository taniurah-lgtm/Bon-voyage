# キャンプ台帳(関東近郊・車2.5時間圏中心)

対象: 大人2+子3(6歳・4歳・2歳)。土日1泊が基本、平日も可。
2歳児がいるため「エアコン付きコテージ/バンガロー or 標高が高く涼しい」+「浅い川・じゃぶじゃぶ池」+「清潔なトイレ・炊事場」を重視。
ステータス: 候補 / 承認済 / 予約済 / 見送り

## 予約の基本(重要)
- 人気ファミリー施設の夏〜秋の土曜は2〜3ヶ月前に即完売。**開始日・時刻は施設ごとに違う**ので各公式の予約スケジュールを都度確認する(例: C&C山中湖は2ヶ月前の月末20時開始＝**2026年9月分は6/30 20時に開始済=受付中**)。
- 取りにくい時は **日曜泊(日→月)** に切替+**なっぷ/公式のキャンセル待ち通知**登録が最も有効。
- 予約開始ルール例: ケニーズ=3ヶ月前の月初1日 / PICA=3ヶ月前の同日0時 / スウィートグラス=毎月1日に翌々月末まで / C&C=2ヶ月前の月末20時 / 無印嬬恋=3ヶ月前第1営業日 / 休暇村鹿沢=6ヶ月前。※ルールは変わるので巡回時に各公式で再確認。

## A. 東京・奥多摩/あきる野/檜原(最も近い・車1〜2時間)
