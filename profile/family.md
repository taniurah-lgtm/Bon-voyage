# 家族プロフィール

- 住まい: 東京都小平市・花小金井駅(西武新宿線)の南側
- 家族構成: 大人2人+子ども3人
  - 年長(6歳ごろ)
  - 年中(4〜5歳ごろ)
  - 2歳(ベビーカー・オムツ配慮が必要)
- 移動手段: 車あり(キャンプに行く)。近場は自転車・電車も。
- 予定の傾向: 基本は土日。平日でも都合をつけられる(空いている平日プール等は提案価値あり)。

## 好み・興味

- 地元イベント: 夏祭り・盆踊り・花火大会・プール・季節の行事
- 旅行・アウトドア: 関東近郊でのキャンプ(車で概ね2.5時間圏)
- 子ども3人連れで動きやすいことが重要:
  - ベビーカーで動けるか / 混雑しすぎないか
  - トイレ・オムツ替え場所
  - プールはオムツ・水遊びパンツ規定(2歳が入れるか)
  - 帰宅時間が遅くなりすぎない(花火は近場・短時間が◎)

## 対象エリア

- 週末イベント: 小平・西東京・小金井・国分寺・東村山・武蔵野など近隣を最優先、多摩地域全体+都心まで
- キャンプ: 奥多摩・秩父・飯能・道志・山中湖/河口湖・北軽井沢・那須・房総など関東近郊
